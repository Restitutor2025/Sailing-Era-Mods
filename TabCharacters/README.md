기존 `Restitutor_fixes_TabMenu.dll`은 진단용 별도 모드다. 교체하지 않는다.
되돌리려면 게임이 종료된 상태에서 이 DLL만 제거한다. 게임/Steam 실행과 실제 조작 검증은 사용자만 수행한다.

## 확인 상태

Release 빌드 경고/오류 0. 관리 대역 검사 11,509개, 훅 서명 9개와 게임 참조 60개 대조 통과.
실제 IL2CPP 후킹·화면 배치·Q/E 키 설정·마우스 조작·병용은 사용자 실행 전이다.

항해사 원본 목록과 현재 선택 상세는 유지한다. 페이지 축소/인물 탭 복귀/종료 때 해당 목록 풀의 비표시 초상화 URL과 남은 MyGLoader 작업 참조를 정리한다. 인물 탭에서 메뉴를 닫으면 큰 일러스트와 상세 초상화도 정리한다. 빈 UI는 재사용한다. 스킬·장비 탭으로 바꾸는 동안 상세 이미지와 원본 3D 수명주기는 유지한다. 공용 텍스처 강제 파괴·GC 없음. 참조 반환이 실제 메모리 감소를 보장하지는 않는다.
