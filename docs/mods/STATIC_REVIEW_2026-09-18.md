# 설치 원본과 Restitutor 정적 재검토

## 결론과 범위
현재 확인한 항로·안개 연결과 테스트 범위에서 새로 확정한 충돌 결함은 없다. 게임 실행 성공, 안개 증상 해결, 모든 원본 분기와의 호환성을 보장하는 결론은 아니다. 추정 원인을 추가하거나 코드 수정하지 않았다.
대상: intro 0.1.2, textspeed 0.1.3, map 0.1.4. 지도 집중 검토이며 다른 두 모드의 모든 네이티브 분기를 재분석한 것은 아니다.
설치 GameAssembly.dll을 비교 기준으로 사용했다. Steam 배포 원본과 동일한 무변조 파일인지는 공식 기준 해시로 검증하지 않았다.

## 이번에 수행한 확인
- 지식베이스 BASELINE에 기록된 파일의 현재 SHA256 불일치 없음.
- 프로젝트 빌드·바탕화면·설치 Mods의 지도 DLL SHA256 동일: F6AB3F86A8ACE8A1B22B40B6ECEBD9EE8EB57E2C32974F65557077C1B5740044.
- fog-evidence와 map-integration의 asm 96개, 명령어 바이트 합계 56,399바이트를 현재 설치 PE의 해당 RVA와 비교: 불일치 0. 이것은 기록된 명령어 바이트의 동일성 검사이며 전체 함수/전체 DLL의 의미 검증이 아니다.
- 3개 모드의 기존 등록 목록 40개에서 네이티브 RVA 중복 없음. 같은 주소에 추가된 다른 외부 모드나 런타임 등록 순서는 이 검사 대상이 아니다.
- Map/tests/MapChecks.csproj: 86개 통과. 실제 소스+대역 API. 게임 코드/렌더러 실행 없음.
- TextSpeed/tests/StoreTests.csproj: 48개 통과. 독립 설정 파일 테스트.
- Map/tests/VerifyBindings.ps1: 패치 대상/매개변수 31개, 외부 참조 107개 해석 통과. 알려진 공유 주소 외 중복/미검토 별칭 검사 통과.

## 원본 연결에서 대조한 사항
- 원본 OnAction_A(int)는 AcceptInput과 CheckPortSelectStatus 이후 AddNodePort/ReduceNodePort로 간다. 모드가 원래 int 선택 함수를 호출하며 조건을 강제 참으로 바꾸지 않는 것을 확인했다.
- AutoSail 패치는 반환 void인 로그 Prefix다. 원래 AutoSail 실행 차단이나 선원/보급/확인창 우회 코드를 추가하지 않는다.
- 원래 CloseHook은 CloseCheckLine으로 이어진다. 모드는 원래 닫기를 유지하며 소유한 지도 정리와 닫기 재진입을 대역에서 확인한다.
- 선 강조는 네이티브 BestLineList를 읽고 선 표시 상태를 갱신한다. 대역 테스트에서 원래 계산 경로 배열을 변경하지 않음을 확인한다.
- 안개는 같은 area/mask 포인터와 유효 텍스처/버퍼 조건에서 초기화 생략. Deserialize/InitHook/SetMaskData/Dispose 시 소유권 초기화가 있으며 원래 함수 실행을 차단하지 않는다. 다른 데이터/없는 텍스처/초기화 조건은 대역 테스트 통과.
- 일반 지도와 항로 지도 객체 전체를 하나로 삭제·재작성한 것은 아니다. 표시 지도는 일반 Tab, 원래 항로 컨트롤러는 계산·확인·출항을 담당한다.

## 사용자 확인이 필요한 사항
사용자는 항로 기능은 미확인, 안개는 아직 테스트 전이라고 답했다. 현재 요청은 코드 검증만이며 아래 실제 실행 결과는 미확인으로 유지한다.
1. 0.1.4 항로 계획의 도시 선택·선 색상, Tab 닫기, 실제 출항.
2. 새 탐사 후 저장 전 재열기, 항구 출입, 저장 후 불러오기의 안개 유지.
추가로 다른 세이브 로드 시 탐사 정보 혼입과 확인창 취소 후 입력 복귀는 실제 실행 확인이 필요하다. 대역 통과만으로 정상 선언하지 않는다.
