# Cheats Interface 1.1.3 — 화면 비율로 초기 배치

2026-09-19. 사용자 참고 화면의 창은 왼쪽 약 9%, 아래 약 6.5% 여백에 위치한다. 고정 좌표 대신 이 비율을 초기 배치에 적용했다.

확인한 관리 소스: Host.OnUpdate는 GRoot의 너비/높이 및 스케일 적용된 창 크기를 WindowState.Place에 전달한다. Place의 최초 X는 screenWidth * 0.09, Y는 screenHeight - height - screenHeight * 0.065다. 스크린샷의 창 제목 표시줄을 제외한 게임 영역에 대한 근사 비율이다. 드래그 이후 위치 유지와 기존 화면 안 제한은 유지한다. 현재 세션 중 해상도 변경 시에는 기존 위치를 화면 안으로 제한하며 초기 비율로 재배치하지 않는다. 화면보다 창이 큰 경우 화면 안 제한이 우선한다.

Interface만 1.1.3, AssemblyVersion 1.0.0.0 유지. 기존 Interface 4개 훅/입력/공유 게임 상태/수명주기 계약 유지. 네이티브 함수 변경 없음. 도시 이동 후 미표시 원인 수정과는 별개다.

실제 게임 참조 빌드: 경고 0/오류 0. 기존 Host 수명주기 검사 61개 통과. 게임/Steam 실행·조작 없음. 실제 게임 위치는 사용자 확인 전.
