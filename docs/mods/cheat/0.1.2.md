# Cheat 0.1.2 — 지도 현재 선택 판정

2026-09-18. 사용자 화면: 도시 위 커서에서 선택 없음/충돌, 도시 밖에서 체류 도시 부산 표시. Latest.log에서 Multiple selected cities 반복을 확인했다. 별도 UIMapLineCtrl.DisposeHook 예외도 존재하며 이번 수정 대상이 아니다.

## 근거와 변경

설치 바이너리를 extract.py로 재추출했다. [일반 지도](../../../Cheat/evidence/UIMapCtrl.GetCurrentSelectPort0x5E0A00.asm)는 모델+0x50 현재 ID로 아이콘을 조회하고 도시 타입을 확인하며 true 인수에서는 아이콘+0x18 선택 상태도 확인한다. [항로 지도](../../../Cheat/evidence/UIMapLineCtrl.GetCurrentSelectPort0x5EAF10.asm)도 현재 ID 및 선택 상태를 확인한다. AbsUIMapIcon.get_IsSelected 본문은 +0x18을 읽는다.

기존 치트는 이 결과에 모든 HarbourIcons의 IsSelected 항목을 합산했다. 0.1.2는 전체 아이콘 순회를 제거하고, 실제 표시 중인 각 지도에서 원본 현재 선택 조회 결과만 수집한다. 서로 다른 ID가 둘 이상이면 기존 로그/적용 거부를 유지하며 같은 ID 중복은 합친다. 지도 선택이 없을 때만 체류 도시로 돌아간다. 각 오탐 ID가 어떤 수집 경로에서 왔는지는 과거 로그로 특정할 수 없으며, 실제 수정 효과는 사용자 확인이 필요하다.

Map의 CurrentRoutePort 훅은 원본 항로 지도의 조회를 일반 지도로 연결할 수 있다. 이 기존 계약을 유지한다. 지도 객체의 표시/해제, DisposeHook, 입력, 목표값 적용 및 무변경 시 UpdateInfluence 미호출 규칙은 변경하지 않았다.
