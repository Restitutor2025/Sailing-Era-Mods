# Cheats Interface 1.3.0 — H 토글과 상태 유지

2026-09-20. WindowState.IsOpen 불리언의 기본값 false. H 누름 가장자리에서 현재 표시 상태를 반전한다. false는 제목줄만 남기는 접힘, true는 패널 펼침이다. 키를 길게 눌러도 한 번만 전환한다. 도시/항해/로딩 및 세션 초기화에서도 사용자 값을 유지하고 프로세스 재시작 시 false로 시작한다. 기존 화살표는 같은 IsOpen을 변경한다.

X는 기존처럼 창 전체를 숨기지만 H를 새로 누르면 다시 펼친다. ResetLocation은 장소 추적만 초기화하며 IsOpen을 바꾸지 않는다. 창 재생성/패널 Refresh도 값을 초기화하지 않는다.

## 입력·공유 계약과 근거
확인된 소스: [WindowState](../../../Cheats/Interface/WindowState.cs), [Host](../../../Cheats/Interface/Host.cs). OnUpdate에서 Unity InputSystem Keyboard.current.hKey.isPressed를 읽고 자체 이전 눌림 값으로 가장자리를 검출한다. 게임이 포커스를 갖고 Player 및 패널이 있으며 FairyGUI GTextInput 포커스가 없을 때만 토글한다. 입력 중 누르거나 비활성 앱에서 누른 H는 허용 상태 복귀 시 뒤늦게 적용하지 않는다. 다른 기능/전투 모듈에 의존하지 않는다.

기존 입력 캡처 훅은 그대로다. 토글 성공 시 자기 포커스와 드래그/스크롤 상태 해제 및 기존 0.25초 SwallowInput 사용. 키 매핑을 변경하거나 새 네이티브 훅을 추가하지 않는다. H 폴링은 게임 액션 캡처와 별도이므로 외부 모드의 H 바인딩은 충돌 가능성이 있다. 설치 metadata의 기본 Keyboard 바인딩 검색에서는 H가 없었고 작업 폴더 소스의 직접 H 키 사용도 발견되지 않았다. 사용자 키 재설정/전체 외부 바이너리 실전 병용은 미확인이다.
