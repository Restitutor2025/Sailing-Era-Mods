# Cheats 1.2.1 — 공헌도 숨김과 진입 시 접기

2026-09-19. Interface 1.2.1 / Contribution 1.1.1. Speed/Bargirls는 1.1.1 유지.

공헌도 패널도 도시 밖에서는 전체 숨김 및 공간 제거. 기존 Resolve의 플레이어/장면/항구 체류 조건을 IsInCity로 추출해 표시 조건으로 사용한다. 도시 안에서는 지도·항로도 등 기존 적용 제한을 유지한다.

WindowState는 기본 최소화이며 세션 초기화에도 최소화한다. Host.OnUpdate에서 준비된 도시 ID 또는 일반 항해 상태 진입을 관측하면 최소화하고 자기 포커스 및 드래그/스크롤 상태를 해제한다. 제목줄은 남고 화살표로 펼칠 수 있다. 동일 상태 반복 갱신/시설 이동/항해 Tab 지도는 최소화를 다시 강제하지 않는다. 로딩 등 준비되지 않은 상태를 거쳐 도시/항해에 재진입하거나 다른 도시 ID가 되면 다시 접힌다. 전투 후 일반 항해 복귀도 진입으로 취급한다. 기존 X의 프로세스 수명 숨김은 보존하며 자동으로 다시 열지 않는다.

## 근거
- [PlayLocation](../../../Cheats/Interface/PlayLocation.cs): 기존 Speed.VoyageActive와 Bargirls/Contribution.Resolve에서 사용하는 현재 플레이어 일치, SceneManager 준비/장면 및 PlayerPort 체류, OceanScene 전투/SceneStateType 값을 읽는다. 함대 준비 여부나 지도 포커스는 진입 감지에 사용하지 않는다.
- [WindowState](../../../Cheats/Interface/WindowState.cs), [Host](../../../Cheats/Interface/Host.cs), [Contribution](../../../Cheats/Contribution/EntryPoint.cs): 확인된 관리 소스 변경. 새 네이티브 훅·게임 상태 쓰기 없음. Interface 4 / Speed 1 / Contribution 2 유지.
- 현재 GameAssembly SHA256/이동 본문 해시 및 7개 RVA/소유권 대조 통과(evidence/check.py). 신규 네이티브 본문 패치 없음. 상태 관측이 실제 장면 전환에서 예상대로 이루어지는지는 사용자 실행 전 미확인.

## 검증·배포
빌드 0 경고/0 오류. Host 77개 및 항해/공헌도 171개 관리 검사 통과. 초기 접힘, 도시→항해, 로딩→도시, 도시 ID 변경, 동일 장소 펼침 유지, 자동 접기 시 포커스 해제, 기존 X/저장 수명과 숨김 패널 레이아웃을 검사했다. 대역 검사는 실제 게임 UI 검증이 아니다.
