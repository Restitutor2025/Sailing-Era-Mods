# Cheats Interface 1.1.2 — 기본 위치 여백

2026-09-19. 사용자가 왼쪽/하단 게임 정보와 겹침을 줄이되 중앙을 피하도록 요청했다.

WindowState.Place의 최초 위치를 왼쪽 12 → 96, 아래 12 → 84 FairyGUI 좌표 단위로 변경했다. 실제 픽셀 간격은 게임 UI 스케일에 따라 달라진다. 최초 배치 이후 마우스 이동 위치 유지 및 화면 밖 제한은 기존 Move를 그대로 사용한다. 창 높이가 화면을 채우면 화면 안 배치 제한이 우선한다.

확인된 관리 소스 근거: WindowState.Place/Move, Host.OnUpdate의 stage 크기와 스케일된 창 크기 전달 및 SetXY. 네이티브 호출/훅/입력/공유 게임 상태 변경 없음. 도시 이동 후 창 미표시 원인을 고치는 변경은 아니다.

Interface만 1.1.2로 변경하고 AssemblyVersion 1.0.0.0 유지. 실제 게임 참조 빌드 경고 0/오류 0, 기존 Host 수명주기 검사 61개 통과. 게임/Steam 실행·조작 없음. 실제 표시 위치는 사용자 실전 확인 전.

배포 파일: Cheats/releases/1.1.2/Restitutor_Cheats_Interface.dll. 검증 및 설치 해시는 같은 폴더 validation.txt에 기록한다.
