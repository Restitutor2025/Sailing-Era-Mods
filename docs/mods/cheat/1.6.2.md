# Cheats Interface 1.6.2 (2026-09-24)

사용자 보고: 게임을 켠 뒤 첫 새 게임 또는 첫 불러오기에서는 치트 창이 없고, 저장 → 타이틀 → 다시 불러오기 해야 뜸(1.6.1 이전부터).
설치: `Mods\Cheats\Restitutor_Cheats_Interface.dll`, SHA256 `8F78D8BE047F0537E21A4DB8EFA9042EE2E64BEE8DA3EFF7C37EB1263A2303BF`. 이전 1.6.1 (EA03DCC7…) = `Cheats\releases\1.6.1\`.

## 원인 (GameAssembly R11 역어셈블)
- 1.6.1 까지 `Host.Player` 는 훅으로만 채움: `PlayerData.Deserialize` Postfix, `PlayerDataManager.ProcessArchiveInitialize` Postfix. 비움: `Deserialize` Prefix, `WorldPortHoldDB.InitHook` Prefix.
- `ProcessArchiveInitialize`(0x45A490)는 네이티브 직접 호출자 0 — 본문이 `CreateNewArchive`(0x45A370)·`ReadSucceed` 람다(0x532EE0)에 인라인됨 → Postfix 가 돌지 않음.
- 새 게임 `CreateNewArchive`: `PlayerData.GetInstance()`(new PlayerData + InitPlayerData → 각 DB InitHook → Player=null) → `Data` 대입. Deserialize 없음 → Player 가 계속 null → 창 없음. 불러오기를 해야 Deserialize Postfix 가 채움. **증상과 일치.**
- 첫 불러오기: `InitArchive`(0x45A010) → new PlayerData → Data 대입 → 읽기 완료(0x9C4CF0)에서 그 객체 Deserialize. 정적으로는 정상 경로. 실패 원인 후보(미확인): `HandBookManager.readOldDB`(0x260B030)가 별도 PlayerData 로 세이브를 읽어 Deserialize → Player 를 임시 객체로 덮음(1회성 플래그 조건).

## 변경
- 세이브 훅 3개 제거(Deserialize, WorldPortHoldDB.InitHook, ProcessArchiveInitialize). 남은 훅: Core 입력 게이트뿐.
- `SyncSession()`(OnUpdate 맨 앞): `PlayerDataManager.Instance.Data` 포인터가 바뀌면 ResetSession(패널 초기화·위치 초기화) → `Player = Data`. 로그 `Session: current save data changed; cheat panels reset.`
  - `PlayLocation.InGame()`·`Current()` 는 Data 를 다시 읽지 않고 Player 를 씀(SyncSession 이 같은 프레임 앞에서 Player = Data 로 맞춤) → Data 읽기(= Il2CppInterop 래퍼 객체 생성) 프레임당 **1회**(1.6.1 은 2회, 1.6.2 초안은 3회).
  - 세션 초기화(패널 Reset·창 UI 폐기 → 다음 프레임 재생성)는 Data 가 바뀔 때만 = 새 게임·불러오기 시작(로딩 중). 1.6.1 의 Deserialize Prefix 와 같은 작업이라 새 비용 아님.
  - 네이티브에서 `PlayerDataManager.Data`(+0x18)를 쓰는 곳은 InitArchive·CreateNewArchive 뿐(저장·자동저장·삭제·이동 함수는 클로저 필드만 씀). 핫업데이트 코드의 `set_Data` 호출은 정적으로 확인 불가.
- 타이틀·로딩·스토리 장면에서 창 없음(1.6.1)은 그대로. 창 처음 모양(접힘)도 그대로.

## 게임 확인 항목
1. 게임 실행 → 새 게임 → 첫 도시/바다에서 바로 창(접힌 제목줄) 표시. 로그 `Session: current save data changed` 1회.
2. 게임 실행 → 바로 불러오기 → 첫 진입에서 창 표시.
3. 게임 중 저장(수동·자동) 때 `Session:` 로그가 **안** 찍히고 배율 유지(핫업데이트 코드가 Data 를 바꾸는지 확인).
4. 타이틀로 나가면 창 없음, 다른 세이브 불러오면 패널 X1 초기화.
