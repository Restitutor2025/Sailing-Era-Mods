# Cheat 0.3.2 — 항해 지도와 배속 선택 분리

2026-09-19 사용자 요청: 지도 종료 후 비활성 원인 조사, 항해 중 Tab 지도에서는 배율 선택 활성, 도시 Tab 지도에서는 비활성, 수정 후 설치 DLL 갱신. 추론은 허용하되 구분하고 확인 질문을 남긴다.

## 조사 결과

[CONFIRMED: 실행 로그] 설치 0.3.1 해시와 배포본 일치. Latest.log의 10:36:04.188/09.172/15.257에 `활성`, 각각 직후 .219/.196/.279에 `지도·항로 화면 열림` 기록. 이 사유는 CanUse의 VoyageActive 및 일시정지 검사를 통과한 후에만 나온다. 따라서 해당 기록에서는 **게임과 치트 모두 항해 조건을 이미 충족했지만 추가 지도 검사가 차단**했다. 항해 상태 복귀 자체가 실패했다는 주장은 이 로그와 맞지 않는다.

[CONFIRMED: 원본 본문] UIMapCtrl.CloseHook의 해양 장면 분기는 0x5DB834에서 렌더 타입 1을 설정하고 0x5DB85F에서 EnterRenderTextureState를 호출한다. 설치 interop enum `MapRenderCameraType.Little=1`, Big=0 확인. UIMapRenderTextureState.Enter는 0x7B6EE3에서 UIMapModel._isSnapshot(+0xF8)=true, MarkDirty, EnterArea를 호출하고 렌더 카메라를 활성화한다. 지도 종료 뒤 작은 지도 렌더링을 위한 별도 상태로 전환하는 원본 경로다. 일반 UIView.InnerHide의 RemoveChild만으로 지도 종료 수명주기를 설명할 수 없다.

근거: [CloseHook](../../../Cheat/evidence/map-return-0.3.1/UIMap-CloseHook.asm), [렌더 상태 Enter](../../../Cheat/evidence/map-return-0.3.1/RenderTexture-Enter.asm), [EnterArea](../../../Cheat/evidence/map-return-0.3.1/EnterArea.asm). GameAssembly 기준 해시는 0.3.0/0.3.1과 동일하다.

[INFERRED] 위 재사용 경로의 지도 객체가 0.3.1의 IsOpen/onStage/표시 검사에 다시 잡혀 Tab 지도로 오인된 것으로 판단한다. 실제 차단 객체의 타입/포인터/지도 상태를 당시 로그에 기록하지 않았으므로 **특정 객체가 UIMapRenderTextureState였다는 런타임 단정은 하지 않는다.** 다만 추가 지도 판정이 직접 차단한 것은 로그와 소스로 확인된다. 이전 부모 숨김 보강은 이 렌더 상태를 구분하지 못했다.

## 수정 계약

- 배율 버튼 표시/클릭 CanUse는 VoyageActive만 검사한다. 지도 UI 객체 조회 및 일시정지 조건을 여기서 제거한다. 항해 중 Tab 지도/일시정지 화면에서도 X1~X5를 선택·유지한다.
- 실제 FixedUpdate 배율 적용은 별도로 GameManager.IsGamePaused를 확인하고 정지 중에는 쓰지 않는다. 게임을 강제로 재개하지 않는다. 원래 시간·소모 처리 유지.
- 도시 장면/IsStayInPort에서 선택 불가. 항해 종료·입항·전투·로딩·저장 교체 시 X1은 그대로다. 도시 공헌도의 지도 차단 정책은 변경하지 않는다.
- 네이티브 훅은 기존 7개 유지. 신규 지도 수명주기 훅, UI 포커스 변경, 지도/장면/일시정지 상태 쓰기 없음.

## 검증

Release 경고/오류 0, 171개 관리 검사 통과. 0.3.1의 지도·정지 중 선택 차단 10개 검사를 새 요구의 지도 선택/정지 중 이동 차단/복귀 이동 재개/도시 지도 X1 검사 9개로 교체했다. 지도 객체가 계속 표시·열림 상태인 대역에서도 항해 복귀 후 선택과 이동 적용이 유지되는 것을 확인했다. [빌드](../../../Cheat/evidence/build-0.3.2.txt), [테스트](../../../Cheat/evidence/tests-0.3.2.txt), [IL](../../../Cheat/evidence/il-0.3.2.txt). 게임/Steam 실행·조작 없음. 실전 지도 왕복 해결, X배 실제 이동 속도, 외부 모드 병용 결과는 사용자 확인 전이다.

## 나중에 확인할 질문

1. 추론: 지도 종료 후 작은 지도 렌더링이 기존 차단을 재발시켰다. 수정본에서 항해 → Tab 지도 → 종료를 반복해도 배속 버튼과 선택값이 유지되는가?
2. 해석: 항해 중 지도에서 배율을 바꿔도 일시정지된 배는 움직이면 안 된다. 지도 종료 후 선택한 배율로 재개되는가?
3. 도시에서 Tab 지도를 열면 비활성이고, 입항/다음 출항에는 X1로 초기화되는가?

설치 결과와 해시는 [배포 기록](../../../Cheat/evidence/deploy-0.3.2.txt)에 기록한다. 이전 0.3.1 DLL은 releases/0.3.1에 보존한다.
