# Cheats 1.0.0 — 모듈 분리

2026-09-19. 사용자가 지정한 세 DLL로 공통 창/속도/공헌도 기능을 분리하고 기존 단일 DLL을 설치 폴더에서 삭제했다.

## 구현

Interface는 Panel 등록/배치, GRoot 창, 자체 입력 차단, 현재 플레이어 및 저장 수명주기를 소유한다. Speed와 Contribution은 각각 자신의 패널 구현/상태/게임 패치를 소유한다. 각 DLL은 독립 MelonInfo와 Harmony 인스턴스를 사용한다. 두 기능에 MelonAdditionalDependencies(Interface)를 선언하고 프로젝트 참조도 Interface에만 둔다. 상호 기능 참조 없음.

패널 순서는 공헌도 위/배속 아래이며 기존 크기와 정렬을 유지한다. 기능 하나만 설치해도 해당 패널만 표시되도록 구성했다. 뷰 재구축과 게임 세션 초기화를 구분하고, 비활성 패널은 자기 포커스만 해제한다. UI 갱신 예외에서 현재 Player 참조를 잃지 않도록 유지하며 실패한 패널 상태는 초기화한다.

항해 지도에서 배율 선택 유지/변경 가능, 도시 지도 비활성, 항해 종료 X1 조건은 0.3.2와 같다. 실제 이동 중에만 기존 호출 범위 배율을 적용한다. 공헌도는 도시에서 목표값 0~1000을 적용한다. 시간·물자 소모 배율 변경 없음.
