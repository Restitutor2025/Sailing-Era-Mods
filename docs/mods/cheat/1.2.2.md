# Cheats Interface 1.2.2 — 기본 펼침 복원 및 Battle 동봉

2026-09-19. Interface 1.2.2 / Battle 1.0.0. 과거 기록은 보존한다.

## 사용자 실행 보고 및 확인된 원인
사용자 스크린샷은 해상 전투 중 펼친 치트창에 소지금만 표시한다. 첨부 로그에는 Interface 1.2.1 및 나머지 치트 다섯 DLL만 있고 Battle 로드/초기화 기록은 없다. 설치 Mods 하위 DLL 목록을 읽기 전용으로 확인한 결과 Restitutor_Cheats_Battle.dll이 없다. 따라서 이번 보고에서는 전투 모듈 미설치가 확인되며 표시 조건 결함이나 능력 적용의 실전 성공 여부는 판단하지 않는다. [로그 해시·설치 목록·배포 해시](../../../Cheats/releases/1.2.2/validation.json).

## 변경 및 공유 계약
WindowState.Minimized 기본값과 ResetLocation을 false로 복원하고 ObserveLocation에서 자동 최소화를 제거했다. 최초/세션 로드 시 펼침, 도시·항해·로딩 왕복에서는 사용자가 선택한 펼침/접힘 상태 유지. 장소 변경의 포커스 해제는 유지한다. 수동 접기 및 X의 프로세스 수명 닫힘 유지.

확인된 관리 소스 변경이며 새 네이티브 함수·훅·게임 상태 쓰기는 없다. Interface 4개 훅, Panel.Visible/Refresh/Reset/입력 계약과 AssemblyVersion 1.0.0.0을 유지한다. Battle 바이너리는 1.0.0과 동일한 SHA256이며 포격 배율 유지·전투 종료 초기화 정책은 변경하지 않았다. 실전 병용 무충돌을 선언하지 않는다.

## 검증 및 배포
Interface 빌드 0 경고/0 오류. Host 수명주기 80개, Battle 관리 대역 49개 통과. 최초 펼침, 세션 로드 펼침, 장소 전환 시 펼침 유지 및 수동 접힘 유지, 기존 닫힘/포커스/뷰 수명 검증. 게임 UI의 실전 검증은 아니다.

[ZIP](../../../Cheats/releases/1.2.2/Cheats-1.2.2-Battle.zip)에 Mods/Cheats 구조로 Interface 1.2.2와 Battle 1.0.0을 함께 동봉했다. 게임 종료 후 게임 폴더에 Mods를 합쳐 Interface 교체 및 Battle 추가. 다른 기능 DLL 유지. 이번 작업에서는 설치 폴더를 변경하거나 게임/Steam을 실행하지 않았다.
