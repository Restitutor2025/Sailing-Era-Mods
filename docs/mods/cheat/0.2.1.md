# Cheat 0.2.1 — 입력값 상한 자동 보정

2026-09-19 사용자 요청에 따라 GTextInput.onChanged에서 숫자 텍스트가 1000을 초과하면 입력창만 1000으로 바꾼다. 입력 변경 콜백은 Apply/UpdateInfluence를 호출하지 않는다. 기존 적용 버튼만 공헌도를 변경한다.

ClampInput은 숫자 문자열의 선행 0을 제외하고 길이/문자열 비교를 사용하여 int 범위를 넘는 입력도 안전하게 처리한다. 빈 문자열과 1000 이하 값은 유지한다. 값이 달라질 때만 text를 대입해 재진입 시 같은 값 재설정을 피한다. 콜백은 기존 callbacks에 보관하고 창 Clear에서 해제한다.

설치 interop의 GTextInput.get_onChanged 메타데이터 확인. Release 경고/오류 0, 기존 및 상한/빈칸/선행 0/정수 오버플로 입력 검사 총 67개 통과. 컴파일 IL: UpdateInfluence 호출은 Apply 한 곳뿐, 지도 훅/커서 조회 없음. 후킹 대상 6개 및 현재 도시/비활성 UI 정책은 동일하다. 게임 실행 및 실제 키입력/붙여넣기는 사용자 확인 전이다.
