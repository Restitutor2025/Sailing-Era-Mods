# Cheat 0.2.0 — 현재 체류 도시 전용

2026-09-19 사용자 계획 변경. 0.1.3은 중간 빌드만 했고 설치하지 않았다. 현재 버전은 0.2.0이다.

## 동작

PlayerDataManager의 현재 플레이어와 보관 참조가 일치하고, 도시 장면 진입 완료/로딩 아님/IsStayInPort인 경우 StayInPortId만 사용한다. 지도 커서/HarbourIcons/선택 ID를 읽지 않는다. UIManager._alreadyOpenedUICtrls에서 UIMapCtrl, UIMapLineCtrl, UISailLineCtrl, UISailReadyCtrl의 열린 뷰를 확인하면 비활성화한다. 일반 지도도 포함한다. 컨트롤러를 생성하거나 참조를 보관하지 않는다.

비활성 시 마지막 도시/입력 표시를 유지하고 갱신하지 않으며 창 alpha=0.5, 입력 글자 취소선 및 입력/적용을 가로지르는 선을 표시한다. editable/touchable=false, 자체 입력 차단 해제 및 자체 포커스 해제. 다시 도시에서 지도/항로도를 닫으면 활성화한다. 도시가 달라졌으면 입력을 비운다. 적용 순간에도 Resolve를 재검사하므로 화면 전환 전 입력으로 원격 변경할 수 없다. 목표값이 현재값과 같으면 기존처럼 UpdateInfluence를 호출하지 않는다.

미발견 원격 도시 선택 경로 자체를 제거했다. 이미 과거 치트로 바꾼 도시의 공헌도/혜택을 되돌리지는 않는다. Contribution DLL은 변경하지 않는다.

## 훅과 근거

UIMapCtrl 및 UIMapLineCtrl의 Show/Close/Dispose 훅을 모두 제거했다. UIMapLineCtrl.DisposeHook RVA 0x3AA670은 ret 0 본문이며 메타데이터 2695개 함수가 주소를 공유한다. 사용자 출항 충돌 스택의 DisposeHook 객체 변환 접근 위반과 부합하는 위험 요소이나, 실제 충돌의 유일 원인이라고 확정하지 않는다.

현재 훅은 Deserialize, WorldPortHoldDB.InitHook, ProcessArchiveInitialize, BaseObjectData.GetPointProperty/GetProperty, OnEventCaptureInput 6개. check.py는 이제 등록끼리의 중복뿐 아니라 전체 메타데이터의 공유 주소도 거부한다. 기존 검사는 전체 별칭을 놓쳤다.

설치 GameAssembly SHA256 50D53D17829E3E77B9786EA42D998D1AD258F0653846524069F22E5E442EFFCA 재확인. 열린 UI 관련 본문은 Cheat/evidence/open-ui-lifetime.asm에 추출. 기존 지도 네이티브 본문/메타데이터 기록은 보존한다.

## 검증과 한계

Release 경고/오류 0, 기존 입력/보정 격리 테스트 55개 통과. 현재 6개 훅 모두 전체 메타데이터 주소 별칭 없음. 컴파일 IL에서 지도 수명주기 훅·커서 조회 부재 및 현재 체류 ID 조회 확인. UpdateInfluence 호출 지점은 Apply 하나뿐, 직접 공헌도 쓰기 없음.

게임/Steam 미실행. 투명도/취소선, 지도와 도시 전환, 출항 충돌 해소는 사용자 실전 검증 전이다. 확인 순서: 도시에서 적용 → 지도/항로도 열어 비활성 확인 → 닫아 활성 확인 → 출항 → 도시 재입장. 항해/지도 중 커서로 도시명이 바뀌거나 적용되지 않아야 한다.
