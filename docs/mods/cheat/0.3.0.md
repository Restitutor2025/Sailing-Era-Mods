# Cheat 0.3.0 — 항해 이동 배율

2026-09-19. 사용자 요청: 치트창 X1/X2/X3/X4/X5, 항해 중에만 조작·적용, 게임 시간/물자 소모 배율 유지, 항해 종료 시 X1. 추론을 확인 사실로 사용하지 않는다.

## 구현

- 기존 도시 전용 공헌도 0~1000 및 입력 상한 보정 유지. 창을 공헌도/항해 두 구역으로 나누며 각자 alpha 0.5·취소선·touchable 제한을 적용한다.
- 현재 PlayerData 일치, 해양 장면 진입 완료, 로딩 아님, 체류 도시 아님, SceneStateType.Sailing, IsInBattle=false, 현재 포커스 함대 isPlayer 및 State.Free 조건을 모두 확인한다. 버튼 클릭 및 이동 훅에서도 재확인한다.
- 지도/항로/출항 준비 UI 또는 일시정지 중에는 조작과 효과를 중지한다. 지도/일시정지만으로 선택값을 초기화하지 않는다.
- 항해 조건 종료, 입항 EnterPort, 전투, 장면 전환/로딩, 저장 로드/초기화, 종료 시 선택값 X1. OnUpdate와 이동 Prefix에서 확인한다. 다음 항해에 배율을 자동 승계하지 않는다.
- 현재 포커스 플레이어 함대 소속이며 boatState.DependOnTeam인 배만 대상이다. FixedUpdate 호출 중 forwardPowerFactorByEscape에 선택 배율을 곱하고 Finalizer에서 복원한다. 원본 호출을 차단하지 않는다. 원본 예외도 억제하지 않는다. 다른 코드가 해당 필드를 별도 값으로 변경했으면 그 값을 덮어쓰지 않는다.
- 게임 시간, 물자 소모 함수, 저장 속도 속성, 최대속도 템플릿에는 쓰지 않는다. 항해 배율을 저장 파일에 기록하지 않는다.
