# Cheats 1.1.0 — 이동 가능한 집합 UI

2026-09-19. 사용자 사진의 남색/금색 게임 UI 분위기에 맞춰 세 DLL의 표시를 변경했다. 래스터/GImage/Texture2D/사용자 Material을 추가하지 않고 기존 GGraph/GTextField 방식으로 그린다. Contribution 혜택 모드의 이미지 shader/clip 속성 오류 경로를 사용하지 않는다. 동일 오류가 절대 발생하지 않는다는 실전 보장은 아니다.

## 모듈 계약

Interface는 기능 독립적인 집합 창과 공통 스타일만 담당한다. 공헌도/항해 모듈명 분기·고정 탭 없음. 기존 Register(Panel), Unregister(Panel), Order, Height 계약으로 등록 패널을 배치하고 기능 추가/제거 때 재배치한다. 길어지면 우측 스크롤바를 드래그하여 전체 패널에 접근한다. 기존 320 단위 폭을 유지한다.

Contribution DLL은 자신의 공헌도 패널/입력/적용을 소유한다. 도시명과 현재값 한 줄, 목표값/적용, 결과 안내를 공통 색상/버튼 스타일로 정리했다. Speed DLL도 자신의 배율/활성 조건/패널을 소유하며 선택된 배율을 금색으로 표시한다. 둘 다 Interface의 protected 스타일 도우미만 사용한다. 게임 기능 계산은 변경하지 않았다.

Interface의 AssemblyVersion은 기존 기능 참조와 호환되는 1.0.0.0, FileVersion/Melon 표시 버전은1.1.0이다. 새 기능 DLL의 추가 스타일 API 때문에 세 DLL을 함께 배포한다. 기능 간 상호참조 없음.

## 창 동작

- 제목줄 드래그로 전체 창 이동, 창이 화면 밖으로 나가지 않게 제한. 시작 위치는 왼쪽 아래.
- ∨는 제목줄만 남기고 전체 최소화, ∧로 복원. 개별 기능 상태/선택 배율은 초기화하지 않는다.
- ×는 현재 프로세스에서 공통 창 전체를 숨긴다. 재열기 단축키 없음. 저장 로드/도시 이동/패널 등록으로 다시 열리지 않는다. 새 게임 프로세스에서 초기화된다.
- 위치/접힘/닫힘은 WindowState에 별도 보관하며 Player Reset에서 지우지 않는다. 저장 파일에는 쓰지 않는다.
- 숨겨진 패널도 Refresh를 유지하여 기존 항해 상태 전환/X1 초기화 등이 중단되지 않는다. 접기/닫기는 이미 적용된 치트를 되돌리지 않는다.
- 공통 제목줄은 기능 패널이 모두 비활성이어도 조작 가능. 숨기기 때 자체 포커스를 해제하고 클릭 직후 입력 차단을 유지한다. UIManager 포커스를 교체하지 않는다.

## 검증과 한계

설치 1.0.0 세 DLL과 기존 빌드 해시가 모두 일치함을 확인한 뒤 수정했다. 배포 전 파일은 Cheats/releases/1.0.0/installed-before-1.1.0에 백업한다.

빌드 경고/오류0. 기존 기능 검사171개, Host 실제 소스의 관리 대역61개 통과. 후자는 임의 이름의 추가 패널/긴 내용 스크롤, 드래그, 전체 최소화/복원, 로드 후 위치/접힘 유지, X후 로드/추가 등록에도 닫힘 유지, 포커스/해제/오류 격리를 포함한다. 원본7개 대상(4+1+2)/GameAssembly baseline 및 IL 기능 소유권 검사 통과. 기능 로직/원본 훅 추가 없음.

게임/Steam 실행·조작 없음. 실제 폰트/드래그/스크롤/다른 모드 입력 병용은 사용자 실행 전 미확인. 특히 우측 스크롤은 패널이 화면 높이를 넘는 경우만 나타난다. DLL 재실행 후 제목줄 이동, ∨/∧, 적용/배율 선택, X후 로드해도 미표시를 확인한다.

배포 위치 Mods/Cheats의 Restitutor_Cheats_Interface.dll, Restitutor_Cheats_Contribution.dll, Restitutor_Cheats_Speed.dll. 해시는 Cheats/releases/1.1.0/validation.txt.
