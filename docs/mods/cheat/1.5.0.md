# Cheats Interface 1.5.0 + Skill 1.0.3 — O 전체 끄기/켜기

2026-09-21. 사용자 요청: O로 치트 전체 끄기/켜기, H는 기존 접기/펼치기. 사용자 결정: 끄기 = 창 숨김 + 치트 효과 해제, 유지 범위 = 게임 종료 전까지(장소 이동·세이브 불러오기에는 유지, 재시작하면 켜짐).

## 동작
- O 누름 가장자리에서 `WindowState.CheatsOn`(기본 true, 프로세스 수명) 반전. 길게 눌러도 1회. 앱 비활성·FairyGUI 텍스트 입력 중에는 무시하고, 나중에 늦게 적용하지 않는다. Player 없이도(타이틀 등) 전환 가능.
- 끄기: 포커스 해제 → 등록된 모든 패널 `Reset()` 1회 → 창 제거. 꺼져 있는 동안 창을 만들지 않고, 패널 Refresh를 호출하지 않고, 입력 캡처 훅은 게임 입력을 막지 않고, H는 무시한다.
  - Speed: Multiplier=1. Battle: Choice X1, 항해사 능력·포탄 lease 복원. 입력 UI가 없으므로 꺼진 동안 X1 유지.
  - Skill 1.0.3: `LevelGetSkill` 후처리와 10레벨 버튼 추가 지급이 `Host.CheatsOn=false`이면 원본 값/동작 그대로. 저장된 간격 설정(skill.v1.json)은 바꾸지 않으므로 다시 켜면 그 설정이 적용된다.
  - 공헌도·소지금·경험치·인물·여급·아이템: 버튼 1회 적용형이라 되돌릴 지속 효과가 없다. 이미 세이브에 쓴 값은 되돌리지 않는다.
- 켜기: 창 복원(H 접힘/펼침 상태 유지, × 로 닫았던 창도 다시 보임). Speed/Battle 배율은 X1에서 다시 고른다.

## 호환
- `Host.CheatsOn` 공개 속성 추가(가산 변경). Speed·Battle·Contribution·Money·Bargirls·Exp·Character·Items는 재빌드 불필요.
- Skill 1.0.3은 `Host.CheatsOn`을 참조하므로 Interface 1.5.0과 함께 설치. 새 네이티브 훅 없음(Interface 4개, Skill 4개 그대로).
- O 키: 설치 metadata `GameInputControls`/`DefaultInputActions` 기본 키보드 바인딩에 O 없음(Debug 맵 포함). 작업 폴더 모드 소스의 직접 O 사용 없음. 하드코딩 키 읽기·외부 모드는 미확인.
