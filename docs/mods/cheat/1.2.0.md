# Cheats 1.2.0 — 장소별 패널 숨김

2026-09-19. Interface 1.2.0 / Speed 1.1.1 / Bargirls 1.1.1.

항해 속도는 기존 SailingSpeed.CanUse 항해 조건이 참일 때만 표시한다. 항해 중 Tab 지도/일시정지는 기존처럼 선택 가능하며, 도시·전투·입항·로딩 등 기존 항해 조건 밖에서는 패널 전체와 배치 공간을 제거한다. 항해 종료 X1 초기화와 실제 정지 중 이동 배율 쓰기 차단은 유지한다.

여급은 기존 Resolve의 플레이어/장면/항구 체류 조건을 IsInCity로 추출해 표시 경계로 재사용한다. 도시에서는 기존 여급 없음/술집 밖 취소선, 최대 단계·현재 여급 퀘스트·과제 상한 제한을 유지한다. 도시 밖에서는 패널을 숨긴다.

Panel.Visible 기본값 true로 기존 기능 호환성을 유지한다. Host는 Refresh를 숨김 중에도 실행하며 표시 대상만 높이에 합산한다. 숨김 시 자기 포커스 해제, 스크롤 범위 재계산. 패널 뷰를 폐기하거나 세션을 초기화하지 않는다. 새 훅/게임 상태 쓰기 없음. 기존 Interface 입력/수명주기 4개, Speed 1개, Contribution 2개 계약 유지.
