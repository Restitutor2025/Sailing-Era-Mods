# Stat Rank 0.1.1 ~ 0.1.4 — 등급 호버 표 복구 · 첫 열기 NRE — 2026-09-21

DLL: `Restitutor_Additional_Stat_Rank.dll`. 소스 `StatRank/src/EntryPoint.cs`. [현재 상태](CURRENT.md) · [패치 목록](PATCHES.md).

## 증상 (사용자 보고, 0.1.0)
1. Tab 인물 창을 처음 열 때 `NullReferenceException at UICharacterView.get_Physical` ← `EntryPoint.AfterRoleInfo`.
2. 능력치 제목 옆 등급 글자(S~D)는 보이지만 마우스를 올려도 확률 표가 나오지 않음.

## 원인
### 1. NRE [원본 GameAssembly R11 objdump — 소스 확인]
- `get_Physical`(RVA 0x1020780) = `this+0x90 → +0x258 → +0x2E8` = `_UIContent(UICharacterMain).roleInfo(Character.UICom_RoleInfo).physical`. 중간 null이면 NRE.
- 원본 `RefreshTipsRoleInfo`(0x102B460)는 `[this+0x90]==null`이면 즉시 return(0x102B517 → 0x102BFB0). Harmony Postfix는 그래도 실행되어 검사 없이 `Physical`을 읽었다.
- 첫 열기 1회 발생, 원본도 그 호출에서 아무것도 하지 않으므로 상태 피해 없음.
- `Fail()`은 같은 메시지를 다시 기록하지 않는다. 로그 1줄 = 1회 발생이라는 뜻은 아니다.

### 2. 호버 [0.1.1 `[HoverTrace]` 실행 로그 — 확정]
- 후보: A) 글자 미생성 B) 다른 터치 객체가 히트 대상 C) 팁은 생기나 안 보임. 글자가 보여 A 제외.
- 글자 C·A·A·S 위 4회 모두 `hit=[GGraph('btnReturn') <- UISheetCharacter('character') …]`, `rollOverFired=False` → **B 확정**.
- `UISheetCharacter.btnReturn`은 시트 전체(1600×900 기준 (0,218)-(1600,887))를 덮는 touchable GGraph. 등급 글자는 `UICharacterMain → roleInfo → physical…` 아래라 FairyGUI 히트 테스트가 글자에 onRollOver를 보내지 않는다. Tab Characters 0.6.2(장비 슬롯)·0.6.8(언어 줄) 클릭 가로챔과 같은 구조.
