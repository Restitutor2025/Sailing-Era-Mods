# Stat Rank 0.1.4

DLL: `Restitutor_Additional_Stat_Rank.dll`. [상세](0.1.4.md) · [패치 목록](PATCHES.md).

Tab 인물 시트의 능력치 제목 5개(체격·감각·기술·지식·매력) 뒤에 Hero 템플릿 성장 등급(S~D) 글자를 붙이고, 글자 위에 커서가 있으면 레벨업 +2/+1/+0 확률과 레벨당 평균을 표(alpha 0.7)로 보인다. 읽기 전용: 게임 상태·세이브를 쓰지 않는다. GameAssembly 해시가 기준과 다르면 비활성.

호버는 FairyGUI 이벤트가 아니라 커서 좌표 폴링이다(btnReturn이 글자를 덮음). 0.1.4 빌드·로드·호버 표시 인게임 확인(2026-09-21). 다른 해상도·장비 패널이 글자를 덮은 상태의 차단은 미확인.
