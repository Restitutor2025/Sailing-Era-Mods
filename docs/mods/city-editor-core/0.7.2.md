# Core 0.7.2 — 셀레네 상세 UI·알파·취소 입력·시작 함선

2026-09-23. 격리 준비본. 게임/Steam 실행 및 main 수정 없이 준비했다. 0.7.1 시설 진입 성공은 사용자 보고이며, 아래 0.7.2 개선은 실제 게임 확인 전이다.

## 변경

- 원본 UIcompCreateRole을 별도 생성해 소개·재능 아이콘/설명·버튼 레이아웃을 사용한다. 원본 컨트롤러/5명 배열에 신규 인물을 넣지 않는다. 자체 모달의 포커스/생명주기 및 PNG 흑백→컬러 페이드는 유지한다. 컬러 전환 완료 시 흑백 레이어도 숨겨 알파 중첩을 없앤다.
- 원본 두 PNG는 RGBA지만 모든 알파가255였다. 사용자 승인에 따라 원본을 보존하고 별도 transparent-v072 사본에서 알파만 변경했다. RGB 동일, 공통 알파 마스크, alpha0 픽셀273593개·중간값589424개. 원본의 브러시 셰이더를 재현한 것은 아니다.
- OnAction_B/ReturnToMenu Prefix는 자체 상세 화면과 취소 입력 해제 대기 동안 같은 컨트롤러의 메뉴 복귀를 차단한다. 동일 입력이 해제되고 최소 다음 프레임이 지난 후 UIAgent를 복원한다. 다른 컨트롤러/일반 화면에는 원본 실행. 중복 취소 무시, Hide/Dispose/OnDisable에서 대기 참조 정리.
- 선택 옵션 startShip=110: 새 게임의 첫 지정 항구 진입에서 기함이 없을 때만 PlayerShipHold.AddFlagShip(110,156)을 호출한다. 일반 슬루프이며 셀레네를 선장으로 지정한다. 기존 저장 로드/다른 주인공/기함 보유에는 지급하지 않는다.
- MainHero.DefaultCoin=5000. 원본 화폐 초기화 경로 사용. 추가 선원/식량은 지급하지 않으며 필요 선원18명은 항구에서 고용해야 한다.
- 소속 표시는 로마 제국. 발견한 creation_name_01 그림의 실제 문구는 '셀레네 / 로마'였다. 사용자 요청에 맞춰 편집 가능한 이름표와 새 전용 RoleCountry 문자열로 설정했다. 해당 그림에 '로마 제국'이 있었다고 해석하지 않는다. 기존 인물/국가 표는 변경하지 않는다.
- 시작 설정 exporter는 설치된 startShip을 보존하고 문서의 DefaultCoin을 반영한다. 케페253/Facility0/이벤트0/기존 해금/사용자 좌표는 유지한다.
