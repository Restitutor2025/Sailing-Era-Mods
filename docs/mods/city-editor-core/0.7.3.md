## 확인한 원인과 수정

- 원본 UICreateRole_fui.bytes를 설치 번들에서 복호화해 실제 계층 확인. groupCharacterSelect(44) → groupAttribute(32) → groupTex(21)/groupSelect(31). 0.7.2가 groupCharacterSelect.visible=false로 설정해 설명·재능·버튼을 모두 숨겼다. 해당 조상 표시와 alpha 복원. 원본 좌측 음영 이미지 n34(src q3fkn, 1628x1440, 기본 alpha0) 표시. 별도 균일 검정막 제거. 원본 파일/자산을 생성하거나 교체하지 않는다.
- Space가 자체 onKeyDown에 누락돼 있었다. Space/Enter/키패드Enter 연결. 원본 OnAction_A도 자체 상세가 소유할 때 동일 확인에 연결한다. 기존 _starting으로 중복 생성 방지.
- 좌우 이동 때 native UICreateRoleView.Refresh IndexOutOfRangeException 실제 관측. 자체 상세를 열어도 원본 5인용 방향 입력을 막는 Prefix가 없었다. OnAction_LeftAxis_And_DPadLeft/Right는 자체 상세/취소 해제 대기 중에만 차단한다. 추가 인물은 원본 5칸 배열에 넣지 않는다. 셀레네 상세에서 좌우로 다른 인물을 고르는 기능은 제공하지 않으며 지도에서 다시 고른다. 원본 5인 화면은 기존 동작 유지.
- MainHero156.DefaultOpenFunction에 기본 메뉴1~10 추가. 원래 함대3/갑판4/장비7/선창9는 자동 해금됐지만 지도1/임무2/인물5/스킬6/가방8/지식10은 실제 도착 로그에서 닫혀 있었다. 기존 시설 목록, 슬루프110, 5000, 케페253, Facility0, 이벤트0 유지. 새 게임 적용이며 기존 저장 상태를 강제 변경하지 않는다.
