# Core 0.7.5 — 새 주인공 이름표 등장 시점

2026-09-24. 빌드 및 설치 입력 검사 통과, 설치·게임 실전 확인 전.

## 근거

- 사용자 영상 `bandicam 2026-09-24 14-06-51-543.mp4`: 약 5.5~6.5초 지도 등장 중 셀레네/로마 제국만 표시되고 약 7초에 원본 이름표 등장. 재진입에서도 반복. 캡처: `analysis/hero-stage2/label-timing-20260924/`.
- 원본 UI 패키지 해독: btnCharacterYunMu(index60)는 visible=1, alpha=1이지만 groupBtnCharacter(index62, visible=0)에 소속. 해당 그룹은 groupRole(index63)에 소속된다.
- 확인된 소스 오류: TryBuildButtons는 버튼 프리팹을 생성하여 같은 부모에 추가하지만 외부 UI 패키지가 설정하는 group을 복사하지 않았다. 버튼 자체 visible만 복사하므로 그룹 숨김이 적용되지 않았다. 단순 알파 지연 문제와 구별된다.
- 설치 GameAssembly SHA256 `50d53d17829e3e77b9786ea42d998d1ad258f0653846524069f22e5e442effca` 재확인. GObject.set_group(RVA1A4CA40), HandleVisibleChanged(RVA1A4E420) 본문에서 그룹 지정 시 표시 갱신 및 그룹의 internalVisible2 적용 확인. 관련 asm은 analysis/hero-stage2/native에 보존.

## 수정 및 계약

TryBuildButtons에서 추가 버튼의 group을 원본 버튼의 group으로 지정한다. 원본 그룹을 직접 표시하거나 숨기지 않는다. 기존 상세 창 SelectIndex/선택 상태에 따른 개별 visible 제어와 Dispose 수명은 유지한다. 새 후크·입력 소비·타이머·프레임별 계측 없음. 원본 이름표 그룹 멤버가 추가되는 만큼 FairyGUI의 그룹 경계 갱신 대상에 포함된다. 그룹 위치·배치를 수정하는 다른 모드와 병용 실전은 미확인.
