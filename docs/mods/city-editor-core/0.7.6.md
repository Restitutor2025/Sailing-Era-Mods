# Core 0.7.6 — 셀레네 상세 글자·키 아이콘

2026-09-24. 빌드 경고0/오류0, 설치 CheckOnly 통과. 실제 게임 미실행·미확인.

## 확인한 근거

- 사용자 비교 스크린샷: 셀레네 이름·소속이 원본 윤무보다 흐리고, 돌아가기/확인 버튼의 Esc/Space 아이콘이 없다.
- 소스 SelectionText의 색상은 (.96,.91,.8,1), 약 #F5E8CC. 원본 UI 패키지 compNameChinese.texName 및 compNameEnglish.texPlace의 RGBA는 (228,255,255,255), #E4FFFF. 따라서 같은 색상도 순백색도 아니었다. 원본 크기는 80/60이다.
- 기존 자체 글자는 BuildCreationArt 안에서 생성돼 이후 생성하는 NativeDetails보다 아래에 있었다. 이미지 배경 및 음영과의 합성은 스크린샷 색상 인식에 영향을 줄 수 있으므로 픽셀 육안만으로 실제 알파를 확정하지 않았다. 기존 tween 목표 알파는1이었다.
- 원본 UIbtnSelect는 loaderIcon을 포함하지만 새 UIcompCreateRole 생성만으로 입력 모델 연결을 수행하지 않는다.
- 설치 원본 UICreateRoleCtrl.InitHook(RVA7F3BC0)에서 IconUtils.GetInputKeyIcon으로 model.iconConfirm(offset28), iconReturn(offset30)을 채우는 본문 확인. 메타데이터와 해당 asm은 analysis/hero-stage2/native에 보존.

## 변경

원본 UIcompNameChinese/UIcompNameEnglish를 생성하여 글자만 셀레네/설정 소속으로 교체. 원본 색상·글꼴·이름/소속 크기 비율을 재사용하고 Shrink로 긴 이름을 수용한다. 이름 영역은 모달 root의 최상단에 배치하여 설명 패널 음영에 가리지 않게 한다. 기존 지연 fade-in은 유지한다.

버튼은 원본 loaderIcon의 URL/texture·배치·색상·채우기 설정을 사용한다. 로더가 비어 있으면 이미 초기화된 원본 모델 iconReturn/iconConfirm을 사용한다. 새로운 키 그림을 그리거나 입력 바인딩을 바꾸지 않는다. 원본 텍스처는 소유·폐기하지 않는다.

새 후크 없음. 이름 컴포넌트는 자체 모달 소유로 root Dispose 때 해제되고 기존 tween 정리를 유지한다. 기존 0.7.5 이름표 그룹 수정 포함. 게임 데이터·출항·시작 대화 무변경. 다른 UI 모드와 병용 실전은 미확인.
