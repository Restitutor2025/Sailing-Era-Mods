## 변경

- 현재 프레임의 donor/extra 받침을 같은 카메라와 FairyGUI WorldToLocal(Vector3,Camera)로 변환한다. 원본 위치 변경도 현재 부모 변환 기준으로 계산한다. 버튼 크기/스케일 동기화, texPlace/texName 가운데 정렬.
- 기본 지도(SelectIndex0)에서만 추가 이름표를 표시한다. 원본 인물 클릭 즉시 숨기고 Refresh에서 상태를 동기화한다. 셀레네 패널 동안 원본 UIContent를 숨기며 취소 시 기존 상태를 복원한다.
- 준비된 흑백/컬러 PNG를 읽어 카메라 이동 후 색을 페이드 인한다. 원본 브러시/마스크 셰이더와 동일한 연출은 아니며 비율 유지·닫을 때 자체 tween/texture 해제. zoomImage는 지역 지도 그림이라 인물 그림으로 덮지 않는다.
- ShowHook에서 view를 다시 획득하고 Hide/Dispose/ManagerDisable에서 추가 버튼을 폐기한다.
- 신규 주인공의 첫 HarbourScene.OnEnter Prefix에서 해당 주인공/시작항구가 일치할 때만 설정된 DefaultOpenFunction을 원본 SetFunctionOpen으로 보완한다. 이미 열린 기능은 건너뛰며 다른 기능을 닫지 않는다. 기존 저장/기존5명에는 적용하지 않는다. 원본 항구 UI 생성 전에 수행한다. 설정값의 누락 원인을 확정한 패치가 아니라 스토리 없는 시작 경로의 명시적 설정 적용이다.
- 진단은 configured-functions와 실제 OpenFacilityList 원소를 출력한다(이전 string.Join은 IL2CPP List 형식 이름 출력).
- 새 도시 생성 시 원본 PortFacility의 donor와 같은 Tid의 Wharf를 복제한다. 누락/충돌은 검증 오류. 현재 바르나900 적용 데이터는 donor14501의 Wharf를90001로 추가하는 한 연산만 보완한다. 예외를 삼키거나 도시 초기화를 건너뛰지 않는다.
