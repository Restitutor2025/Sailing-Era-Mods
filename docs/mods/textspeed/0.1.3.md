# Restitutor_fixes_textspeed.dll 0.1.3
## 목적과 버전 변경 근거
대화 텍스트를 원래 속도 또는 즉시 표시로 선택하고 선택값을 유지하는 모드다. 0.1.3 번호는 소스와 DLL에서 확인되지만, 직전 버전의 정확한 장애 보고·변경 목록은 보관 자료에서 확인하지 못했다.
## 현재 구현
- 설정의 RunningInBackground 행 바로 위에 텍스트 출력 / 느리게 / 빠르게 선택 UI를 삽입한다.
- 행 풀링 재렌더링 전에 높이·자식 위치를 복원하고, 크기 0인 행은 LateUpdate에서 배치를 재시도한다.
- 느리게는 원래 동작, 빠르게는 등록된 대화 본문·방백·좌/중/우 말풍선의 타이핑만 원래 Cancel로 완료한다.
- StartEffect에서 교체된 효과 객체를 다시 등록한다. 문장 시작 때 모드를 읽으며, 완료 대기 중 콜백이 달라졌거나 창이 닫히면 건너뛴다.
- 다음 대화로 자동 진행시키지 않는다. 처리 오류 시 중단하고 중복 Harmony ID 설치를 거부한다.
## 저장
게임 UserData/Restitutor/textspeed.v1.json. 기본 Slow, schema=1, slow/instant와 SHA256 체크섬.
명시적 설정 선택만 저장하며 동일 값 선택은 재기록하지 않는다. 임시 파일과 File.Replace, .bak을 사용한다.
외부 변경은 덮어쓰기를 거부한다. 원본 손상 시 유효 백업값을 읽기 전용으로 보여주고 기능/변경을 제한한다. 손상 파일을 자동 초기화하지 않는다. 게임 세이브와 별도다.
## 근거와 검증 범위
[EntryPoint](../../../TextSpeed/src/EntryPoint.cs), [TextSpeedModule](../../../TextSpeed/src/TextSpeedModule.cs), [OptionsRow](../../../TextSpeed/src/OptionsRow.cs), [ModeStore](../../../TextSpeed/src/ModeStore.cs).
독립 저장 테스트 소스는 신규 기본값·재시작 유지·백업·반복 변경·손상·외부 수정 거부를 검사한다:
```powershell

```

## 사용자 확인 / 유지 지침
설정 행 중복·겹침, 재시작 후 모드 유지, 대화/방백/말풍선 즉시 표시와 다음 대화 입력을 확인한다.
합칠 때 독립 MelonMod EntryPoint만 제외하고 모듈 초기화/LateUpdate/종료 호출을 연결한다. 저장 경로와 HarmonyId를 바꾸지 않는다.
출력: TextSpeed/bin/Release/net6.0/Restitutor_fixes_textspeed.dll.
