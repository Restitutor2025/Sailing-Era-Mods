## 수명주기·공유 상태
Start는 열기/닫기/거절도 포함하므로 request와 ShowChild의 실제 탭/호출을 구별한다. 중첩 요청은 현재 창에 포함하고 독립 요청은 이전 창을 요약한 뒤 새 창으로 전환한다. 세션별 span stack은 게임 스레드에서만 접근한다. 예외는 Finalizer에서 계측 stack만 복원하고 원래 예외를 그대로 반환한다. Postfix/Finalizer 중복 종료를 방지한다.
게임 참조는 해당 훅 인스턴스에서 읽으며 UI 싱글턴을 새로 생성해서 조사하지 않는다. 모델 Count/기존 UI 포인터의 읽기만 수행하며 배경 큐에는 값 스냅샷만 전달한다. 핸들러 실패 시 기록만 비활성화한다.
원래 동기 호출 시간은 자기 훅의 전후 스냅샷/기록 비용을 제외하지만 중첩 훅의 부하는 포함한다. renderer는 개별 시간/로그 없이 횟수만 합산한다. UI 렌더/게임 상태 완료 시각을 판정하지 않는다.
관측 창 제한과 파일/큐 제한, 첫 관측의 의미 및 포함/잔여 시간의 한계는 사용법 참조.
