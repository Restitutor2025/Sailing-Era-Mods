## 원본 근거 [본문/표] (GameAssembly 50D53D17…, table 8be62de8…)
- 등급 = `Gyyx.Template.Hero` phycGrowth/percGrowth/craftGrowth/knowGrowth/chamGrowth (1=S…5=D). PlayerRoleData·FB 세이브에 growth 필드 없음(native-fields 전수 검색).
- `TemplateManager.GetItem` 0x3CB800 = 정적 Dictionary<int,Item> 조회. 인터롭 정적 필드 `_item`, `_itemType`, `_hero`, `_textLib`, `_textLib_English/_Japanese/_ChineseTraditional`.
- `Item..ctor(FbsTemplate.Item)`만 있음 → il2cpp_object_new로 할당 후 필드 직접 설정.
- 한국어 = 기본 TextLib(chunk 196: Item_Name_36000 = 휴대용 등불). `TextLibUtils.Text` → `LanguageManager.GetTextContentById`가 언어별 표 선택.
- 가방 사용 버튼 = ItemType.canUseInBag + `UIBagCtrl._itemUseCallbackDict`(type 키). 이번에는 쓰지 않음(canUseInBag=false).
- `PlayerRoleData.Deserialize` 0x678940: ListSkillBooks = FB 목록을 항등 Select(b__130_0 0x533AA0, 3바이트)로 복사 → 모르는 id도 보존. Serialize b__129_2도 항등.
- ListSkillBooks(+0x68) 뒤 `List<int>.Contains`(0x8C8C0) 호출자: PlayerHoldRoleDB.UpdateRoleSkillLevel, UICharacterCtrl.OnClickBtnBook, GetBookStateByParam, PlayerRoleData.IsSkillBookUsed → 모두 실제 스킬북 id로 질의. 990001~5는 스킬북 id가 아님. **Contains 외 순회·Count 사용처는 전수 확인하지 못함 [미확인].**
- `OnClickBtnBook`: 학습 시 ListSkillBooks.Add(0x94BFEE) → MarkDBDirty(0x94BFF8). 같은 순서를 따름.
- `PlayerBagDB.AddItem(int,int,bool)`/`RemoveItem(int,int)`/`GetItemAmount(int)`.

## 저장·복원
- 기록: 열매 1개 = 해당 항해사 ListSkillBooks에 열매 tid 1개. 적용값 = max(1, 원래값 − 개수).
- 원래값: 처음 건드릴 때 템플릿 값을 저장(프로세스 동안). 다른 세이브/새 게임 로드 시 기록 없는 영웅은 원래값으로 복원.
- 모드를 빼면: 기록은 세이브에 남고 등급은 원래 표 값(효과 사라짐). 다시 넣으면 복원.
- 선원(IsSeaman) 제외.
