## 변경
- 항해사의 등급 글자 클릭이면 보유 수·등급과 관계없이 패널을 연다(선원·글자 밖은 원본 그대로).
- 패널: 제목 "○○ 성장 등급 X", 아이템 칸(원본 프레임 iconDeck + 아이콘, `Core.NewUISystem.MyGLoader` = 게임 자체 로더, 보유 0이면 아이콘 흐리게), "xN", 아이템 이름, 상태 줄:
  - 사용 가능: "C → B" + [사용] (사용 후 패널을 새 값으로 다시 그림, 원본 알림 유지)
  - 보유 0: "보유한 ○○ 악마의 열매가 없습니다."
  - S: "○○ 성장 등급이 이미 S입니다."
- 위치: 글자 오른쪽, 화면을 넘으면 왼쪽, 세로 가운데, 화면 안으로 제한. sortingOrder 32100. 패널 밖을 누르면(좌·우 클릭) 닫힘. 0.1.0의 가운데 확인창·어두운 차단막 제거.
- Bind: 시트 content가 없으면 연결을 다음 새로고침으로 미룸(NRE 제거).
- Templates: 이미 넣은 행도 원본 행(1000, 23207)이 생기면 분류 아이콘·프레임·무게를 원본 값으로 갱신.
- 이전 소스: `DevilFruits/archive/0.1.0/`.

## 확인 수준
클라우드에 dotnet 없음: 컴파일·테스트·실전 미실행. `MyGLoader()` 생성자·LoadExternal(ResourcesManager.LoadAssetAsync) 존재는 native-map으로 확인, 인터롭 네임스페이스 `Il2CppCore.NewUISystem`은 기존 모드 관례(Il2CppCore.InputSystem)로 추정.
