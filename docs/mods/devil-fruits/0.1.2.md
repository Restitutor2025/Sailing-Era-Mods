# Devil Fruits 0.1.2 — 2026-09-21 (빌드·실전 미확인)

## 사용자 보고 (0.1.1 실전 스크린샷, 설치본 SHA256 앞 16자 6926C74C028E497A)
- 0.1.1 패널이 그려짐(아이콘·x0·"보유한 신체 악마의 열매가 없습니다." 표시 확인 → MyGLoader 아이콘 로딩, 보유 0 안내 동작).
- 문제: 등급 글자가 화면 오른쪽 속성 열에 있어 패널이 글자 왼쪽으로 가고, 같은 자리에 뜨는 Stat Rank 호버 팁과 겹침.

## 사용자 결정
- 열매 패널을 **랭크 팁 바로 아래**에 붙인다.
- (검토 근거: 글자 오른쪽~화면 끝 약 360px(2560 기준), 패널 약 640px → 오른쪽 배치 불가.)

## 변경
- 위치만 변경. GRoot 자식 `RestitutorStatRankTip`(Stat Rank 팁)이 보이면: 패널 오른쪽 끝 = 팁 오른쪽 끝, 패널 위쪽 = 팁 아래 + fs*0.3. 아래 공간이 없으면 팁 바로 위. 팁이 없으면 글자 왼쪽·세로 가운데(Stat Rank 팁과 같은 기준). 화면 안으로 제한.
- 이전 소스: `DevilFruits/archive/0.1.1/`.

## 사용자 확인
① 신체~학식 행: 팁 아래에 겹치지 않게 ② 매력(맨 아래) 행: 공간이 없으면 팁 위 ③ 커서를 글자에서 떼면 팁은 사라지고 패널은 그대로(의도).
