# 지도 현재 상태 — 0.1.5
후속 [미구현 설계](DESIGN.md): 항로 계획 종료 시 작성 중인 경유지를 원본처럼 초기화하는 규칙을 사용자 확인으로 확정. DLL 변경 없음.
사용자 실전 검증 후속: 안내한 모든 테스트를 끝냈으며 지도 모드는 정상 작동하는 것 같다고 보고했다. 이는 사용자 종합 결과이며 개별 항목의 로그/영상 재검증이나 모든 조건의 무결함 보장은 아니다. 아래 '실제 게임 실행 미검증'은 배포 당시 에이전트 검증 범위다. 검정 깜박임의 해소 여부는 별도 명시되지 않았다.
최신 변경: [0.1.5](0.1.5.md). 항구의 실제 onClick 콜백을 항로 상태에서만 원래 선택/취소에 연결한다. 일반 지도·우클릭·더블클릭 유지. 검정 깜박임 추가 요청은 미해결.
현재 검증: Release 경고/오류 0, 대역 97개, 패치 32개, 참조 107개. 실제 게임 실행 미검증. 아래 0.1.4 기록은 기존 동작과 이력이다.
DLL: Restitutor_fixes_map.dll. [이전 상세 검토](../../../Map/REVIEW_0.1.4.md) · [현재 패치 32개](PATCHES.md) · [원본](../../../analysis/systems/MAP.md).
## 항로 변경 계약
항구 UISailLineCtrl.ShowHook 후 시작, 실제 UIMapCtrl을 표시. 원래 계산/검증/확인 UI는 유지한다. 원래/Tab 배경·전환 완료를 기다리고 단계별 15초 제한으로 실패 정리한다.
Prefix는 소유한 지도에 한정해 기존 지도 갱신/선택 조회/포커스 이동과 일반 지도 A/B/X/SetLane 등을 대체한다. 조회·입력 활성의 __result를 변경하는 패치도 있다. 정확한 서명과 핸들러는 PATCHES 참조.
원래 OnAction_A(int)는 동일 프레임 중복을 제외하고 실행 유지, 이후 갱신. AutoSail Prefix는 로그만 추가한다.
입력 CaptureClose는 포커스/액션 조건에서 원래 실행을 막고 닫기와 release를 소비한다.
## 공유 상태·복원
UIManager 포커스, oldMap.UIContent.visible, 일반 groupTip.visible, 항구 imgRedFlag, SailLine.isSelect/Order, 조작 안내 상태.
원래 계산된 BestLineList를 표시로 투영하며 새 경로 계산은 하지 않는다.
Close/Dispose와 원래 planner 종료에서 소유한 화면을 정리하고 저장한 UI/깃발 표시를 복원한다. 전체 네이티브 상태의 스냅샷 롤백은 아니다.
## 안개 변경 계약
InitUIMask Prefix/Postfix: 동일한 유효 area/mask와 텍스처/버퍼가 있을 때만 원래 초기화를 생략하고 소유권 기록.
PlayerAreaDB.Deserialize/InitHook, MapMaskManager.Dispose/SetMaskData Prefix에서 소유권만 초기화하며 원래 실행은 유지.
공유 정적 안개가 두 지도에 영향을 준다. 저장 파일 자체를 쓰지 않는다. 다른 저장의 탐사 데이터를 합치지 않는다.
## 검증 / 충돌
최신 사용자 확인: 콘솔 선택 없는 재시작 후 지도 진입, 스페이스 선택과 빠른 이동 성공. 마우스 단일 클릭 무반응/더블클릭 현재 항구 복귀 보고. [입력 분석](../../../analysis/user-reports/2026-09-18-mouse/REPORT.md). 일반 Tab UpdateUI의 더블클릭 위치 복귀 분기가 유지된 것을 확인했다.
사용자 실행 후속: 일반 지도 마크 재열기 유지 보고, 항로 계획 검정 화면/응답 없음 보고. 설치 DLL은 0.1.4 일치. 원인 미확정이며 [실행 기록](../../../analysis/user-reports/2026-09-18-route-freeze/REPORT.md)에서 후속 확인한다.
기존 기록: 대역 86개, 패치 31개, 참조 107개. 사용자 실전 해결 미확인.
UIMapCtrl.OnAction_B와 ClosePortCheckLine은 기존 근거의 같은 RVA 0x5DD430: 중복 패치 금지.
공통 입력 함수에 외부 모드 접점이 있다. [호환성 목록](../COMPATIBILITY.md).
