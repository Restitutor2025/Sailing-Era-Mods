# Map 0.2.6 — 빨간 항구 판정을 원본 클릭 판정으로, 재적용 대상 수정

2026-09-23. 0.2.5 게임 테스트: 항주→아르긴 뒤 세우타(클릭 시 "측량 스킬 레벨이 부족합니다")가 빨갛지 않음. controller 모드는 원본 재그리기 뒤 1초 560회 재적용해도 빨갛게 보이지 않음(ctrlSelfPort=2 만으로는 빨간 외형 아님 → 확정), url 모드는 재적용 횟수가 Refresh 당 0~1회(시야 목록 `InViewIcons` 가 보이는 항구 전체가 아니었음).

## 변경
- **판정**: 원본 클릭 처리와 같은 `UISailLineCtrl.CheckPortSelectStatus` 0xD326F0 사용 — 3 = 측량 레벨 부족(`Tip_MeasureLvNoReached`), 4 = 마지막 경유지에서 경로 없음, 그리고 원본이 클릭 때 보는 `NoLineReach == false`(열린 항로 없음). 이전 판정 `MeasureCanReach && NoLineReach` 는 출발항 기준으로 창을 열 때 한 번만 계산된 값이라 경유지 추가를 반영 못 함(역어셈블: TotalPortDic 은 BuildData 에서만 채움). 경로 변경(RefreshRoute) 때마다 1회 계산, 로그 `[ROUTE] red ports N (survey a, no path b, no open line c) in X ms`.
- **재적용 대상**: `InViewIcons` 대신 빨간 항구 목록 + 선택 항구 목록. 원본이 다시 그리지 않은 아이콘은 url 이 이미 같아 비용 없음.
- **기준값 보호**: 아이콘이 이미 우리 빨간 상태일 때는 원래 그림으로 저장하지 않음(복원 때 빨강이 남는 문제 방지).
- **기본 모드 url**(controller 는 선택 사항으로만 남김).
