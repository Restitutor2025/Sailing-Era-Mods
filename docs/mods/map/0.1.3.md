# Restitutor_fixes_map.dll 0.1.3 — 검정 화면 전환 완료 대기

## 새 버전을 만든 이유
0.1.2의 active 로그와 실제 검은 화면이 불일치. UIHarborView.Auto의 LineGather 전환과 배경 로딩 완료를 함께 기다려야 함.

## 변경 내용
원래 지도의 MapBgLoadDown과 Gather/EnterBlack/Black 상태 해제를 기다린 뒤 Tab 표시. Tab 배경과 전환도 확인. 15초 제한 및 원래 복귀 경로 유지. 전환 플래그 강제 변경 없음.

## 이후 확인된 상태
사용자 스크린샷에서 지도는 표시되나 별도 하단 패널이 안내와 겹침. Tab 닫기 실패, 항구 선택 강조/항로 색상 미반영, 자동항해 미출발 보고. 이를 0.1.4에서 수정 대상으로 삼음.

## 검증
기존 기록: Release 오류/경고 0, 대역 45개, 패치 13개, 외부 참조 82개. 부분 소스/테스트는 Map/archive/0.1.3에 보관.
위 결과는 기존 검토 기록을 옮긴 것이며 이번 문서화에서 재실행한 결과가 아니다. 대역 테스트와 메타데이터 대조는 게임 렌더링·실제 출항·안개 유지의 실전 증명이 아니다.

## 구조와 유지 지침
표시할 지도는 실제 일반 UIMapCtrl/Model/View를 기준으로 한다. 기존 항로 계산/검증 컨트롤러와 보조 객체까지 삭제해 단일 객체로 재작성한 것은 아니다.
안개 보존은 동일한 살아 있는 영역/마스크의 반복 초기화를 막는 접근이다. 다른 저장 데이터·마스크 교체에는 초기화를 허용해야 한다. 사용자 안개 증상의 실제 원인이 이 경로인지 미확인이고 잃어버린 탐사 기록을 복구하지 않는다.
게임·Steam은 에이전트가 실행하지 않는다.

## 사용자 확인
이전 버전은 이력 보존용이다. 최신 0.1.4 문서의 확인 항목을 기준으로 테스트하며 과거 DLL의 문제 해결을 단정하지 않는다.
