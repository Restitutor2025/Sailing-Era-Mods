# Restitutor_fixes_map.dll 0.1.1 — 수명주기·안개 소유권 검토 보완

## 새 버전을 만든 이유
지도 전환 중 동기 닫기, 해제 예외, 저장 데이터 교체에 대한 코드 검토상 결함을 보완할 필요가 있었음.

## 변경 내용
Show 도중 닫히면 소유권이 다시 남지 않도록 순서 수정. 패널 해제 실패와 원래 UI 복원 분리. 닫힌 화면 재접근 방지. 항구 범위 제한. 원래 선택/취소 연결. PlayerAreaDB.InitHook·Deserialize·SetMaskData·Dispose에서 안개 소유권 초기화.

## 이후 확인된 상태
사용자 로그에 Route UI did not become ready와 UnifiedRoute.Tick 오류 발생. 이 로그만으로 어느 준비 조건이 실패했는지 구분 불가.

## 검증
기존 기록: Release 오류/경고 0, 대역 33개, 패치 대상 13개, 외부 참조 74개.
위 결과는 기존 검토 기록을 옮긴 것이며 이번 문서화에서 재실행한 결과가 아니다. 대역 테스트와 메타데이터 대조는 게임 렌더링·실제 출항·안개 유지의 실전 증명이 아니다.

## 구조와 유지 지침
표시할 지도는 실제 일반 UIMapCtrl/Model/View를 기준으로 한다. 기존 항로 계산/검증 컨트롤러와 보조 객체까지 삭제해 단일 객체로 재작성한 것은 아니다.
안개 보존은 동일한 살아 있는 영역/마스크의 반복 초기화를 막는 접근이다. 다른 저장 데이터·마스크 교체에는 초기화를 허용해야 한다. 사용자 안개 증상의 실제 원인이 이 경로인지 미확인이고 잃어버린 탐사 기록을 복구하지 않는다.
게임·Steam은 에이전트가 실행하지 않는다.

## 사용자 확인
이전 버전은 이력 보존용이다. 최신 0.1.4 문서의 확인 항목을 기준으로 테스트하며 과거 DLL의 문제 해결을 단정하지 않는다.
