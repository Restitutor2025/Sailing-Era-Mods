# 지도 0.2.0 후보 — Tab 지도 단일화

2026-09-18. 설치본 0.1.5와 별개 후보이며 사용자 실행 미검증.

## 변경 이유와 동작
기존 항로 지도에서 Tab 지도로 교체할 때 발생하는 중복 표시·깜박임을 없애기 위해, 확인한 항로 계획/부두 출항 준비 진입 경로를 UIMapCtrl 하나로 변경했다. UIMapLine 객체를 먼저 열고 숨기는 방식은 사용하지 않는다. routeMode가 켜진 항로 계획에서만 좌클릭/Space 경유지 선택·취소를 처리한다. 일반 Tab 지도와 출항 준비에서는 경유지 편집을 켜지 않는다. 우클릭/더블클릭 변경 없음.

원본 FindPath와 출항 확인·보급·선원 UI를 유지한다. 원본 본문에 맞춰 경유지 추가/뒤쪽 구간 취소를 이식했다. 종료 시 편집 중 목록을 비우며, 지연 종료 콜백은 새 세션을 닫지 못하도록 세대 번호로 제한한다. 안개 패치 소스는 0.1.5와 동일하다.
