# 지도 통합 후속 설계 — 미구현

## 확정된 종료 규칙
사용자 지시: 원본과 같이 항로 계획 종료 시 작성 중인 경유지를 초기화한다. 종료 후 편집 목록을 유지하는 기능은 추가하지 않는다.

[확인된 원본 본문] UISailLineCtrl.CloseHook (RVA 0xD35060)은 선택 항구의 빨간 깃발을 정리하고 SailLineManager.SelectPortList를 비운 뒤 CloseCheckLine으로 이어진다. 해당 함수에는 편집 목록 보존 선택 분기가 없다.
근거: [CloseHook 디스어셈블리](../../../analysis/map-integration/UISailLineCtrl.CloseHook0xD35060.asm). 직전 검토에서 설치 바이너리의 동일 함수 및 필드 오프셋을 대조했다. Ctrl+0x40은 SailLineManager, Manager+0x10은 SelectPortList이다.

이 규칙은 항로 계획의 편집 목록에 관한 것이다. 출발 확정 후 항해에 전달된 데이터까지 삭제하라는 지시로 확대하지 않는다. 구현 시 확정 데이터 전달과 편집 목록 정리 순서를 원본과 대조해야 한다.

## 상태
이번 반영은 설계 문서에만 적용했다. 현재 DLL 0.1.5와 패치 등록은 변경하지 않았다. 기존 항로 지도 객체의 완전 제거 범위 및 대체 호출 설계는 아직 확정하지 않았다.

## 2026-09-18 구현 후속
사용자 승인으로 항로 계획과 부두 출항 준비 모두 Tab 지도를 사용하며 원래 항로 지도 생성 경로를 대체한 [0.2.0 후보](0.2.0-candidate.md)를 작성했다. 앞선 미구현/미확정 문구는 당시 이력이다. 실전 결과는 미확인이다.
