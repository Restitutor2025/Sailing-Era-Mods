# Map 0.2.5 — UIMapHarbourIcon.UpdateInfo 훅 제거

2026-09-23. 기능: 공유 항로 계획 지도에서 도달 불가 항구 빨간색, 선택 항구 깃발 — 0.2.4 와 같게 보이는 것이 목표.

## 왜
- 0.2.4 는 `UIMapHarbourIcon.UpdateInfo` 에 Prefix+Postfix+Finalizer. 항해 미니맵도 이 함수를 매 Refresh 마다 아이콘 수만큼 불러 바다에서 초당 900~1,700회(항로 선택 중 2,300회) 훅이 돌았음. 실제로 필요한 건 항로 계획 세션 동안뿐.
- 프로젝트 규칙: 자주 불리는 공용 함수에 훅 금지, 런타임 Unpatch 금지(handoff/HOOK_CENSUS_RESULTS.md R절).

## 방법 (역어셈블 근거 S절)
- UpdateInfo 는 호출마다 아이콘 url·ctrlSelfPort 를 다시 계산해 씀 → "한 번 설정" 불가. `_eMapUseType=1` 세션 유지안은 항구 선택 제한·교역 UI(UICommerceCtrl.SetMapPort) 호출 등 부작용으로 기각.
- 기존 `UIMapView.Refresh` Postfix(원본 UpdateInViewIcons 가 보이는 아이콘을 다시 그린 뒤)에서, **세션·항로 모드일 때만** `Model.InViewIcons` 에 있는 항구 아이콘에 빨강/깃발을 다시 적용. 바다에서는 추가 비용 0.
- 빨간 표시 방식(MelonPreferences `[RestitutorMap] RedPortMode`):
  - `controller`(기본, 시험 중): `ctrlSelfPort=2` 만 설정. url 은 그대로 → 원본이 매 프레임 바꾸는 url 재설정 없음. 이것만으로 빨갛게 보이는지 **미확인**.
  - `url`: 0.2.1 방식으로 아이콘 url 도 빨간 그림으로. 세션 중에는 원본이 매 Refresh 마다 url 을 되돌리고 다시 바꾸는 반복이 생김(세션 한정).
- 깃발(imgRedFlag)은 UpdateInfo 가 건드리지 않음 → 같은 경로에서 유지.
- `RedPort` 목록과 `_eMapUseType` 은 더 이상 건드리지 않음.

- 설치 `Mods/Bug_Fixes/Restitutor_fixes_map.dll`, SHA256 `6b7ff20a5c39070fe11d09cb3082edf9c172e63d24091e2fd184625af6cb7aeb`. 되돌리기 `Map/candidates/tab-only/dist/0.2.4/`.
- 게임 확인: 도시에서 출항 준비 → 항로 선택 지도에서 도달 불가 항구가 빨간지(controller 모드), 선택 항구 깃발, 지도 끌기 때 끊김, 로그 `red port mode=controller`.
