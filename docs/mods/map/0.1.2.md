# Restitutor_fixes_map.dll 0.1.2 — 지도 준비 대기·실패 복귀

## 새 버전을 만든 이유
도시 항로 계획에서 준비 대기 오류와 무한로딩 보고. Tab Show 뒤에도 원래 화면 열림 상태를 요구하는 구조와 실패 복귀 누락을 보완.

## 변경 내용
원래 화면과 Tab 준비 대기를 분리. 600 업데이트 제한을 단계별 단조 시계 15초로 변경. 포인터/열림/콘텐츠 단계 로그. 소유한 Tab 정리 후 원래 Close, 필요 시 CloseCheckLine(true). 실패 후 해당 실행에서 통합 비활성화. 안개 코드 변경 없음.

## 이후 확인된 상태
사용자 보고: active 로그까지 도달했지만 도시에서 검은 화면으로 바뀌고 멈춤. IsOpen/Content만으로 실제 화면 준비를 보장하지 못함.

## 검증
기존 기록: Release 오류/경고 0, 대역 38개, 패치 13개, 외부 참조 76개.
위 결과는 기존 검토 기록을 옮긴 것이며 이번 문서화에서 재실행한 결과가 아니다. 대역 테스트와 메타데이터 대조는 게임 렌더링·실제 출항·안개 유지의 실전 증명이 아니다.

## 구조와 유지 지침
표시할 지도는 실제 일반 UIMapCtrl/Model/View를 기준으로 한다. 기존 항로 계산/검증 컨트롤러와 보조 객체까지 삭제해 단일 객체로 재작성한 것은 아니다.
안개 보존은 동일한 살아 있는 영역/마스크의 반복 초기화를 막는 접근이다. 다른 저장 데이터·마스크 교체에는 초기화를 허용해야 한다. 사용자 안개 증상의 실제 원인이 이 경로인지 미확인이고 잃어버린 탐사 기록을 복구하지 않는다.
게임·Steam은 에이전트가 실행하지 않는다.

## 사용자 확인
이전 버전은 이력 보존용이다. 최신 0.1.4 문서의 확인 항목을 기준으로 테스트하며 과거 DLL의 문제 해결을 단정하지 않는다.
