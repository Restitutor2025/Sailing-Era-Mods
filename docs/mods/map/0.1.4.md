# Restitutor_fixes_map.dll 0.1.4 — 기존 항로 UI와 입력·표시 연결

## 새 버전을 만든 이유
0.1.3 사용자 보고: 낯선 하단 패널, 닫히지 않는 Tab, 선택 항로 색상 누락, 자동항해 미출발. 별도 패널 생성과 입력 포커스/별도 모델 의존, 기존 지도 닫힘에 따른 LaneIcon 정리를 코드에서 확인.

## 변경 내용
별도 패널 제거, 기존 UISailLineView 보존. TransferFocusTo로 입력 이전. 보이는 Tab 항구를 원래 OnAction_A(int)에 전달. 원래 입력 잠금/선택 검증 유지. Action_Start와 MenuMap 닫기 및 키 해제 처리. 원래 계산 결과 BestLineList를 Tab 선의 isSelect/Order에 반영하고 항구 깃발 표시/복원. 중복 요약 숨김/복원. 원래 자동항해 버튼·확인·보급 절차 보존. 안개 코드는 변경하지 않음.

## 이후 확인된 상태
실제 게임에서 해결됐다는 사용자 확인은 아직 없음. 현재 최신 소스/빌드 버전이며, 바탕화면 DLL 전달 완료 기록이 있음.

## 검증
기존 검토: Release 오류/경고 0, 대역 86개, 패치 서명/매개변수 31개, 외부 참조 107개. 공유 네이티브 주소와 중복 패치 검사 포함.
위 결과는 기존 검토 기록을 옮긴 것이며 이번 문서화에서 재실행한 결과가 아니다. 대역 테스트와 메타데이터 대조는 게임 렌더링·실제 출항·안개 유지의 실전 증명이 아니다.

## 구조와 유지 지침
표시할 지도는 실제 일반 UIMapCtrl/Model/View를 기준으로 한다. 기존 항로 계산/검증 컨트롤러와 보조 객체까지 삭제해 단일 객체로 재작성한 것은 아니다.
안개 보존은 동일한 살아 있는 영역/마스크의 반복 초기화를 막는 접근이다. 다른 저장 데이터·마스크 교체에는 초기화를 허용해야 한다. 사용자 안개 증상의 실제 원인이 이 경로인지 미확인이고 잃어버린 탐사 기록을 복구하지 않는다.
게임·Steam은 에이전트가 실행하지 않는다.

## 사용자 확인
기존 항로 UI, 항구 깃발·항로 색상/방향·예상 일수, 경유지 추가/취소, Tab 닫기/재열기, 확인창 취소/실제 출항을 확인한다. 임무·플레이어 마크 및 저장 전후 탐사 유지도 확인한다.
