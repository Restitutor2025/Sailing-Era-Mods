0.1.0 게임 테스트(사용자, 2026-09-22 21:43): 로그 정상(`history loaded: game kept 10, file had 101, restored 91`, `storage list: numItems 101, scrollPane yes`), 스크롤 막대 생김, 빈 칸 클릭 시 "빈 저장 파일은 불러올 수 없습니다" → 칸 자체는 동작. 그러나 **11번째 이후 줄이 전부 안 보임**, 표시 `저장 수: 10/10`.

## 원인 (코드 확인, GameAssembly)
- `UIStorageView.RenderStorageItem` (0x663C50): 뷰의 `_isShowing`(+0x98)이 거짓이면 줄마다 `aniReset`(+0x330, 숨김) 재생 후 `aniruchang`(+0x320, 등장)을 **지연 index×0.1초**(상수 0x2D3D2B4 = 0.1)로 재생.
- `ShowHook` (0x6635C0): 0번 선택·맨 위로 스크롤 → `_isShowing = true` → `MarkDirty` → `Refresh` 다시 실행.
- `Refresh` (0x6638B0): `numItems = 10` → 10번 이후 줄이 화면에서 빠짐 → `Transition.OnOwnerRemovedFromStage` (0x181FB50) 가 `Stop` 호출 → 지연 중이던 등장 애니메이션이 숨김 상태로 멈춤. 이어서 0.1.0 Postfix 가 `numItems = 101` 로 되돌리지만 `_isShowing` 이 참이라 애니메이션 없이 붙음 → 숨김 그대로.
- 같은 이유로 선택도 사라짐: `GList.set_selectedIndex` (0x2202030)는 번호 ≥ 자식 수면 `ClearSelection`.
- 저장 수 글자: `Format(UIStatic_System_Storage_StorageNum, CurrentStorageCount, 10)` — 10 이 상수.
- 0~9번 줄은 화면에서 빠지지 않으므로 영향 없음 — **사용자 확인(2026-09-22): 원래 칸은 UI까지 정상, 새로 늘린 칸만 안 보임.**
