# Rebalance SaveSlots 0.2.1 (2026-09-23)

0.2.0 게임 테스트(사용자, 13:08): 포커스·Q/E·키 아이콘 모두 정상(로그 `key icons Q/E`, `load: slot 0 …`, `save: slot 12 …`). 사용자 지시: 키 설명 줄을 목록 아래(가운데 맨 밑)에서 **왼쪽 '저장 수: N/101' 바로 아래**로 옮기고, 모양을 `Q < 5칸씩 이동 > E` 로.

## 변경
- 위치: `UIStoragePanel.txtStorageNum`(저장 수 글자) 아래 10px, 그 글자 기준으로 가운데 맞춤. 0.2.0 은 목록 아래(1272,1286)였음.
- 글씨: `txtStorageNum.textFormat` 을 `CopyFrom` 으로 그대로 복사(글꼴·크기·색 동일), 가운데 정렬.
- 화살표 `<` `>`: 게임 수량 입력 창(`CommonPrompt.UICompInputNum`)의 `btnReduce`·`btnAdd` 와 **같은 패키지 항목**을 `UIPackage.CreateObjectFromURL(resourceURL)` 로 하나 더 만들어 씀(그 창을 한 번 만들어 URL만 읽고 바로 버림, URL 은 캐시). 클릭 안 되게 `touchable = false`.
- 키 아이콘 Q·E: 0.2.0 과 같음(`IconUtils.GetInputKeyIcon(5)`=L1/Q, `(6)`=R1/E).
- 각 조각을 못 얻으면 그 자리만 글자로 대체(`Q`, `<`, `>`, `E`).
- 로그 한 줄: `storage hint: count text (…), hint (…), keys Q/E, arrows </>`.

## 미확인
- 새 위치가 다른 요소와 겹치는지(위 로그 줄과 화면으로 판단).
- 화살표 패키지 항목이 이 화면에서 로드돼 있는지 — 안 되어 있으면 글자 `<` `>` 로 나오고 로그에 `arrows -/-`.
