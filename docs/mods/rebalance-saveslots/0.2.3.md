# Rebalance SaveSlots 0.2.3 (2026-09-23)

사용자 지시: 기존 "5칸씩 이동" 설명 줄과 Q/E ±5칸 이동 **대신** 페이지 방식. 목록 맨 아래 가운데에 전체 세이브 칸 수로 페이지 수를 계산해 `Q < 1 2 3 … 21 > E`.
사용자 결정: 21개 전부 표시 + 현재 페이지 강조, 번호·화살표 클릭으로 이동, 페이지는 0번 칸부터 5칸씩(1페이지 = 자동 2 + 수동 1~3, 21페이지 = 수동 99 하나).

## 변경
- `Rules`: `Page = 5`, `PageCount`(101 → 21), `PageOf`, `PageStart`, `PageStep`(Q/E = 이전/다음 페이지의 첫 칸, 끝에서 멈춤). 0.2.0 의 `Paged`(±5칸) 삭제.
- Q/E(패드 L1/R1): 이전/다음 페이지 첫 칸 선택 + 그 칸을 목록 맨 위로. 로그 `storage list: Action_… -> previous/next page.`
- 페이지 줄(`Pager`): 목록 아래 가운데, 목록 아래 끝 +20 을 세로 중심으로. `[Q 65px] < 1 … 21 > [E 65px]`. 숫자 글씨 = '저장 수' 글자 서식 복사, 현재 페이지 = 금색 굵게. 화살표 = `Common/ui_common_arrow_02`(왼쪽 반전). 숫자·화살표·키 아이콘 클릭 = 이동. 간격: 키↔화살표 10, 화살표↔숫자 18, 숫자↔숫자 20.
- 저장 수 아래에 있던 0.2.1~0.2.2 설명 줄 삭제.
- 강조 갱신: 모드 선택, 클릭(`OnStorageItemIndexChanged` Postfix 추가), 키 이동(`OnListNavigationItemChanged` Postfix), Refresh. 바뀐 게 없으면 아무것도 안 함.
- 페이지 줄은 저장 패널이 살아 있는 동안 한 번만 만듦(클릭 콜백도 한 번). 0.2.2 까지는 화면을 열 때마다 새로 만들었음.
- 0.2.2 임시 진단(입력·목록 이동 로그)과 포커스 로그 유지.

## 미확인
- 페이지 줄 세로 위치가 아래쪽 테두리·조작 팁 줄과 겹치는지(로그 `storage pager: …` 좌표로 판단).
- Q/E 입력이 모드에 들어오는지(0.2.2 진단 대기).

## 테스트
1. 로그 `Rebalance SaveSlots 0.2.3 loaded … 10 hooks`, `storage pager: … pages 21, keys image/image, arrows image/image`.
2. 목록 아래 `Q < 1 … 21 > E`, 현재 페이지 금색.
3. 숫자 클릭 → 그 페이지 첫 칸이 선택·맨 위. 화살표·키 아이콘 클릭 = 이전/다음 페이지.
4. Q, E, S 한 번씩 → 로그 `[diag]` 줄.
