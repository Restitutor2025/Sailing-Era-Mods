# 통합 이벤트 작업 화면 0.1.0 — 2026-09-24

주인공 행은 Ctrl/Shift로 다중 선택하며 파란 선택색은 포커스를 옮겨도 유지한다. 마지막 클릭 주인공을 우측에서 편집하고 선택 집합은 이벤트 필터로 사용한다. 목록 갱신 시 Tid로 선택을 복원한다.

상위 이벤트 플래그/고유 이벤트/대화 탭을 이벤트 작업 화면으로 통합했다. 목록은 Type33에 선택 주인공이 등장하는 이벤트의 합집합이며 Amount0(아닐 때)도 포함한다. 선택이 없으면 전체. 공용/후속 조건을 임의 평가하지 않는다. 동일 이야기의 비일치 이벤트는 연결된 이야기 함께 보기로 확인한다. ID·이야기·첫 대사·이벤트 메모 검색, 40개 이야기씩 추가 표시.

주인공 목록 아래 이벤트 창 열기로 독립 창을 연다. 조건/이벤트 상세 편집은 이벤트 화면 내부에 유지한다. 대화 전체는 가벼운 목록을 통해 이벤트에 연결되지 않은 대화도 접근한다. 선택 필터가 있으면 관련 대화 연결 요소로 제한한다. 연결 탭의 기존 이동은 통합 화면으로 전달한다.

카드 ID 아래 작은 이야기 제목, 좌측 선택 이벤트의 조건, 우측 이벤트 목록. 조건은 원본 행 단위 빈 줄로 구별하고 툴팁에 원본 조건 ID를 보존한다. AND/OR를 새로 추정하지 않는다. 제목은 기존 색인의 발화자 빈도 기반 자동 제목이다.

더블클릭: 별도 대화 창. 원본 Spine·atlas·텍스처를 읽는 기존 TalkArt/ArtCache/TalkSceneView를 재사용하며 게임 미실행, 이미지 파일을 쓰지 않고 메모리 캐시 사용. Q/E는 입력란 밖에서 이전/다음 줄, 입력란 안에서는 문자 입력. 줄 이동·창 닫기는 입력을 문서에 적용한다. 디스크 저장은 기존 Ctrl+S. 동일 대사를 여러 창에서 충돌 수정하면 덮어쓰지 않고 입력을 유지한다. 대화 분기는 목록에서 명시 선택하며 임의 진행하지 않는다. 공유 대화 표시 유지.

검증: 실제 설치 표를 사용한 offscreen Qt 검사에서 선택 보존, 두 주인공 합집합, 별도 창 동기화, 대사 수정/되돌리기, 기존 연결 이동, 키 입력 보호, 리소스 기반 장면 그리기 통과. 한국어 폰트를 등록해 화면 PNG도 확인. 기존 큰 대화 탭을 중첩 재사용한 초안은 갱신 시 access violation을 재현하여 폐기하고 가벼운 대화 목록/별도 창으로 변경했다. 게임/Steam 미실행. 실제 사용자의 에디터 조작 검증 전.

범위: 에디터 UI만 변경. 게임 DLL, 시작 대화, 선박/자금, 원본 게임 표, 사용자 character.json은 변경하지 않는다. 현재 별도창에서 편집하는 것은 대사 문구이며 원본의 표정/배치 편집 코드는 삭제하지 않았지만 새 간단 창에 노출하지 않는다.
