# 0.1.1 시작 연결 표시 — 2026-09-24

사용자 요청: Type33 조건 이벤트와 함께 startTalk/startEvent 연결 표시. 이벤트 목록 상단에 선택 주인공의 시작 연결을 카드로 표시한다. startTalk15607401은 GameEvent11001과 다른 항목이며 이벤트 ID를 새로 만들거나 원본 이벤트를 변경하지 않는다. 시작 이벤트는 기존 GameEvent 링크와 상세 편집으로 연결한다.

원본 게임 표에는 추가 TalkPart15607401이 없으므로 로딩 때 hero-assets/<tid>/hero-rows.json의 추가 대화 표(TalkPart/Talk/TalkTextLib 언어별)를 읽어 원본 Source의 별도 보완본을 만든다. 원본 키는 덮어쓰지 않고 충돌/누락을 경고한다. GameAssembly·게임 표·모드 DLL·JSON 파일에는 쓰지 않는다. 설치 행의 출처를 보존한다.

링크 우선순위는 문서 startSettings의 필드 > 설치 hero-start.json이다. 명시된0은 연결 해제이며 설치 값으로 되살리지 않는다. 설치 설정은 에디터 적재 시 읽으므로 외부에서 설치값을 바꾼 뒤에는 재시작해야 한다. 시작 대화도 대화 전체 목록의 주인공 필터에 포함한다.

검증: 실제 .venv와 설치 데이터로 셀레네156의15607401 연결,156074001 한국어 대사, 다른 주인공 제외, 검색, 명시0 우선, 시작 이벤트 상세 이동, 대사 수정/undo/문서 저장·재로드를 확인했다. 원본 Source와 GameEvent11001/TalkPart1100101 보존을 비교했다. 미리보기 PNG 확인. 사용자 GUI 조작은 확인 전. 대사 수정은 에디터 문서에 저장되며 게임 적용을 자동 실행하지 않는다.
