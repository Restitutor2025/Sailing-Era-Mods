# Fleet Info 0.1.0

DLL: `Restitutor_fixes_Fleet_Info.dll`. [상세](0.1.0.md) · [패치 목록](PATCHES.md).

여급 함대 정보 목록의 Owner 사전 구성에서 중복 키 예외 대신 첫 항목을 유지한다. 원본 함대 객체·월드 목록·저장 파일은 변경하지 않는다. 다른 소유자와 원본 해역 필터·목록 표시·입력·애니메이션은 유지한다. 동일 소유자의 네 함대를 각각 표시하는 기능은 아니다.

GameAssembly 해시와 대상 함수 0x962바이트 전체가 기준과 같을 때만 현재 프로세스 코드 1바이트를 수정한다. 종료 시 자신의 변경만 남아 있는 경우 복원한다. 지원 기준 외에는 비활성화하며 오류를 기록한다.

빌드/정적 검사/저장 사본 19개 정책 모사 완료. 게임 실행·설치·실전 확인은 하지 않았다.
