# Trade Exp 0.1.1 패치 목록

| 대상 | 함수 RVA / 길이 | 교체 범위 (끝 제외) |
|---|---|---|
| UIMarketView.AccountRefresh() | 0x11AE200 / 0x3322 | 0x11AFBA0~0x11AFBE9 (73바이트) |
| UIMarketView/<>c__DisplayClass33_1.<AccountRefresh>b__4() | 0x4438A0 / 0x6DA | 0x443B71~0x443BAF (62바이트) |

두 표시 합계 블록을 제자리 교체하며 남는 바이트는 NOP이다. 외부 trampoline/관리 콜백 없음.

- Int64 보유량의 음수를 0으로 보정하고 증가분 Int32를 부호 확장한다. Int64 덧셈 overflow 검사 후 0~2,147,483,647로 제한하여 기존 표시 필드에 쓴다.
- scratch 레지스터/스택 복원. callback의 RAX는 기존 보유량용 volatile 레지스터이며 후속 원본에서 덮어쓴다. 후속 원본은 flags를 다시 설정한다.
- 999999 MAX 아이콘 활성화 제거. 상한 도달시 숫자 2147483647을 표시한다. 원본 AccountRefresh의 초기 숨김 유지.
- 지급/DB/저장/입력/포커스/애니메이션 콜백 등록 변경 없음. Harmony 등록 없음. 초기 증가분의 원본 배율/부동소수점 계산은 범위 밖이다.
- 디스크 SHA256과 두 실행 함수 전체 바이트를 모두 검증한 뒤 적용한다. 불일치시 적용하지 않는다. 초기화 실패시 소유 변경 복원을 시도한다. 종료시 각 전체 함수가 자체 패치 결과와 같을 때만 원복한다.
- Contribution의 SetMarketGoods 추적과 시장 UI 수명주기 공유. 같은 대상 직접 패치 검색 결과는 없으나 외부 후속 변경/실전 병용 미검증.
