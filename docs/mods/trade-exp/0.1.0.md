AccountRefresh는 currency ID 2를 조회하고 보유량과 정산 경험치를 Int32로 더한 다음 999999와 비교해 표시용 합계를 잘랐다. 콜백에도 별도의 같은 표시 제한이 있다. IncreaseExpAmount는 ID 2를 IncreaseAmount에 전달한다. 기존 currency에 대한 IncreaseAmount 경로는 Int64 보유량에 가산하며 같은 상한이 없지만 신규 currency 생성 경로에는 999999 제한이 있다. 이번 수정은 사용자가 지정한 표시 두 곳에만 적용한다.
