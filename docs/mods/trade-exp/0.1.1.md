## 구현·근거

기존 두 함수의 표시 합계 블록을 제자리 교체한다. Int64 보유량의 음수를 0으로 보정하고 증가분 Int32를 부호 확장한다. Int64 덧셈의 overflow flag를 검사한 뒤 0~Int32.MaxValue로 제한한다. Int64.MaxValue + 양수도 상한으로 처리한다. 지급/저장 및 초기 증가분 배율 계산은 변경하지 않는다.
