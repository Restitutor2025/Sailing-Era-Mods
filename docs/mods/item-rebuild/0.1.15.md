# Item Rebuild 0.1.15 — 스킬북 묶음 표시

## 정책

스킬북(type 72)의 설치 108종: 10034, 10098, 71001~71100, 71146~71151. 같은 ItemId, BuyPrice, Supply, Quality, IsSuper, state끼리 묶는다. 무역 상태는 제외하며 UI 장착/전용 조건도 기존 그룹 필터로 보존한다. 아이콘만 같고 종류가 다른 책은 합치지 않는다. 일반 책·지도·언어책은 제외한다.

가방의 모든 소지품/서적·지도 목록에서 대표 행 하나와 x개수를 표시한다. 같은 묶음은 한 권이라도 남아 있으면 논리 용량 한 칸이며 마지막 권이 없어져야 빈 칸이 된다. 추가 획득/구매 공간 계산과 판매 묶음/수량 창/가운데 최대 선택도 같은 정책을 사용한다. 판매 단가·임무·유일·전용 조건이 다르면 판매 목록에서는 따로 표시한다.

저장 행과 개별 GUID/Number는 그대로 유지한다. 실제 소모품 병합 Rules.Stack에는 포함하지 않는다. 스킬 화면의 원본 책 목록 및 습득 처리도 변경하지 않았다.

## 확인한 근거와 판단

사용자 화면: 같은 모양의 스킬북 여러 개가 개별 아이콘으로 표시된다. 이미지 유사성만으로 같은 ItemId라고 판단하지 않는다.

[설치 테이블](../../../ItemRebuild/evidence/0.1.15/category-evidence.json)을 번들에서 다시 추출해 정확한 108종을 확인했다. 원본 pileNum은 1이다. 확인 바이너리 SHA256 `50d53d17829e3e77b9786ea42d998d1ad258f0653846524069f22e5e442effca`.

[InitBookData 본문](../../../ItemRebuild/evidence/0.1.15/UICharacterCtrl.InitBookData.asm)의 0x948266~0x94826A는 보유 항목의 +0x10 GUID를 책 UI 데이터 +0x18에 복사한다. [OnClickBtnBook](../../../ItemRebuild/evidence/0.1.15/UICharacterCtrl.OnClickBtnBook.asm)의 0x94C027~0x94C02E는 그 GUID를 읽어 ItemBagData.InnerRemoveItemByGuid에 전달한다. 따라서 원본에서 식별자가 실제로 쓰이지 않는다는 주장은 맞지 않는다. [삭제 함수](../../../ItemRebuild/evidence/0.1.15/ItemBagData.InnerRemoveItemByGuid.asm), [가방 모델 생성](../../../ItemRebuild/evidence/0.1.15/UIBagCtrl.RefreshDataModel.asm)도 현재 설치 본문을 보존했다.

추론: 같은 종류의 책을 화면에서 한 묶음으로 보여주는 데 개별 아이콘은 필요하지 않다. 그러나 개별 GUID 제거는 별도의 소비·캐시·저장 재설계를 요구하므로 이번 요청은 표시/논리 용량/판매 그룹으로 구현했다. 고유 식별자가 개발자 의도상 반드시 필요하다는 주장과는 구별한다.
