# Item Rebuild 0.1.13 — Min/Max 및 가운데 클릭

## 동작

판매·탐험 수량 창에 Min/Max 버튼을 추가했다. Min은 0, Max는 동기화된 현재 최대값이다. 버튼은 수량 초안을 바꾸며 적용/취소를 유지한다. 슬라이더 영역은 양쪽 버튼 16%씩, 내부 여백 2%씩, 트랙 64%로 배치한다. 보급품에는 이미 원본 최소/최대 버튼이 있어 유지한다.

상점 아이콘 가운데 클릭은 수량 창 없이 해당 판매 묶음의 판매 가능량 또는 현재 구매 목록의 같은 ItemId 전체 재고를 선택한다. 최종 결제/돈/재고 변경은 기존 거래 확정 경로에 남긴다. 다른 선택을 해제하지 않는다. 반복 클릭은 toggle이 아닌 Max 유지다. 장착/임무 판매는 거부하며 장비·소모품은 기존 안전한 묶음 판정을 사용한다. 구매 클릭 행이 현재 상점 목록에 실제로 속하는지 확인한다.

역참 탐험 도구의 가운데 클릭은 수량 창을 만들지 않고 기존 확정 콜백을 최대값으로 적용한다. 재고/종류별 3개/가용 무게 제한을 그대로 적용하고 실제 재고를 확정 직전에 다시 확인한다. 이미 선택한 수량의 무게를 돌려놓고 재계산하므로 반복 클릭으로 무게가 중복되지 않는다.

## 입력·수명·호환성

QuickBinding은 아이콘 onTouchBegin의 button=2에만 반응한다. 다른 버튼은 기존 경로를 유지한다. 포커스 활성, 모델 포인터, 세대, 실제 행 소속을 검사한다. 가상 목록 재사용 때 콜백을 교체하고 stage 이탈/화면 종료/Reset에서 구독을 제거한다. 팝업이 열려 있는 동안 배경 아이콘 shortcut을 차단한다.

기존 상점 가운데 단축키가 중복 실행되지 않도록 R2/L2에서 Unity Input.GetMouseButton(2)/GetMouseButtonUp(2)일 때만 원본을 건너뛴다. 해당 액션 호출 안에서만 조회하며 전역 polling은 추가하지 않는다. 입력 순서와 native 클릭 버블링은 게임 실전 미검증이다. BtnMulti로 가운데 이벤트가 들어오는 경우에도 수량 창을 열지 않는 보조 경로를 넣었다.

이미 게임에 설치된 `UnityEngine.InputLegacyModule.dll`을 Private=false로 참조한다. 새 런타임/모드 DLL 배포 없음. 기존 44개 훅에 R2/L2 두 개가 추가되어 46개다.
