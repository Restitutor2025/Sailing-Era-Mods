# Item Rebuild 0.1.16 — 스킬북 실제 수량 통합

사용자 요청: 스킬북을 장비처럼 권별 고유 객체로 유지하지 않고 기존 Restitutor_Additional_Item_Rebuild에 통합한다.

## 최종 동작과 범위

type 72 스킬북 108종을 Rules.Stack에 포함했다. 비무역 동일 ItemId/BuyPrice/Supply/Quality/IsSuper/state 기록은 첫 기록의 Number로 합산하고 중복 기록과 해당 GUID를 가방에서 제거한다. 다른 속성과 무역 기록은 그대로 보존한다. 언어책·일반 서적·지도·장비는 새 병합 대상이 아니다.

권별 GUID는 없애지만 원본 PlayerItemData 저장 형식과 소비/판매 API가 요구하는 대표 GUID 하나는 묶음에 남는다. GUID 필드 자체를 제거하거나 모든 값을 0으로 만드는 변경은 아니다. 100권의 동일 속성 책은 기록 하나와 Number=100으로 유지된다. 획득 중 원본이 만드는 임시 기록은 병합 후 제거하며, 모든 일시적 객체 생성이나 판매용 단위 Slot 생성을 없앴다는 의미는 아니다.

기존 Deserialize/가방 갱신/판매 준비/획득 병합 경로를 사용한다. 변경 전 inventory-backups에 대상 행을 기록하고, 백업 실패·수량 오버플로 시 병합하지 않는다. 사용 시 기존 InnerRemoveItemByGuid 전처리가 대표 기록의 Number를 1 감소시키며 마지막 권만 원본 삭제로 넘긴다. 저장 dirty/배지 변경 알림은 기존 경로다. 스킬 학습 조건·효과·비용·금지 표식은 수정하지 않았다. 인물 팝업/탭 제거는 이번 변경에 포함하지 않는다.
