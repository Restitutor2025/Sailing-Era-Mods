# Item Rebuild 0.1.3 — 가방 수량 배지

사용자 이미지에서 역참 도구의 이름이 아이콘 위에 크게 겹쳐 표시되는 것을 확인했다. 요청에 따라 가방 BagLabel을 이름 없는 소문자 `x수량`으로 변경했다. 기존 슬롯 글자 크기의 절반(정수 반올림, 최소 1), 검은색, 외곽선 제거, 우측/아래 정렬, 슬롯 내부 4 UI 단위 여백을 사용한다. 다른 화면 수량 표시와 실제 저장·사용 로직은 유지한다.

GTextField.textFormat 및 TextFormat.CopyFrom/size/color/gradientColor/align, verticalAlign/autoSize/singleLine/stroke와 GObject.SetXY/SetSize API를 설치 interop에서 대조했다. 기존 BagSlotRenderer 본문 근거 유지, 새 native 훅 없음. 런타임 형식 객체를 복사하여 변경하며, 슬롯 재사용 시 이전 텍스트와 서식·크기·좌표를 복원한다. 반복 renderer 호출마다 절반으로 줄어드는 것을 방지한다.

Release 빌드 경고/오류 0, 기존 대역 3,644개 검사 통과(수량 문자열·반복 절반 크기 유지·재사용 원복 기대값 수정). 초기화 호출 그래프, 훅 22개 및 interop 참조 검사 통과. [검사](../../../ItemRebuild/evidence/interop-verification.txt), [배포 해시](../../../ItemRebuild/evidence/release-hash.txt). 이전 0.1.2 DLL/EntryPoint 소스/검사 결과는 evidence/0.1.2에 보존했다.

게임/Steam 실행 및 자동 설치 없음. 첨부 화면은 변경 전 사용자 실행 근거이며 새 표시의 실제 배치 검증은 사용자 확인 전이다.
