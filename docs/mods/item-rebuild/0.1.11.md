## 구현

공통 마우스 트랙을 compact 모드로 팝업 안에 배치한다. 숫자 창은 원본 입력 필드 아래와 하단 버튼 위의 간격을 사용한다. 보급품은 원본 감소 버튼 오른쪽부터 증가 버튼 왼쪽까지의 바 영역을 사용한다. Stage 좌표를 slider.Local 좌표로 변환하고 가장 가까운 정수로 반올림한다. 중간값은 큰 쪽, 바깥은 범위 끝으로 제한한다.

숫자 창의 제목은 수량 선택(0~상한). ±는 0↔상한 순환이며 직접 입력은 기존 clamp를 유지한다. 판매 최대는 판매 가능량, 탐험 최대는 재고·3개·가용 무게로 제한한다. 적용 때 재검사한다.

하단 원본 버튼 중심에 두 버튼을 배치하며 각각 45%, 사이 10%다. 원본 버튼은 일시적으로 숨긴다. 자체 숫자 창의 B는 취소, A는 적용으로 한 번만 호출한다. 기본 키 ESC/Space는 표시 문구이고 실제 입력은 게임의 액션 매핑을 따른다. 외부 금액 팝업 액션은 통과시킨다. 공급은 원본 가격/무게/OK/Close를 유지한다. 취소 후 적용 버튼의 지연 클릭은 폐기한다. 제목·원본 버튼 표시는 종료 때 복원한다.

상품 수량 textFormat.size 18→27, 텍스트 높이 24→36. 단가·기존 흰색/검정 외곽선 및 긴 텍스트 Shrink 유지. GUID·묶음·용량·결제 데이터 정책은 변경하지 않았다.
