# Item Rebuild 0.1.2 — 역참 클릭 무반응 및 빈 보급품 칸

## 사용자 실행 증거

[첨부 로그 보존본](../../../ItemRebuild/evidence/0.1.2/user-log.txt)은 0.1.1(해시 518CAA3A…F19D68A)을 이름 `Restitutor_Additional_Item_Rebuild_Exploration.dll`로 설치한 실행이다. 이름 변경과 무관하게 내용은 배포 0.1.1과 일치한다.

01:21:03 시작 화면 진행, 01:21:18 중복 81행 병합 로그 이후 역참에서 CarryLabel NullReferenceException이 반복된다. 01:22:55.653~.661 지연 UIManager 훅 등록은 완료되었지만 직후 **IndexOf → Contains → ChooseLand** NullReferenceException으로 팝업 열기 전에 클릭 처리가 중단된다. 사용자는 아이템 클릭 무반응을 보고했다. 최초 CarryLabel 표시 오류만으로 클릭 무반응을 추정한 것이 아니라 클릭 경로의 별도 예외가 확인됐다.

## 확인된 원본 본문

- UILandExploreCtrl.ShowHook 0x1135040: 0x1135949에서 model.ListLandBag(+0x28)을 읽고, 0x113595D에서 edx=0, 0x113595F에서 List.Add를 호출한다. 즉 빈 보급품 항목을 넣는다. [본문](../../../ItemRebuild/evidence/UILandExploreCtrl.ShowHook.asm).
- ListLandBagRender 0xB34DF0: 0xB35053~55에서 index=0을 별도 분기로 보낸다. 그 분기는 Goods를 읽지 않고 보급 수량(+0x94)과 SupplyWeight를 표시한다. [본문](../../../ItemRebuild/evidence/UILandExploreView.ListLandBagRender.asm).
- RefreshListLandBag 0x1138DA0은 도구를 index 1에 삽입한다. 첫 칸은 도구가 아니다. [본문](../../../ItemRebuild/evidence/UILandExploreCtrl.RefreshListLandBag.asm).
- 원본 JumpToLandExplore의 Where predicate `<JumpToLandExplore>b__32_0`(0x4402F0, 7바이트)은 `test rdx,rdx; setne al; ret`: null 제외 조건이다. 출발 전에 null을 없애서 목록 인덱스를 바꿀 필요가 없다. [추출 목록](../../../ItemRebuild/evidence/targets.json).

0.1.1 IndexOf는 모든 항목의 Pointer를 읽었고 CarryLabel과 JumpBegin은 모든 항목의 GoodsID를 읽었다. null이 정상 데이터라는 원본 계약을 놓친 구현 오류다. 이전 대역 테스트도 빈 일반 목록으로 시작하여 이 조건을 재현하지 못했다.

## 수정·검증

- IndexOf는 null 항목을 건너뛰며 원래 인덱스를 반환한다. 선택/재선택/확정은 보급품 칸을 삭제하지 않는다.
- CarryLabel은 index 0을 원본에 맡기고, 다른 null 항목도 건너뛴다. Depot/Carry 표시에 모델·목록·항목·UI 자식의 null 방어를 적용했다.
- JumpBegin은 null을 임시 목록에 그대로 넣고 실제 도구만 선택 수량만큼 펼친다. Finalizer는 원래 목록을 복원한다. 3개 상한/재고/무게/저장 정책 및 지연 초기화 유지.
- 실제 production source에 보급품 null 칸을 넣은 테스트를 먼저 실행하여 **동일 IndexOf→Contains→ChooseLand 예외 재현**. [수정 전 결과](../../../ItemRebuild/evidence/0.1.2/before-fix-test.txt).
- 수정 후 **3,644 assertions 통과**: 보급품 칸이 있는 클릭→팝업→수량 확정→출발 확장·복원→0 해제, 보급품만 있는 출발, 수량 라벨, 추가 null 행/없는 UI 자식 검사 포함. [결과](../../../ItemRebuild/evidence/managed-tests.txt).
- Release 경고/오류 0, native 훅 22개 유일성 및 interop 참조 94개, 초기화 호출 그래프 검사 통과. [해시](../../../ItemRebuild/evidence/release-hash.txt).

0.1.1 DLL/검사 결과/이전 Land.cs는 evidence/0.1.1에 보존했다. 게임/Steam 실행, Mods 자동 설치 없음. 0.1.2의 실제 UI 입력·출발/귀환은 사용자 확인 전이다. 설치 시 이전 Exploration 이름 DLL과 새 DLL을 동시에 두지 않고 기존 파일을 교체한다.
