# Item Rebuild 0.1.1 — 타이틀 이전 검은 화면 수정

## 사용자 보고와 로그

2026-09-20 사용자: 게임 실행 직후 타이틀 이전 검은 화면, Item Rebuild 모드를 빼면 정상 작동. MelonLoader 로그에는 관련 예외를 찾지 못했다고 보고했다.

설치 경로에서 읽은 01:13:18/01:13:56 실행은 Item Rebuild 0.1.0 초기화 완료가 있지만 시작 화면 진입 기록이 없다. 01:14:26 실행은 해당 모드가 없고 원래 Launch UI/안내 생략 로그가 이어진다. [모드 포함 Melon 로그](../../../ItemRebuild/evidence/0.1.1/with-mod-melon.log), [모드 제외 Melon 로그](../../../ItemRebuild/evidence/0.1.1/without-mod-melon.log).

게임/Steam을 실행·조작하지 않고 Unity 별도 로그를 읽었다. [Player-prev.log 보존본](../../../ItemRebuild/evidence/0.1.1/with-mod-player.log)에 다음 NullReferenceException이 있다.

- FairyGUI.StageCamera.OnScreenSizeChanged
- GameObject.GetComponent → UIContentScaler.OnEnable
- DisplayObject.UpdateHierarchy → Container.AddChildAt → GComponent.AddChild → UIManager.StartUp → GameLaunch.Start.MoveNext

[모드 제외 Player.log 보존본](../../../ItemRebuild/evidence/0.1.1/without-mod-player.log)에는 위 예외가 없다. 로그와 사용자의 제거 비교는 동일 원인을 강하게 지지하지만 수정본 실전 성공 보고와 구별한다.

## 확인된 원본·메타데이터

설치 GameAssembly 기준 해시 유지. [UIManager..cctor 본문](../../../ItemRebuild/evidence/UIManager..cctor.asm) RVA 0xA3E830에서 Stage의 static 인스턴스가 없으면 **0xA3E8CE에서 FairyGUI.Stage.Instantiate(0x86C4E0)**를 호출한다.

설치 interop의 UIManager generated .cctor는 NativeClassPtr을 얻은 직후 **il2cpp_runtime_class_init**를 호출한다. Harmony가 이 타입의 네이티브 메서드 포인터를 해석하는 것만으로 원본 static 생성자와 Stage 생성이 실행될 수 있다. 0.1.0은 OnInitializeMelon → InstallLand → UIManager.ShowInputNumPromptBox 패치 등록을 통해 이 타입을 너무 일찍 초기화했다. 타입 초기화가 UI 생성을 일으킨다는 사실을 최초 검증에서 놓쳤다.

## 수정과 검사

- 기존 UIManager 대상 1개만 초기 등록에서 분리. 역참 화면의 유효한 대상 도구를 클릭한 시점에 별도 NoInlining 함수에서 등록한다. 이 시점에는 게임 시작 UI 초기화가 이미 완료되어 있다.
- 등록 성공 이후 팝업 반복·세션 Reset에서도 한 번만 등록. 실패 시 팝업을 열지 않고 오류 기록. 등록 시작/완료 로그를 추가했다.
- 수량 통합·세이브 변환·±1·직접 입력·최대 3개 규칙은 변경하지 않았다. 세이브 로드 훅을 추측으로 수정하지 않았다.
- Release 빌드 경고/오류 0. 대역 검사 **3,636개** 통과(조기 등록 없음/첫 클릭 등록/한 번만 등록의 회귀 검사 추가).
- Cecil로 실제 빌드 DLL의 시작 호출 그래프 6개 메서드를 순회하여 UIManager 참조나 지연 등록 함수가 없음을 확인. [결과·interop 초기화 IL](../../../ItemRebuild/evidence/startup-verification.txt).
- native hook 22개 서명/별칭 검사 및 interop 참조 94개 resolve 통과. 시작 21개+지연 1개. [검사 결과](../../../ItemRebuild/evidence/interop-verification.txt), [관리 검사](../../../ItemRebuild/evidence/managed-tests.txt), [배포 해시](../../../ItemRebuild/evidence/release-hash.txt).

0.1.0 DLL과 당시 검사 결과는 [이전 근거 폴더](../../../ItemRebuild/evidence/0.1.0)에 보존했다. 0.1.1 DLL은 작업 루트에 제공했으며 게임 Mods에 자동 설치하지 않았다. 수정 후 타이틀 진입 및 역참 첫 팝업 실전 검증은 사용자 확인 전이다.
