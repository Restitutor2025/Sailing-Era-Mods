# Item Rebuild 0.1.14 — 보급품 최대 적재와 휴대 수량

중앙 보급품 보충 아이콘과 왼쪽 보급품 아이콘의 가운데 클릭은 공급 모델의 EntryType/ItemHeavy/MaxHeavy/AddNum을 준비하고 원본 ShowHook으로 MaxNum을 계산한다. 음수가 아닌 MaxNum을 AddNum에 넣고 SetCountPrice 후 탐험 Supply에 대입하고 MarkDirty한다. UI Show/Close는 호출하지 않는다. 총수량을 교체하므로 반복 클릭해도 중복되지 않는다. 도구 무게를 제외하며 이미 실린 보급품을 중복 차감하지 않는다.

사용자 화면의 상한 19kg/도구 9.1kg에서는 보급품 6개(9kg)가 최대다. 남은 0.9kg에는 1개를 더 넣을 수 없다. 생산 코드는 단위 무게를 고정하지 않고 원본 계산을 호출한다.

왼쪽 도구에 독립 GTextField x수량 표시를 추가했다. 오른쪽 위 비율 영역, 흰색 26/검은 외곽선, Shrink, touchable=false이며 하단 무게는 유지한다. 재렌더/풀링/이탈/Reset에서 배지와 이벤트를 정리한다.

## 근거 구분

사용자 실행 보고: 왼쪽 휴대 도구에서 개수가 보이지 않았다. 실제 controller가 숨긴 시점은 계측하지 않았다. 기존 보급품용 표시와 분리해 해결한다.

설치 바이너리 SHA256 `50d53d17829e3e77b9786ea42d998d1ad258f0653846524069f22e5e442effca`. [6개 함수 메타데이터](../../../ItemRebuild/evidence/0.1.14/targets.json)와 본문을 보존했다.

- [OnClickSupply](../../../ItemRebuild/evidence/0.1.14/UILandExploreCtrl.OnClickSupply.asm): 공급 모델 데이터 준비 후 UI 열기. 자체 경로는 데이터 준비만 재현한다.
- [ShowHook](../../../ItemRebuild/evidence/0.1.14/UILandExploreSupplyCtrl.ShowHook.asm): 반올림한 MaxHeavy−ItemHeavy를 게임 단위 무게로 나눈 내림값을 MaxNum에 저장하고 맥락/가격을 준비한다. 본문에 UI Show/Close 없음.
- [OnClickBtnOK](../../../ItemRebuild/evidence/0.1.14/UILandExploreSupplyCtrl.OnClickBtnOK.asm): Supply 대입/MarkDirty/Close. 자체 경로는 앞 두 동작만 수행한다.
- [ListLandBagRender](../../../ItemRebuild/evidence/0.1.14/UILandExploreView.ListLandBagRender.asm): 공급 controller/공급 수량/도구 무게 표시 분기. 자체 배지는 이 controller와 독립이다.
- [SupplyWeight](../../../ItemRebuild/evidence/0.1.14/UILandExploreModel.get_SupplyWeight.asm): 공급 수량과 게임 단위 무게로 합산 무게 계산.
