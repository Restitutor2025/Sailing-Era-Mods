# Rebalance Boarding 0.1.0 (2026-09-22)

## 사용자 결정
- 백병전이 너무 늦게 일어남(접현해도 포격으로 전투가 끝남) → **진입 기준값 100 → 40**.
- 방식: 숫자 1바이트 교체(Fleet Info 방식). 새 모드 `Mods/Rebalance/`.

## 원본 동작 [본문]
- 각 배가 2초마다 `ShootProgress += 접현속도(ContactSpeed, 표 10~12 대부분)`(+기함 갑판장 보너스). 두 배 합 **> 100** 이면 백병전.
- 접촉이 끊기면 그 배의 `ShootProgress = 0`, 재접촉 후 첫 증가는 2초 뒤(분석 9절). 이번 버전은 이 부분을 바꾸지 않는다.
- 기준 40 이면: 양쪽 12 → 2초마다 +24 → 4초째 48 > 40 → 약 **4초 연속 접촉**(원본 10초). 양쪽 10 → 4초째 40 은 초과가 아니므로 6초째 60.

## 구현
- `src/Patch.cs`: RVA·길이·편집 위치·기대 바이트(83 F9 64 0F 8E)·새 값 정의.
- `src/EntryPoint.cs`: GameAssembly 해시 확인 → 파일에서 함수 본문 0x44A 바이트를 읽어 기준으로 삼음(게임 코드를 DLL 에 넣지 않음) → 실행 중 본문 == 기준 확인 → 1바이트 쓰기(VirtualProtect·FlushInstructionCache·읽기 확인) → 종료 시 조건부 복원.
- 매 프레임 비용 없음, 훅 없음.

## 사용자 확인 항목
1. 로그 `Rebalance Boarding 0.1.0 active: … > 40 (was 100)` 1줄, `initialization failed` 없음.
2. 기함으로 적선에 붙었을 때 백병전 진입이 이전보다 빠른지.
3. 게임 종료 시 로그 `original threshold restored`.
4. 여전히 늦으면: 접촉이 끊겼다 붙기를 반복하는지(선원만 1씩 줄고 진입 안 됨) → 분석 9절 H1, 진단 로그 필요.
