## 0.1.1 변경
- 훅 설치 시점: 모드 로드 때 → 첫 장면 진입 후 첫 프레임(HookCensus 와 같은 방식, 조기 정적 생성자 실행 방지).
- `gap` 기준 50 → 40 ms(HookCensus `[HITCH]` 와 맞춤).
- 새 훅: `BoatEntityCreateManager.CreateShipEntity`(NPC 기함 엔티티 1척 생성, 프레임당 1척) 소요 시간 → `ship_create` 행·`sec.shipCreate/shipCreateMs/shipCreateMaxMs`. `OceanScene.AddNpcBoat` 소요 시간 → `npc_boat.costMs`.
- `gap` 행 `inFrame` 에 그 프레임의 배 생성 수·시간, `InstantiateAsync` 요청 분류별 수(`reqByCat`), `il2cppUsedDeltaMB`(IL2CPP 힙 사용량 변화) 추가. `gcDelta` 는 IL2CPP GC(Il2CppSystem.GC.CollectionCount(0)).
