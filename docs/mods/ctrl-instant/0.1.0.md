## 수명주기와 범위

일반 항해·플레이어 자유 함대·장면 진입 완료·활성 항해 UI로 제한한다. 도시/전투/로딩/다른 창 포커스/기존 일시정지 상태에서는 새로 시작하지 않는다. 원본 입력 전달 뒤에만 동작한다.

자체 토큰과 원본 선단 선택 토큰을 구별한다. 키 해제나 취소, UI/앱 포커스 상실, UI 닫기/폐기, 항해 상태 종료, 모드 해제에서 자기 소유분만 반환한다. GameManager.ForceReset 뒤에는 참조를 폐기한다. 목록 포인터·토큰 존재 여부를 대조하며 중복·재진입 해제를 방지한다. UI 전환 뒤 늦게 도착하는 동일 Hold 성립은 해제 전까지 억제한다.

원본 선택 UI는 대상이 있을 때만 열린다. 빈 바다에는 가짜 선택 대상이나 선택 상태를 만들지 않는다. 다른 창의 토큰은 유지하며, 전역 시간/배속 필드/세이브를 쓰지 않는다.
