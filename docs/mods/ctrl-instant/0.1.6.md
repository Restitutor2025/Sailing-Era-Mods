# CTRL Instant 0.1.6 — 진단 제거 정식판 — 2026-09-20

## 배경

0.1.5에서 교섭(선단 상호작용 창) 중 시간 흐름 문제가 해결됐다. 사용자 보고와 20:16 로그 교차 확인으로 확인했다([0.1.5](0.1.5.md)). 사용자 요청에 따라 진단 코드를 모두 뺐다.

## 변경

- 제거한 것:
  - 0.1.3~0.1.5 진단 훅 21개와 `OceanSceneSailingState.Enter` 등록 트리거
  - 관측 창(WATCH/TICK)
  - 0.1.1 진단: `XBaseInputAgent.OnEvtCaptureFeatureInput` 관측 Prefix, CTRL 키 직접 폴링(PHYSICAL_*/HELD), `UserData/Restitutor/CTRLInstant/CTRLInstant-*.log` 파일 생성과 `[CTRLTrace]` 출력
- 남은 훅 7개: `UISailInputAgent` Start(Postfix)·Perform(Prefix)·End(Finalizer), `UISailingCtrl` CloseHook·DisposeHook(Prefix), `OceanSceneSailingState.Exit`(Prefix), `GameManager.ForceReset`(Postfix).
- 정지 로직은 0.1.5와 같다. 소스 대조로 확인했고, 로그 문장만 삭제했다. `HANDOFF_NPC_WINDOW` 분기의 `if (selectionToken > 0)` 조건은 로그용이었으므로, 조건 없이 `selectionToken = 0`으로 바꿨다(동작 동일).
- 오류는 MelonLoader 로그에만 남는다(`CTRL Instant: <예외>`, 같은 메시지는 1회).
- `TraceLog.cs`는 빌드 대상에서 뺐다(csproj의 Compile을 `src\EntryPoint.cs;src\PauseLease.cs`로 지정). 파일은 삭제하지 않았다. 원본은 `archive/0.1.5/src/`에 있다.
- `extract.py`가 확인하는 등록 수를 7로 바꿨다.

## 남은 확인 사항

- 기존 로그 파일(`UserData/Restitutor/CTRLInstant/`)은 자동으로 지워지지 않는다. 필요하면 사용자가 직접 삭제한다.
- 이후 이 모드에 버그 제보가 오면 진단판(`archive/0.1.5`)을 다시 기준으로 삼는다.
- 창 안의 교역·정보·전투 버튼 경로와 다른 창과 겹치는 경우는 실전에서 확인하지 않았다.

## 검증 상태

- 소스 작성. 빌드와 검사(`build.ps1`)는 사용자 PC에서 해야 한다. 실전은 확인 전.
- 0.1.5 소스·DLL(`ECC5D704…`)·검증 결과는 `CTRLInstant/archive/0.1.5/`에 보존했다.
