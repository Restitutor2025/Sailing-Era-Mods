# CTRL Instant 0.1.5 — 선단 상호작용 창이 열려도 CTRL 정지 유지 — 2026-09-20

## 사용자 보고 (0.1.4 실행, 20:10)

1. CTRL을 누른 채 상대 선단을 클릭한다 → 창이 열리고 시간이 멈춘다. 이 상태에서 우클릭으로 취소하면, CTRL을 계속 누르고 있는데도 시간이 흐른다.
2. CTRL을 다시 누르면 멈춘다. 그 상태에서 같은 선단을 클릭하면 시간이 흐른다.

## 로그 근거 [사용자로그] — `CTRLInstant/evidence/user-report-20260920-2010/runtime.log`

- 0.1.4 진단 등록 성공(`DIAG_INSTALL_END`). 설치본 SHA256은 `B3C6183F…D02344`로 빌드 산출물과 같다. 검은 화면 없음.
- **시도 1 (34154~36460ms):** CTRL을 누르면 자체 토큰 4와 선택 토큰 5가 생긴다. 선단 클릭(`NPC_SHOW by=ray-ship`) → `UINpcInteractiveCtrl`이 포커스를 가져간다 → 모드가 `RELEASE_SCENE_OR_UI`에서 선택 5와 자체 4를 모두 반환한다(`pauses=[]`). 곧이어 `CheckRayShip`이 다시 호출돼(`NPC_SHOW` 4회) 원본이 선택 6을 연다(`by=ray-ship`). 이 동안 `day`는 2.44로 고정이다. 우클릭(35433) → `NPC_CLOSE` → 원본 `CloseHook`이 선택 6을 반환한다(`by=npc-close`). 이때 CTRL은 눌린 상태(`ctrlDown=True`)지만 자체 토큰이 이미 없어서 `pauses=[]`가 되고, `day`가 2.44→3.18→3.46으로 증가한다. **(증상 1)**
- **시도 2 (36628~37775ms):** CTRL을 누르면 자체 토큰 7과 선택 토큰 8이 생긴다. 선단 클릭 → 모드가 선택 8과 자체 7을 반환한다. 이번에는 `CheckRayShip`이 다시 호출되지 않아서 재선택이 없다. 창이 열려 있는 동안 `pauses=[]`, `day`가 3.63→4.63으로 증가한다. **(증상 2)** 창을 닫을 때 `CloseCheckNpcStatus`의 결과는 false였다(반환할 것 없음).
- 정지 목록이 비어 있지 않은 동안에는 `day`가 변하지 않았다. 따라서 "토큰이 있어도 시간이 흐른다"(0.1.3 H4)는 반박됐다.

## 원인 (확정)

0.1.2부터 들어간 "다른 창으로 포커스가 넘어가면 자체 정지 해제" 규칙이 선단 상호작용 창에도 적용됐다. 이 규칙은 원본이 창의 수명 동안 유지하는 선택 정지까지 함께 닫았다. 창이 열린 뒤 시간이 멈춰 있는지는 `CheckRayShip`이 우연히 다시 호출돼 원본이 선택을 다시 여는지에 달려 있었다(시도 1은 다시 열림, 시도 2는 안 열림). 창을 닫은 뒤에는 자체 토큰이 이미 반환된 상태라서, CTRL을 누르고 있어도 시간이 흘렀다.

원본 계약 [본문, 0.1.3.md]: 선박 클릭 → `ShowNpcTeamInfo` → (선택이 없으면) `OpenCheckNpcStatus`. 창의 `CloseHook`은 `CloseCheckNpcStatus`를 호출한다.

## 변경

- 정지 유지 검사에서 현재 포커스가 **`UINpcInteractiveCtrl`**(Il2Cpp 타입 이름으로 판정, 포인터별 캐시)이면 포커스 변경으로 보지 않는다. 자체 토큰은 CTRL을 누르고 있는 동안 유지된다.
- 창이 포커스를 가진 동안에는 자체 선택 토큰의 소유권을 창에 넘긴다(`selectionToken=0`, `HANDOFF_NPC_WINDOW` 기록). 이렇게 하면 CTRL을 떼도 모드가 선택을 닫지 않는다. 창이 닫힐 때 원본 `CloseHook`이 선택을 반환한다.
- 창이 열려 있는 동안에는 모드의 재선택 호출을 멈춘다. `acceptedFocus`는 창 포인터로 바꾸지 않는다. 창이 닫혀 항해 화면으로 돌아오면 CTRL을 누르고 있는 동안 기존처럼 재선택한다.
- 그 밖의 창(메뉴, 교역 화면 등)으로 포커스가 넘어갈 때는 0.1.2와 같이 자체 정지를 해제한다. 장면 변경, 전투, 앱 포커스 상실, 키 해제 때의 해제도 그대로다.
- 0.1.4의 지연 등록 진단 21개는 그대로 유지한다(검증용).
