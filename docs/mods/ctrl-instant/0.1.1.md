## 기록 내용

- `PHYSICAL_DOWN`, `PHYSICAL_UP`, `HELD`: 좌/우 CTRL 상태. 관측 전용. 누름 중 초당 1회.
- `DISPATCH`: 공통 원본 입력 에이전트가 받은 CheckTarget phase, 에이전트 타입·유효성·포커스.
- `START`, `START_REJECT_*`: 항해 UI 시작 콜백과 시작 조건. 장면 진입/로딩/항해/전투/플레이어 함대/함대 상태/모델/뷰/입력 활성/포커스/기존 정지를 각각 기록.
- `PERFORM`, `END`: 지연 Hold 성립, 원본 처리 차단 여부, 해제 전달.
- `PAUSE_ACQUIRED`, `RELEASE_*`, `FORGET_LIST_CHANGED`, `UI_CLOSING`, `SAILING_EXIT`, `NATIVE_RESET`: 토큰 ID, 목록 개수, 전체 정지 여부, 선택 상태, 해제 전후 및 수명주기.
- `ERROR`, `snapshot-error`: 관측이나 기능 예외. 오류만으로 정지 원인을 추정하지 않는다.

벽시계와 Stopwatch 경과 시간을 함께 기록한다. 실행당 최대 6,000줄, 자동 flush. 로그 파일 쓰기 실패는 게임 입력으로 전파하지 않으며 MelonLoader 로그로도 출력한다. 로그는 게임 데이터를 수정하지 않는다.
