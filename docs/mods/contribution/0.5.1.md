# Contribution 0.5.1 — 확인 버튼 반응과 소리

2026-09-19. 알림 확인 버튼에 마우스 진입 밝기, 누르는 동안 어두워짐/글자 2px 이동, 벗어나거나 놓으면 원복을 추가했다. 실제 onClick에만 원본 `CommonSoundUtils.SpecialClick()`을 한 번 호출한다. 음향 예외는 기록한 후 확인 처리를 계속한다. 누르기/취소만으로는 소리가 나지 않는다.

현재 설치 0.5.0 SHA256 `CCED1CFD8720A588567D7E05B8FB7D1C954A8A720F4BBB799075386D4AD272E7`를 확인하고 `Contribution/releases/0.5.0/installed-before-0.5.1.dll`에 백업했다.

[확인된 원본 본문] 현재 GameAssembly의 SpecialClick RVA 0x9F26C0 길이 0xF5는 `UI_Common_choose_01` Sound template을 조회하고 SoundManager.AudioPlayer.PlayAudio로 재생한다. 기존 도시/설정/목록 선택 및 UIGovHouseLicenceView.OnClickLicence 등에서 사용하는 공통 선택음이다. 모든 기본 확인 버튼과 동일한 소리라고 판단한 것은 아니다. [본문](../../../Contribution/releases/0.5.1/SpecialClick.asm), [문자열](../../../Contribution/releases/0.5.1/sound-literals.txt). onRollOver/onRollOut/onTouchBegin/onTouchEnd는 현재 interop API 확인 후 사용했다.

[관리 검증] Release 경고/오류 0. 실제 Overlay 소스의 오프라인 GDI 대역 27개 통과: 기존 배치/스크롤/확인/수명주기에 누름/이탈/해제 원복, 취소 무음, 클릭 1회 재생, 음향 실패시 확인 완료를 추가했다. 컴파일 IL의 공헌도 쓰기/회수 없음 검사 통과. 게임/Steam은 실행하지 않아 실제 클릭 소리·음량·터치 반응은 사용자 확인 전이다.

기존 14개 훅/저장 v3/정렬/인식 정책 유지. 추가는 자체 버튼 이벤트와 원본 음향 호출뿐이며 새 Harmony 훅·음량 설정 변경 없음. 배포 경로는 `Mods/Additional_Functions/Restitutor_Additional_Contribution_Goods_Recognition.dll`, 설치 검증은 `Contribution/releases/0.5.1/validation.txt`.
