# Contribution 0.5.4 — 도시 메인 화면 전용 혜택 HUD

사용자 요청: 술집 여급 등을 가리지 않도록 도시 메인에서만 혜택 창 표시. 알림/상품 인식/혜택 처리는 유지.

HarborHud는 UIManager.CurrentFocusViewCtrl을 IL2CPP TryCast<UIHarborCtrl>로 읽는다. Harbor 인스턴스를 새로 생성하지 않는다. 열린 controller, Model.CtrlShowMainUI == 1, 살아 있는 View/UIContent 및 stage 부착, 부모/group 표시를 모두 확인. 다른 시설/메뉴로 포커스가 넘어가면 HUD만 숨긴다. 조회 예외는 HUD 숨김과 중복 억제 오류 로그로 처리한다.

Overlay.SetHudVisible을 별도 도입하고 Draw/재구성 후에도 이 상태를 존중한다. 기존 SetVisible의 도시 전체 표시/모달 정책 유지. EntryPoint는 도시 조건 뒤 HUD 조건만 별도 적용하며 Engine.Apply와 알림 Draw 경로는 그대로 실행. 후킹 14개/입력 차단/저장 v3/공헌도 정책/이미지 재질 변경 없음.

OnChangeMainUI 0x961CC0은 값1에서 PlayAni 호출. 현재 본문을 releases/0.5.4에 보존. 실제 interop 참조 빌드로 API 대조.
