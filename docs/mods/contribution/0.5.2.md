# Contribution 0.5.2 — 이미지 재질 소유권과 로드 수명주기 수정

2026-09-19. 사용자 실행에서 0.5.1 이미지가 깨지고 Unity ApplyClippingProperties 예외가 반복됨을 확인했다. [이전 분석](../../../analysis/contribution-ui-render/REPORT.md).

## 변경

GImage마다 지원되는 현재 ShaderConfig.imageShader로 전용 Material을 만들어 명시적으로 지정한다. _ClipBox/_StencilComp 속성을 확인하고 texture를 연결한다. HUD와 스크롤 내부 이미지가 서로 다른 clipping 값을 공유하지 않도록 material은 이미지마다 독립 소유한다. 전역 ShaderConfig/게임 재질은 수정하지 않는다.

Texture2D와 자체 Material에 HideAndDontSave를 지정하여 사용 중 자동 자원 정리에서 보호한다. 이미지 컴포넌트 폐기 후 해당 material을 Destroy한다. HUD/알림 목록 갱신 때 폐기된 이미지의 material을 정리한다. 저장 로드/플레이어 초기화 Reset 때 UI 폐기 → material 정리 → 아이콘/texture 캐시 폐기를 수행하여 이전 native cache를 재사용하지 않는다. 화면 해상도 변경만 있을 때 texture는 재사용한다.

지원되지 않거나 clipping 속성이 없는 shader는 화면에 붙이기 전에 실패시킨다. 실패 material/image를 정리하며 도시 갱신 예외도 부분 생성 UI를 Clear한다. 게임 데이터/해금/인식/알림 순서/확인음/기존 14개 훅은 유지한다.

## 근거와 검증

현재 NGraphics.set_material 본문 0xD45DF0은 사용자 material을 설정하고 _ClipBox 존재시 flags에2를 설정한다(0xD460BF~0xD460D1). Update 본문0xD47010은 자체 material 경로에서 유효성 확인 뒤 ApplyClippingProperties를 호출한다(0xD47262~0xD47348). 직접 private flag 변경 없이 원본 setter를 사용한다. [setter](../../../Contribution/releases/0.5.2/set-material.asm), [Update](../../../Contribution/releases/0.5.2/graphics-update.asm).

Release 오류/경고0. 실제 UiAssets 소스를 사용하는 API 대역검사12개(독립 material, 연결, 자동 정리 제외, 개별 폐기, unsupported shader/clip 실패 정리, Reset 후 새 texture, 중복 정리) 통과. 기존 Overlay 배치/입력 대역27개 통과. IL 공헌도 쓰기/회수 없음 통과. 이것은 Unity 실행 검증이 아니다.

0.5.1 설치 해시 `6876EDCC24DEF1DB9F3261C4DE1DBCBF53B0C46598E0B58F35D4140186BE20CB` 확인·백업 후 같은 설치 파일명을 0.5.2로 교체한다. [검증/설치 해시](../../../Contribution/releases/0.5.2/validation.txt).

실전 정상화는 사용자 재실행 전 미확인. 최초 도시 표시 → 공헌도 상승 알림 → 저장 재로드 후 반복을 확인해야 한다. 지원 shader 검사에서 실패하면 정확한 원인이 City update 로그에 남는다. 이번 수정은 관측된 material 렌더 실패 경로와 확인된 캐시 수명주기 취약점을 변경한 것이며, 이전 실행에서 자원 자동 해제가 실제 원인이었다고 확정한 것은 아니다. 게임과 Steam은 실행·조작하지 않았다.
