# Contribution 0.3.1 — 신규 자원 등록 후 교역품 인식

사용자 요청: 신규 자원 발견 인식 추가, 기존 발견 자원 보충 처리 금지. 기존 최초 방문/최초 공헌도 100 정책은 유지한다.

## 확인한 원본 및 변경

[원본 분석](../../../analysis/contribution-natural-resources/REPORT.md). 설치 GameAssembly SHA256 `50D53D17829E3E77B9786EA42D998D1AD258F0653846524069F22E5E442EFFCA` 재확인.
탐사 ENActionAddNature.ExecuteHook의 0x2595495가 WorldPortHoldDB.AddNaturalResources(int portId,int resourceId)를 직접 호출한다. AddNaturalResources(0xB7A210)는 중복이면 false, 신규 자원 효과 호출 및 등록/DB dirty 후 true를 반환한다.

- AddNaturalResources Postfix 1개 추가, 총 14개 훅. 성공 반환, 현재 플레이어/WorldPort DB 일치, 해당 resourceId의 실제 등록을 모두 확인해 도시 공개 예약을 추가한다. 원본 실행/인수/반환은 유지한다.
- Postfix에서는 상품 조회/해금을 하지 않는다. 기존 OnUpdate 도시 장면 준비 및 대상 도시 체류 조건을 통과하면 기존 허가 적용 → CargoDiscovery → 통합 알림 흐름을 사용한다.
- 다른 새 자원 등록은 다시 예약할 수 있다. 중복 자원 실패 반환은 무시하며 최초 100 이력은 변경하지 않는다.
- 기존 자원 순회, 로드/재입장 보충 처리, 주기적 전 도시 탐색은 추가하지 않았다. 과거 누락 자원에 대한 별도 보충은 없다. 이벤트가 발생한 도시에서 기존 CargoDiscovery의 원본 시장 인식 범위는 유지한다.
- 저장 v3 유지. 기존 공개 예약과 보류 알림의 저장/로드 경로를 사용한다. 입력/시장 UI/지도 패치 변경 없음.
