# Contribution 0.5.3 — 설치 셰이더 속성/변형 대조 수정

사용자 0.5.2 실행 로그 21:06:22.312에서 UiAssets.Bind의 `Image shader does not support FairyGUI clipping: FairyGUI/Image` 확인. 0.5.2의 HasProperty(_ClipBox) 필수 검사가 화면 생성을 거부했다.

현재 설치 resources.assets의 Shader path_id71을 UnityPy로 읽었다. 실제 이름 FairyGUI/Image, ShaderLab 속성은 _MainTex, _StencilComp, _Stencil, _StencilOp, _StencilWriteMask, _StencilReadMask, _ColorMask, _BlendSrcFactor, _BlendDstFactor이며 _ClipBox가 없다. 반면 export에는 CLIPPED/SOFT_CLIPPED/NOT_CLIPPED 변형이 있다. 즉 HasProperty(_ClipBox)를 클리핑 지원 판정으로 사용할 수 없다. [직렬화 근거](../../../analysis/contribution-ui-render/shader-71.json), [export](../../../analysis/contribution-ui-render/FairyGUI-Image.shader.txt).

0.5.3은 잘못된 필수 검사를 제거하고 현재 셰이더에 존재하는 stencil 속성 확인만 유지한다. 독립 material에 설치된 변형 조합 NOT_COMBINED/NOT_GRAYED 및 HUD NOT_CLIPPED 또는 목록 아이콘 CLIPPED를 설정한다. 원본 custom material 경로의 flags2를 자체 이미지에만 명시하여 ApplyClippingProperties의 uniform 갱신을 사용한다. 원본 setter가 HasProperty(_ClipBox)에 의존하는 자동판정을 보완한다. 0.5.2에서 추가한 자체 재질/texture 소유권 및 Reset 정리는 유지한다.

현재 자원에서 추출한 속성 차이를 반영한 실제 UiAssets 대역검사16개, 기존 Overlay 대역27개 통과. Release 경고/오류0. 이는 Unity/GPU 실전 검증이 아니며 0.5.3 화면 정상화는 사용자 재실행 전 미확인. 이전 분홍색의 유일한 원인을 확정한 것은 아니다. 게임/Steam 실행·조작 없음. 14개 훅/저장/인식/알림 정렬/확인음 유지.
