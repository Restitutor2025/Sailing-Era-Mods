# Contribution 0.2.0 — 상승 전용

2026-09-18. 사용자 요청: 하락 관련 효과를 DLL에서 삭제하고 상승으로 얻는 것만 확인한다. 이전 회수 오류를 수정하는 작업은 취소했다. 중간 0.1.1 소스는 archive/0.1.1-unreleased에 보존하며 배포 버전이 아니다.

## 변경

Observe는 after <= before에서 반환한다. 기준을 아래에서 위로 통과하고 아직 열리지 않은 혜택만 예약한다. 이미 예약한 획득은 이후 하락으로 취소하지 않는다. Apply는 획득 예약만 재검사해 AddGovHouseLicenceData를 호출한다. 기존 혜택은 중복 추가하지 않는다.

CommerceEffects, FleetStops, MonthlyReport, RetainedGoods, TradeLicences, TradeRepairRules를 현재 소스 및 DLL에서 제거했다. 허가/효과 제거, 시장 필터·거래 차단, 상회 폐쇄·투자 환불, 선단 제어와 보고서 훅은 없다. 원래 게임의 다른 원인에 의한 효과 종료까지 전역 차단하는 패치는 아니다.

부가 저장 v1의 Pending 중 Original=false/Target=true이며 ID가 일치하는 항목만 가져온다. 회수·시장·선단 상태와 v1 알림은 복원하지 않는다. v2는 획득 예약과 새 알림만 저장한다. 이전 DLL이 실제 저장에 이미 반영한 제거 상태는 자동 복구하지 않는다.

## 근거와 검증

- 사용자 화면/로그: 치트 100→50 실제 반영 후 기존 Contribution의 RemoveGovHouseLicenceData 경로에서 NullReferenceException 발생, 백자 상품은 여전히 표시됨. 이는 사용자 실행 보고이며 새 버전 실행 결과가 아니다.
- 설치 GameAssembly SHA256: 50D53D17829E3E77B9786EA42D998D1AD258F0653846524069F22E5E442EFFCA. audit.py가 현재 등록한 12개 대상의 메타데이터 및 본문을 다시 추출했으며 RVA 중복/별칭 없음.
- Release 빌드 성공, 경고/오류 0. RulesTests 176개 통과: 상승/하락/동일 값, 이미 열린 혜택, 예약 유지·중복 방지, 이전 혼합 기록 필터와 복사 독립성.
- audit-il.ps1: DLL에 공헌도 쓰기 호출, 제거 함수 호출, 폐기한 하락 처리 타입 없음.
- 게임/Steam 미실행. 실제 후킹, UI, 저장 재로드와 타 모드 병용은 사용자 검증이 필요하다.

[현재 패치](PATCHES.md). 과거 0.1.0 문서 및 tests는 보존하며 과거 양방향 정책 테스트는 현재 버전의 실행 대상이 아니다.
