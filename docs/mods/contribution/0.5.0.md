# Contribution 0.5.0 — 사진 기준 화면 변경

2026-09-19. 도시 혜택은 사용자 2번 이미지, 교역품 확인·해금 알림은 1번 이미지 기준으로 변경했다. 교역품 확인을 전부 먼저 표시하고 해금 전체를 뒤에 표시한다.

## 실제 설치 기준 확인

작업 시작 때 CURRENT의 0.3.1과 달리 설치 DLL은 0.4.0.0이었다. SHA256 `167A2A1BEE00C4D12EB4695B0657C36AFBA6B47BBCFE8B42BE0FB9089B766BC3`.
설치 DLL을 dnSpy 라이브러리로 역컴파일하여 기존 0.3.1 역컴파일과 대조했다. Token/RVA/File Offset 주석 제거 후 다른 타입은 EntryPoint와 Overlay뿐이었다. EntryPoint는 버전 로드 로그 차이, Overlay는 화면 디자인 변경이다. Engine, CargoDiscovery, LiveViews, Rules/Journal, SaveState 본문은 같다. 해당 결과는 `Contribution/exports/Contribution-0.4.0-installed-dnSpy`에 보존했다. 설치 백업은 `Contribution/releases/0.4.0-installed/installed-before-0.5.0.dll`.

## 변경

- 금색 테두리·청록색 제목판·양피지 배경 도시 HUD, 아이콘·색상별 상태 표시. 역참이 있는 도시의 역참 행 유지. 실제 Engine.Status 값을 사용하고 긴 값에 따라 행 높이 조절.
- 금색 밧줄·남색 제목판 알림, 상품 상자/해금 두루마리 아이콘, 드래그 목록·현재 위치 스크롤바·확인 버튼.
- NoticePresentation은 모든 미확인 알림의 표시 행을 안정 정렬한다. 교역품 확인 → 해금 → 기타 안내 순서, 각 묶음 내부 원래 순서와 도시 연결 보존. 저장된 Notice/Lines는 변경하지 않는다. 여러 도시가 섞일 때 도시명을 각 행에 표시한다.
- 이미지 3개를 DLL에 포함하여 별도 외부 파일 설치가 필요 없다. 최초 로드 후 texture 캐시 사용, 모드 해제 때 자체 자원 반환. [아트와 프롬프트 요구사항](../../../Contribution/assets/README.md).
- 도시 준비·혜택 적용·교역품 인식 순서, 최초 방문/최초100/신규 역참 자원 이벤트, 과거 자원 보충 없음, 저장 v3는 유지한다.

## 확인 및 한계

[확인된 관리/정적 근거] Release 빌드 경고/오류 0. 규칙·인식·표시 정렬 196개, 기존 해금/UI/저장/자원 대역 54개 통과. 실제 Overlay.cs를 실행하는 별도 GDI 대역 21개에서 긴 값/역참 행, 정렬, 드래그 상하단 제한, 화면 크기 변경시 UI 정리, 확인/입력 해제를 검사했다. 1600×1000 및 1280×720 미리보기를 생성해 버튼 위치를 수정하고 재확인했다.

[확인된 메타데이터/본문 대조] 현재 interop로 Unity ImageConversion·NTexture·GImage·DrawRoundRect API를 확인하고 빌드했다. 14개 기존 네이티브 패치 대상 RVA 별칭 없음. GameAssembly SHA256 `50D53D17829E3E77B9786EA42D998D1AD258F0653846524069F22E5E442EFFCA` 유지. 컴파일 IL에 공헌도 쓰기·혜택 회수 호출 없음.

[실전 미확인] 게임과 Steam은 실행·조작하지 않았다. PNG는 오프라인 대역 미리보기이며 실제 Unity/FairyGUI 렌더·텍스처 생성·폰트·터치·다른 모드 병용 성공 증거가 아니다. 사용자 실행 시 도시 HUD, 여러 상품+해금의 알림 순서, 끝까지 드래그 후 확인 및 출항/재입항을 확인해야 한다.
