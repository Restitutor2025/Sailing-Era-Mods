# Restitutor_fixes.dll 0.1.0
## 만든 이유
게임 시작 로고와 건강·면책 안내 대기를 줄이기 위한 최초 기록 버전.
## 당시 구현
기존 README는 Unity SplashScreen.StopImmediate, 안내 두 객체의 포인터 식별, Transition._Play Prefix 차단 및 완료 콜백, 다음 Update의 SkipDeal 재개를 설명한다.
## 근거와 한계
[당시 README](../../../README.md), [초기 조사](../../../analysis/INTRO_FINDINGS.md). 보관 파일 analysis/intro-evidence/Restitutor_fixes.before-contract-cleanup.dll의 파일 버전은 0.1.0이다. README와 보관 DLL의 세부 구현 일치 여부는 이번 문서화에서 역컴파일 검증하지 않았다.
당시 README에는 Release 오류/경고 0, 게임 실행 미검증으로 기록되어 있다.
## 후속 이슈
현재 0.1.2 소스는 콜백만 완료할 때 표시 상태가 미완료로 남는 문제와 약관 패널 잔여 표시를 처리한다. 각 수정이 정확히 어느 중간 버전에 처음 들어갔는지는 확정하지 않는다.
## 유지 지침
원래 시작 초기화와 완료 흐름을 보존한다. 최초 로고부터 모두 없어지는지는 모드 초기화 시점에 달려 있으므로 사용자 확인이 필요하다.
