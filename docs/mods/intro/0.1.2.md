# Restitutor_fixes.dll 0.1.2
## 이슈와 수정 목적
현재 소스 주석에서 확인되는 문제는 안내 완료 콜백만 호출할 때 타임라인의 표시·알파·컨트롤러 상태가 끝나지 않는 것, SkipDeal 이후 GroupDeal이 남아 메뉴 입력을 막는 것이다. 0.1.1 대비 정확한 변경 경계는 자료 부족으로 미확인이다.
## 현재 구현
- 등록한 건강/면책 Transition만 _Play Postfix에서 Stop(true,true)로 완료시킨다.
- 다음 Update에서 원래 SkipDeal을 호출해 재진입을 피한다.
- 실제 안내 생략이 발생한 launch에 한정해 GroupDeal.visible을 정리한다. UpdateHook와 LateUpdate에서도 잔여 표시를 확인한다.
- 약관 Confirm/Refuse나 동의 저장 플래그를 변경하지 않는다.
- Unity 스플래시 중단, 종료 시 포인터 정리, 패치 설치 실패 시 해제를 포함한다.
## 근거
[src/IntroSkipMod.cs](../../../src/IntroSkipMod.cs), [csproj](../../../Restitutor_fixes.csproj). 소스 MelonInfo와 현재 빌드 파일 버전 모두 0.1.2. 루트 README의 Prefix 설명은 이 버전 구현과 다르다.
## 검증
사용자 제공 로그에 안내 생략·패널 정리·원래 흐름 재개 메시지가 있다. 모든 시작 조건에서 정상이라는 증거는 아니다. 이번 문서화에서 재빌드/게임 실행은 하지 않았다.
## 사용자 확인 / 유지 지침
메뉴 입력, 필요한 언어·감마·약관 흐름을 확인한다. 타이틀/세이브/게임 원본 파일을 수정하는 모드로 확대하지 않는다.
출력: bin/Release/net6.0/Restitutor_fixes.dll.
