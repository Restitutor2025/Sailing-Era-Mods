# Restitutor_fixes.dll 0.1.1 — 이력 미확인

## 상태
버전별 이력을 정리하기 위한 미확인 항목이다. 이 문서 생성은 해당 번호의 빌드·배포 사실을 입증하지 않는다.

## 새 버전을 만든 이유 / 수정 내용
해당 버전의 소스 스냅샷·확인된 DLL·변경 기록을 찾지 못해 확정할 수 없다. 현재 구현을 이 버전의 변경 내용으로 추정해 기록하지 않는다.

## 검증 / 후속 작업 지침
당시 빌드·테스트 결과도 미확인이다. 추후 원본 DLL, 소스 또는 대화 기록이 확보되면 버전과 변경 이유를 대조하여 이 문서를 보완한다.
현재 확인 가능한 구현은 [최신 문서](0.1.2.md)를 따른다.
