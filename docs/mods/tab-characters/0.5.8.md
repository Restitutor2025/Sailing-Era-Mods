## 변경
- `TickBooks`에서 물리 Space(`Keyboard.current.spaceKey.wasPressedThisFrame`)를 확인한다. 기존 Esc·우클릭 닫기와 같은 방식이다. 조건: 패널 열림, 게임 창 포커스, FairyGUI 텍스트 입력(`InputTextField`)에 포커스 없음.
- 기존 `Action_A` 경로는 유지한다(패드 확인 버튼 등). 두 경로는 `ConfirmLearn` 하나로 합쳐졌고, `confirmLatch`로 한 번 누를 때 1회만 학습한다. 래치는 Space와 `Action_A`가 모두 떼어진 뒤 해제된다. 마지막 1권을 쓴 뒤 다음 책이 자동 선택돼도 누르고 있는 동안에는 이어서 학습하지 않는다.
- `LearnBlock()`: 학습 가능하면 null, 아니면 사유(패널 무효/처리 중/선택 없음/재고 없음/원본 판정 번호). `Commit()`은 기존대로 다시 전부 확인한다.
- 로그: `Characters learn by physical Space|Action_A`, 불가 시 `Characters learn key ignored (<경로>): <사유>`. 누를 때만 1줄.
- F·마우스·포인트·닫기 변경 없음. 20개 훅 유지.

## 검증
- PopupTests 추가: 물리 Space 1회 학습·마지막 권 삭제 후 다음 책 선택, 누른 채로는 다음 책 미학습, 같은 누름의 Action_A 중복 방지, 떼고 다시 누르면 다음 책 학습, 텍스트 입력 포커스 중 무시, 학습 불가 책 무시, 패널 닫힘 시 무시. 대역에 `Keyboard.spaceKey`, `Stage.focus`, `InputTextField` 추가.
- 빌드·테스트는 사용자 build.ps1 결과로 확인. 게임/Steam 미실행, Mods 자동 교체 없음.

## 사용자 검증
배울 수 있는 책(빨간 사유 문구 없음, 버튼 보임) 선택 → Space. 반응이 없으면 Latest.log의 `Characters learn` 줄을 확인·보존한다. `ignored` 사유가 나오면 판정 문제, 줄이 아예 없으면 키 입력 자체가 모드에 도달하지 않은 것이다.
