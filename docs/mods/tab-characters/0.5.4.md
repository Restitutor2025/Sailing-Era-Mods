# Tab Characters 0.5.4 — 공용 FeatureUI 승격 제거

## 원인과 근거
[실행 영상/0.5.3 로그 분석](../../../analysis/video-review/1640-analysis.md): 두 창이 visible=True인 채 FeatureUI가 0→32760으로 승격되어 overlay(32000), 포인트 표시(31900), 치트(25000)보다 앞에 놓였다. parent=null 시에는 안내 자체를, 연결된 상태에서는 공용 부모를 선택하던 코드가 문제였다.

## 변경 및 수명
- 부모를 따라 올라가는 루프 제거. 실제 재생 중이며 부모에 연결된 원본 UITips content만 GRoot 직계 자식으로 임시 이동, sortingOrder=32760.
- FeatureUI 및 다른 부모/형제의 sortingOrder는 쓰지 않는다. 별도 메시지나 안내 그래픽을 만들지 않는다.
- 기존 content 부모/형제 인덱스/정렬/touchable 보관, 임시 touchable=false로 입력 통과. 원본 AniTips 2배 속도 유지.
- 이동 동안만 AniTips._options에 OPTION_AUTO_STOP_DISABLED를 OR하고 finally 복원. 원본 완료 콜백/재생 호출은 교체하지 않는다.
- 종료/새 안내/정리에서 속도·정렬·touchable 복원. 아직 자체 GRoot 배치에 남아 있으면 원래 부모/형제 위치 복원. 원본이 이미 분리한 content는 재부착하지 않는다. 원래 부모가 폐기됐으면 자체 배치에서 분리하며 native 객체는 Dispose하지 않는다.
- 새 훅 없음(20개), 기존 제한된 진단 유지. 책/포인트 저장 호출 변경 없음.

## 원본 재대조
현재 GameAssembly SHA256 50D53D17829E3E77B9786EA42D998D1AD258F0653846524069F22E5E442EFFCA 일치.
설치 바이너리 Transition.OnOwnerRemovedFromStage RVA 0x181FB50: options bit 2가 켜지면 Stop을 호출하지 않음. OnOwnerAddedToStage RVA 0x181FB00: 이미 playing이면 Play 호출하지 않음. [보존 본문](../../../TabCharacters/evidence/0.5.4/native/OnOwnerRemovedFromStage.asm), [추가 본문](../../../TabCharacters/evidence/0.5.4/native/OnOwnerAddedToStage.asm).
UITipsView.HideHook 기존 본문도 재검토. 실제 native UI 관리자/다른 모드와 이동 후 병용은 사용자 실행 확인 전이다. 프레임별 native 수명주기를 관리 대역으로 완전히 재현했다고 주장하지 않는다.

## 검증
Release 경고/오류 0. 관리 대역 11,509 + 2,314 = 13,823 검사 통과. 공용 부모 있음/없음 교대 4회, 준비 중 무변경, 안내만 승격, 공용 부모/형제 유지, 입력/옵션/속도 복원, 원본 종료 후 재부착 방지 검사 추가. 20개 훅/309개 API 참조 및 시작 그래프 5개 메서드 통과. [빌드 근거](../../../TabCharacters/evidence/0.5.4/).
게임/Steam 미실행, Mods 자동 교체 없음. 실제 개선 여부는 사용자 확인 전.

## 사용자 검증
