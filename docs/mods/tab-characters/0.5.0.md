# Tab Characters 0.5.0 — 바깥 클릭 닫기·버튼 입력·원본 알림

2026-09-20. 사용자 스크린샷과 최신 조작 요청 반영. [실행 보고 화면](../../../TabCharacters/evidence/0.5.0/user-report). 0.4.1에서 인접 패널이 열린 화면 및 포인트 사용 후 자체 알림을 확인할 수 있으나 전체 기능 성공으로 확대하지 않는다.

## 닫기와 버튼

두 창 뒤에 색이 없는 입력용 사각형을 둔다. 왼쪽 버튼을 누른 위치가 원본 정보 컨테이너와 학습 컨테이너 모두 바깥이면 두 창을 닫고 Stage.CancelClick으로 해당 클릭의 후속 처리를 취소한다. 숨겨진 스킬/메뉴가 같은 클릭으로 실행되지 않는다. 어느 창 안이든 닫지 않는다. 판정은 Stage.touchPosition을 각 창의 로컬 좌표로 변환하므로 배율과 위치를 반영한다. 기존 우클릭/Esc/취소 입력 유지. 바깥 클릭은 먼저 닫는 동작이며 이후 클릭으로 다른 스킬을 선택한다.

포인트 버튼 문구는 `스킬 레벨 +1`. 마우스를 올리면 파란색 수직 그라데이션과 테두리 강조, 누르면 밝기 강조 및 글자 위치의 작은 이동을 적용한다. 그라데이션은 비입력 그래프 16개로 생성하며 배치·가시성은 버튼에 따른다.

onTouchBegin은 왼쪽 버튼만 받아 CaptureTouch하고 활성 상태를 보관한다. 이 단계에서는 포인트를 쓰지 않는다. onRollOut 또는 밖으로 이동한 onTouchMove는 누름 상태와 효과를 취소한다. 다시 들어와도 취소된 누름은 복구하지 않는다. onTouchEnd에서 왼쪽 버튼·취소되지 않은 누름·버튼 안의 위치·현재 사용 가능 조건을 모두 확인한 경우에만 기존 SpendSkillPoint를 실행한다. 뒤따르는 onClick은 소비만 하며 두 번 적용하지 않는다. 포인트 없음/최대 레벨에서는 입력과 강조를 비활성화한다. 기존 인물 동일성/잔여량/같은 프레임 중복 검사 유지.

## 원본 학습 알림

자체 GComponent 알림·배경·3초 타이머를 제거했다. 기존 UITipsCtrl.ShowBaseTips 훅은 원본 호출을 항상 허용하며, 자체 학습 Committing 범위일 때만 원본 View를 추적한다. 원본 알림의 텍스트/이미지/표시/종료 콜백을 그대로 사용한다. 책 학습은 원본 메시지 인수를 유지하고, 포인트 학습 성공은 같은 원본 ShowBaseTips로 스킬 상승 문구를 전달한다.

원본 base 알림 상태(CtrlSelect=6, CtrlBaseSelect=1)를 확인한 뒤 AniTips.timeScale을 기존 값의 2배로 설정한다. 별도 타이머로 강제 삭제하거나 애니메이션을 다시 시작하지 않는다. 아직 생성되지 않은 View는 Update에서 잠시 기다려 적용한다. 시작 대기는 최대 2초이며 재생이 시작된 뒤에는 playing 종료를 따른다.

원본 알림의 GRoot 직계 조상 sortingOrder를 일시적으로 32760으로 높여 학습 패널 위에 표시한다. 종료·다른 알림·다른 표시 모드·메뉴 정리 때 기존 재생 속도와 순서를 복원한다. 다른 일반 알림은 속도를 변경하지 않는다. 패널만 닫을 때에는 진행 중인 원본 알림을 계속 재생한다.
