## 사용자 결정 (2026-09-20)
- 인물 창 왼쪽 아래 장비 4칸을 클릭하면 원본 장비창의 **한 줄 4칸 목록**이 오른쪽에 말풍선처럼 뜬다. 선택한 칸은 노란 테두리로 표시한다.
- 패널 폭 약 600: 왼쪽 목록(필터 포함) | 오른쪽 장비 설명·속성.
- 마우스를 올린 장비의 스킬 변화는 인물 창 스킬 목록에 원본처럼(`Lv.1 +1`, 증가는 초록) 표시한다. 가려질 수 있으므로 **변화가 있는 스킬만 패널 오른쪽 작은 상자에 따로** 보여 준다. HP·공격·속성 변화(예: 537/337 빨강)도 인물 창 오른쪽 위 수치에 표시한다.
- 우클릭: **선택한(노란) 칸 위에서 우클릭하면 그 칸의 장비를 해제**. 목록 항목 위에서는 원본처럼 그 항목(착용 중이면)을 해제. 그 밖의 곳에서는 패널을 닫는다.
- Space: 원본처럼 마우스가 올라간 목록 항목을 장착/해제. 필터 목록이 열려 있으면 필터 적용.
- 다른 인물이 착용 중인 장비를 고르면 원본처럼 가져온다.
- 필터 포함. 상단 장비 탭은 유지한다.

## 원본 근거 요약 [본문]
- 장비 시트는 인물 시트와 같은 Ctrl/Model/View를 쓴다(SheetType 인물 0, 스킬 1, 장비 2).
- `OnClickBtnListEquip`·`OnListEquipRollOver`·`InitEquipPropChange`는 SheetType==2가 아니면 아무것도 하지 않는다. `InitEquipPropChange`는 게이트 전에 `ListPropEquip`을 비운다.
- `OnTakeOffEquip`: CurFoucType==3이면 `CurHeroEquip[WearEquipIndex]`, 아니면 `ListFilterEquip[EquipIndex]`를 해제(WearRoleId≠0일 때), `IsSelectEquipFilter`면 무시.
- `PlayerEquipDB.PutOnEquip(guid, roleId, slot)`: 다른 인물이 착용 중이면 먼저 해제, 칸에 기존 장비가 있으면 해제 후 착용.
- `ChangeCurRoleIndex`: 시트와 무관하게 CurHeroEquip·RefreshTipsRoleInfo·MarkDirty. CurFoucType==4 또는 `_isSelectBook`이면 가상 호출(vtable 0xA08, 대상 미확인)을 한다.
- `RefreshPropChangeEffect`: ListPropEquip에서 PropertyType 23(스킬)은 `RefreshSkillPropEffect`(content.listSkill 행), 나머지는 `RefreshPropEffect`(content.roleInfo: HP·공격·속성). 게이트 없음.
- `RefreshSkillPropEffect(skillId, value)`: 행 번호=DictSkill[skillId], addLevelState = value<0 ? 0 : 2, isAdd = (value+장비 보정) > 0, texAddLevel = 합계>0 ? "+합계" : "".
- 인물 시트 스킬 행(UIBtn_SkillItem, `RenderListBtnSkill`): isAdd = 보정>0, texAddLevel = 보정>0 ? "+보정" : "" (같은 서식 문자열).
- 인물 시트 장비 칸(`RenderListEquipShow`)은 아이콘만 그리고 이벤트가 없다. 칸 번호 = CurHeroEquip 키.
- `PlayChangeEquipAni`: 장비 시트 자체의 착용 칸 목록 `listEquipWear.GetChildAt(WearEquipIndex)`를 범위 확인 없이 읽는다.
- `UICharacterView.Refresh`는 SheetType별로 하나의 시트만 갱신한다(0이면 RefreshSheetCharacter).
- `UIModel.MarkDirty`: dirty 플래그와 정적 대리자 호출. 동기 Refresh 여부는 본문으로 확정하지 못했다 [추론: 지연 갱신] → 진단 로그로 확인(아래).

## 구현 [소스]
- 새 파일: `src/EquipPanel.cs`(연결·입력), `src/EquipPanelUi.cs`(상태·동작), `src/EquipPanelLayout.cs`(배치·빌린 위젯), `src/EquipPreview.cs`(미리보기).
- 기존 파일에는 선택적 partial 호출만 추가(`BookPopup.cs`: 설치·슬롯 바인딩·Tick·입력·행 렌더 후처리·리셋, `EntryPoint.cs`: 시트 전환/숨김/페이지/해제 시 닫기, Refresh 진단). 구현이 없으면 호출이 사라지므로 기존 대역 테스트 두 묶음은 장비 코드 없이 그대로 컴파일된다(`tests/Tests.csproj` 제외 목록에 새 파일 추가).
- 새 훅 1개: `UICharacterView.RefreshTipsRoleInfo` Postfix `EquipRoleInfoAfter`(총 26개). 패널이 열려 있고 미리보기 중일 때만 HP·공격·속성 미리보기를 다시 적용한다.
- 슬롯 클릭: Refresh 후 `SheetCharacter.listEquip`의 칸마다 기존 BookBinding으로 클릭을 붙인다. 목록 touchable은 true로 두고 해제 시 원래 값으로 되돌린다.
- 위젯: 원본 `UISheetEquip`의 loaderType·texType·comFilter·listEquip·TexTitleNoEquip, texName·TexTitleEquipCondition·listCondition·texEquipDesc·TexTitleEquipProp·listEquipProp·TexTitleNoSelectEquip를 패널로 옮긴다. 옮길 때 부모·순서·좌표·크기·배율·표시·touchable·group·relations를 보관하고 AddDisplayLock을 건다. 닫을 때 모두 되돌리고 잠금을 푼다. 시트 자체는 옮기지 않는다. 실패해도 overlay 폐기 전에 원본 위젯을 먼저 떼어 낸다.
- 목록 렌더러: 원본 `RenderListEquip` 뒤에 행의 클릭·롤오버·롤아웃 콜백만 교체(원본 콜백은 장비 시트 전용 함수라 인물 시트에서 동작하지 않음). 필터 행도 원본 `RenderListFilter` 뒤에 교체.
- 데이터: 열 때와 동작 후 `InitEquipData(PlayerEquipData)`·`InitHeroEquipData(현재 인물)`(원본 SyncPlayerDataToModel/ChangeCurRoleIndex와 같은 경로). WearEquipIndex/EquipIndex는 필드에 직접 쓴다(세터는 MarkDirty).
- 동작: 목록 클릭·Space → 원본 `OnClickBtnListEquip(i)`. 칸 우클릭 → 원본 `OnTakeOffEquip()`(CurFoucType 3). 목록 우클릭 → 원본 `OnTakeOffEquip()`(EquipIndex=i, CurFoucType 0). **이 세 호출 동안만 `_sheetType`=2, CurFoucType을 위 값으로 바꾸고 finally에서 되돌린다.** CurFoucType 4를 쓰지 않아 ChangeCurRoleIndex의 미확인 가상 호출을 피한다. 호출 전 `listEquipWear` 자식이 칸 번호보다 적으면 `numItems=max(칸+1, MaxEquipWearCount)`로 채운다(PlayChangeEquipAni 범위 보호).
- 미리보기: `_sheetType`=2 범위에서 원본 `InitEquipPropChange()`(데이터만) → content.listSkill을 렌더하지 않은 UICom_SkillItem 행 목록으로 잠시 바꾼 채 원본 `RefreshPropChangeEffect()`(0.5.x 책 패널과 같은 방식, 3D 홀더 없음). 그 행에서 추가 레벨 문구·색·isAdd를 읽어 인물 시트 스킬 행에 덮어쓰고, 원래 값을 보관했다가 복원한다. 원본이 행을 다시 그리면(RenderListBtnSkill 후처리) 보관값을 새로 잡고 다시 덮는다. 증가 색은 원본 행 색을 쓰되 초록 계열이 아니면 고정 초록(0.24,0.62,0.20). 감소는 인물 시트 행에서 원래 색(원본 addLevelState 0과 같은 의미), 오른쪽 상자에서는 빨강·`+0` 표시.
- 입력: 패널이 열려 있으면 Action_A/B/X/Y를 패널이 소비한다(누름 유지 중 입력도 소비). Action_Y=필터 열기/닫기(원본 장비 시트 OnAction_Y와 같은 상태 변경), Action_B=닫기(우클릭·Esc가 눌린 경우 제외), Action_A=확인. 물리 Esc=닫기, 물리 우클릭=위 규칙, 물리 Space=확인(1회 누름 1회). 바깥 좌클릭(밖에서 누르고 밖에서 뗌)=닫기, 다른 장비 칸을 누르고 떼면 칸 전환.
- 닫힘: 시트 전환, 창 숨김, Q/E 페이지, 인물/모델 변경, 게임 리셋, 책 패널 열기.
- 진단: 빌린 SheetType 호출 도중 View.Refresh가 실행되면 경고 `Characters equipment: view Refresh ran during a borrowed SheetType call.` 동작 로그 `Characters equipment list click|slot take-off|list take-off (slot=n)`.

## 한계·미확인
- **빌드 전.** 클라우드 작업 공간에 dotnet이 없어 컴파일하지 못했다. API 이름·시그니처는 설치 interop `Assembly-CSharp.dll`·`Il2Cppmscorlib.dll` 메타데이터를 직접 파싱해 대조했다 [메타]. 장비 코드의 대역 테스트는 없다.
- 원본 행 isAdd 컨트롤러가 색을 바꾸는지, 렌더하지 않은 UICom_SkillItem에서 색 기어가 적용되는지 미확인(그래서 초록 대체값).
- MarkDirty가 동기 Refresh를 부르는지 미확인(진단 로그로 확인).
- 필터 행·목록 행의 원본 콜백은 닫을 때 비우고, 원본 장비 탭이 다시 그릴 때 원본이 등록한다(0.5.x 책 목록과 같은 방식).
- 원본 장비 시트의 `R` 단축키가 Action_Y인지는 확인하지 않았다(OnAction_Y 본문이 필터 토글이라는 것만 확인).
- 장착 변경은 세이브에 기록된다.

## 사용자 검증
1. 인물 창에서 장비 칸 4개를 각각 클릭 → 노란 테두리, 오른쪽 패널(말풍선 꼬리), 목록 4열, 필터 표시.
2. 목록 위에 마우스 → 오른쪽 설명 갱신, 인물 창 스킬 `+N` 초록, 오른쪽 작은 상자에 변화 스킬만, HP·공격 변화 표시. 목록 밖으로 나가면 모두 원래대로.
3. 클릭/Space로 장착·해제, 다른 인물 착용품 가져오기, 착용 불가 장비 안내.
4. 노란 칸 위 우클릭 → 해제. 목록의 착용 항목 위 우클릭 → 해제. 빈 곳 우클릭·Esc·바깥 클릭·닫기 버튼 → 닫힘.
5. 필터 버튼/필터 선택, 목록 스크롤.
6. 닫은 뒤 상단 장비 탭이 정상인지(목록·필터·설명·착용 칸).
7. 책 학습 패널, Q/E, 탭 전환과 번갈아 사용.
8. Latest.log의 `Characters equipment` 줄과 경고·오류 보존.
