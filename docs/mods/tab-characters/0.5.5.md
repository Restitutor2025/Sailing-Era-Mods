# Tab Characters 0.5.5 — 학습 패널 배경 반투명, 학습 버튼 교체

작성: 2026-09-20, Claude (Cowork). 근거 등급: [사용자 보고] 스크린샷 / [소스] 이번 변경 본문 / [추론] 추정.

## 요청과 원인
- [사용자 보고] 스킬을 클릭했을 때 옆에 붙는 학습 패널이 뒤쪽 인물 정보(함대 경험치, 능력치 등)를 가린다. 사용자 결정: **패널 배경만** alpha 0.8, 글자·아이콘·버튼은 불투명 유지. 가운데 원본 스킬 정보창(infoPane)은 대상 아님.
- [사용자 보고] 학습 패널 아래 `스킬 배우기`의 글자가 버튼 테두리 밖으로 넘친다. 버튼을 눌렀다는 표시도 없다. 사용자 결정: 원본 버튼 그림을 숨기고 모드가 그리는 버튼으로 교체.
- [추론] 원인: 0.4.0부터 원본 `UISheetSkill.btnSkillUp`을 관계(relations)를 뗀 상태로 오른쪽 열에 440×60으로 강제 배치했다. 원본 버튼 내부 구성(배경·제목 위치)은 게임 에셋이라 확인하지 못했으며, 내부 요소가 새 크기에 맞게 따라오지 않은 것으로 본다.

## 변경
- `StyleCompanion`: 원본 정보창 배경을 복제한 `companionBackdrop`(GImage)에 `alpha=0.8`. 복제본이 없을 때 쓰는 자체 배경 GGraph는 채우기 색 alpha를 0.8로 그린다(테두리는 불투명). 복제 이미지 자체에 투명도가 있으면 실제 불투명도는 그 값 × 0.8이다 [추론, 에셋 미확인].
- 학습 버튼: `CreateLearnButton`/`PlaceLearnButton`/`PaintLearnButton`(BookInteraction.cs). 오른쪽 열에 440×64, 글자 26pt(`스킬 배우기`, 언어 패널은 `언어 배우기`). 글자 상자는 측정한 글자 크기로 고정해 버튼 가운데에 둔다.
  - 인터랙션은 `스킬 레벨 +1` 버튼과 같은 계약: 호버 시 파란 그라데이션·밝은 테두리, 누르는 동안 그라데이션 밝기 +0.14·테두리 2px·글자 2px 내려감, 밖으로 끌면 취소, 안에서 뗄 때만 `Stage.CancelClick` 후 다음 프레임에 `Commit()` 1회(`DrainLearnRequest`, TickBooks에서 호출). 패널이 닫히면 대기 요청도 사라진다.
  - `Commit()`은 기존 그대로 역할·가방·선택 GUID·재고·원본 책 상태를 다시 확인하고 원본 `OnClickBtnBook`을 한 번 호출한다. 책 차감은 Item Rebuild 경로 그대로.
  - 학습 불가(이미 학습·언어 가득·최대 레벨·조건 미충족)이면 버튼을 숨기고 기존 붉은 사유 문구를 표시한다(0.5.4와 같은 분기).
  - 원본 `btnSkillUp`은 오른쪽 열로 옮기지 않고 숨긴 채 원래 부모에 남는다. 닫을 때 기존 `RestoreLayout`이 표시 상태를 복원한다. 키보드/패드 확인 입력 경로(`BookUse` Prefix)는 변경 없음.
- 새 훅 없음(20개 유지). 새로 참조하는 FairyGUI 멤버: `GObject.alpha`(set), `GTextField.textWidth`(get).

[근거](../../../TabCharacters/evidence/0.5.5/).
- PopupTests에 추가한 검사: 배경만 0.8·다른 요소 alpha 1, 정보창 배경 불변, 버튼 440×64·원본 버튼 숨김, 글자 상자가 버튼 안, 호버/누름/이탈 표시, 끌어 나갔다 돌아오면 취소, 뗀 다음 프레임에 1회 학습, 후속 클릭 무시, 학습 후 버튼 숨김·숨김 상태 입력 무시, 닫기 전 대기 요청 폐기, 언어 패널 문구. 대역 `GTextField.textWidth` 추가.
- 게임/Steam 미실행, Mods 자동 교체 없음. 화면 결과는 사용자 확인 전.

## 사용자 검증
1. `TabCharacters/build.ps1` 실행 → 경고/오류·테스트 PASS·`verify_interop` PASS 확인.
2. 게임 종료 상태에서 루트 `Restitutor_Additional_Tab_Characters.dll`로 `Mods/Additional_Functions/`의 동명 파일 교체.
3. 스킬 클릭 → 학습 패널 뒤의 인물 정보가 비쳐 보이는지, 글자가 선명한지.
4. `스킬 배우기`: 글자가 버튼 안에 있는지, 호버·누름 표시, 버튼 밖으로 끌어 떼면 학습되지 않는지, 안에서 떼면 책 1권만 차감되고 학습되는지. 언어 패널도 같은 확인.
