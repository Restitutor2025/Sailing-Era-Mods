# Tab Characters 0.6.8 — 언어 줄 클릭으로 언어 학습 패널 열기

작성: 2026-09-20, Claude (Cowork).

## 증상 [사용자 보고]
- 인물 탭 언어 줄을 클릭해도 언어 학습 패널(언어 서적 목록)이 뜨지 않는다.

## 0.6.7 진단 결과 [사용자로그 22:54 실행, 0.6.7 로드 확인]
- 연결은 붙어 있었다: `texLanguage`(GTextField, 화면 (693,367)-(1219,411))와 `TexTitleCharacterLanguage`((555,365)-(627,411)) 모두 touchable=True, visible=True, bound=True. → 후보 B 배제.
- 패널이 닫혀 있을 때 언어 제목(599,397)(619,395)·언어 글자(1035,370) 누름 3회 모두 hit=`UISheetCharacter.btnReturn`(GGraph, (0,349)-(2560,1419)). → 후보 A 확인.
- `click received` 줄 0회, `open skipped` 줄 0회. → 클릭이 핸들러에 도달하지 않음. 후보 C는 도달 전이라 판단 대상 아님. `Book popup stopped` 없음.
- 스킬 패널이 열린 상태의 누름 1회(866,391)는 패널의 바깥 닫기 층이 받았고 설계대로 패널을 닫았다(원인과 무관).

## 수정 [소스 LanguageCatcher.cs, BookPopup.cs]
- 장비 칸(0.6.2)과 같은 방식: `btnReturn`에 누름/뗌 리스너를 추가한다. 학습·장비 패널이 닫혀 있고 좌클릭 누름이 언어 글자 또는 언어 제목 영역 안일 때만 누름을 잡고(CaptureTouch), 뗄 때 그 클릭을 취소(StopPropagation + Stage.CancelClick)한 뒤, 뗀 위치도 언어 영역 안이면 `OpenBooks(view,-1)`로 언어 학습 패널을 연다. 영역 밖 누름은 원본 btnReturn 동작 그대로.
- 연결은 `RefreshBookBindings`에서, 해제는 `ClearBookBindings`(시트 숨김·해제·게임 리셋 경로)에서 한다.
- 기존 texLanguage/제목 onClick 연결과 `[LangTrace]` 계측은 유지(실행당 40줄 상한). 새 로그: `language press taken from btnReturn`, `click received: language row via btnReturn`, `released outside the row`.
- 새 훅 없음(26 유지). 게임 상태 쓰기 없음(열기만). `Tests.csproj`에서 `LanguageCatcher.cs` 제외.

## 빌드
- `TabCharacters/build.ps1`(evidence/0.6.8). 이 세션에서는 컴파일하지 못했다.

## 사용자 확인
1. 언어 제목·언어 글자 클릭 → 원본 정보창 옆에 “언어 학습” 패널, 가방의 언어 서적만 목록 표시.
2. 언어 서적 선택·학습(“이미 습득한 언어”, “언어 수 가득” 판정 포함), 학습 후 가방 수량 1 감소.
3. 언어 줄 밖 빈 곳 클릭 시 기존 동작 변화 없음, 장비 칸 클릭 정상.
4. 패널 닫기(버튼·Esc·우클릭·바깥 클릭).
