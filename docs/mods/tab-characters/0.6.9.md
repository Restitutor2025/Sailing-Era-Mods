# Tab Characters 0.6.9 — 언어 서적 상세 NullReferenceException 수정

작성: 2026-09-20, Claude (Cowork).

## 증상 [사용자로그 22:58, 0.6.8]
- 언어 줄 클릭이 btnReturn 경유로 수신되었다(`language press taken from btnReturn`, `click received: language row via btnReturn` 2회). 0.6.8 수정은 동작함.
- 곧바로 `Book popup stopped: NullReferenceException at UICharacterView.RefreshSkillBookTips` → `BookPopup.RefreshBookDetails` → `Refresh` → `Open` 경로에서 2회 모두 실패, 패널은 오류 복구로 닫힘.

## 원인 [원본 GameAssembly(R11) 본문 — objdump, native-map/native-fields 대조]
- `RefreshSkillBookTips`(RVA 0x1027810): `BookType != 1`(언어 서적)이고 원본 상태 컨트롤러가 0(학습 가능)이면 `content.roleInfo.listLanguage.data`를 `HeroLanguage` 목록으로 보고, `listLanguage.GetChildAt(data.Count)` 행에 새 언어 미리보기를 쓴다. data가 null이면 0x1027EF1에서 NRE.
- `RefreshTipsRoleInfo`(RVA 0x102B460): `listLanguage.data = hero.HeroLanguage`, `listLanguage.numItems = UICharacterModel.MaxLanguageCount`를 **`model._sheetType == 1`일 때만** 실행한다(0x102BAF1 분기). 스킬 탭 폐지(0.5.9) 이후 인물 시트에서는 이 분기가 실행되지 않아 data가 null로 남는다.
- `_sheetType == 1`이 스킬 시트라는 점은 추론이다(분기 내용이 언어 목록·언어 수를 채우는 것, 0.5.9에서 스킬 시트 요청을 인물 시트로 돌린 것에서 추론). NRE 위치를 0x1027EF1로 특정하는 것도 추론이다(같은 경로의 다른 null 후보: `GetHeroLanguage` 결과). 새 `[LangTrace] language preview:` 줄에서 data=null을 확인한다.

## 수정 [소스 LanguageCatcher.cs, BookLayout.cs]
- 언어 모드의 `RefreshSkillBookTips` 한 번 호출 동안만 원본 분기와 같은 준비를 한다: `listLanguage.data = Role.HeroLanguage`, `numItems`가 `MaxLanguageCount`보다 작으면 올림. 호출 뒤 finally에서 이전 data와 항목 수로 복원.
- 스킬 모드 경로, 훅 수(26), 게임 상태 쓰기 없음은 그대로.

## 사용자 확인
1. 언어 줄 클릭 → “언어 학습” 패널이 열리고 오류 없이 언어 서적 목록·상세가 보이는지.
2. 언어 서적 학습 → 언어 수 증가(3/5→4/5), 서적 1권 감소.
3. 인물 창 오른쪽 정보(레벨·HP 등) 표시가 패널 열기 전후로 변하지 않는지.
4. Latest.log `[LangTrace] language preview:` 줄과 오류 줄 유무.
