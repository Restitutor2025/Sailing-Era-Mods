# Tab Characters 0.2.1 — 책 팝업 오류·크기 수정

2026-09-20. 사용자 0.2.0 로그/화면 보고에 대한 수정. 게임/Steam 실행 및 설치 폴더 변경 없음. 산출물은 루트 `Restitutor_Additional_Tab_Characters.dll`.

## 확인된 오류와 원인

- **사용자 실행 보고:** 0.2.0, 13:20:05.696 `An item with the same key has already been added. Key: FairyGUI.GGraph`. `UI3DHolderManager.SetGameObject → UICharacterView.RenderListSkillShow → GList.set_numItems` 스택. 첨부 화면은 책 세 개에 비해 배경이 거의 전체 화면을 차지하며 장비 보너스가 이름/+/숫자로 줄바꿈된다. [원본 첨부 사본](../../../TabCharacters/evidence/0.2.1/user-report/0.2.0-log.txt).
- **현재 본문 대조:** GameAssembly SHA256 `50D53D17829E3E77B9786EA42D998D1AD258F0653846524069F22E5E442EFFCA`로 기존 기준과 일치. [추출 스크립트](../../../TabCharacters/evidence/extract_popup_fix.py), [현재 원본 본문](../../../TabCharacters/evidence/0.2.1/native).
- **코드에서 확인:** 0.2.0 `BookPopup.Refresh`가 매번 `RefreshSheetSkill`을 호출한다. 원본 0x102749A에서 공유 listSkill의 numItems를 다시 지정하고 `RenderListSkillShow`가 0x1022F4A ClearGGraph, 0x1022FE7 SetGameObject를 호출한다.
- **메타데이터/본문:** UI3DHolderManager의 0x10은 `_waitForLoading`, 0x28은 `_waitForRemove`. ClearGGraph(0x69EAF0)는 즉시 대기 항목을 제거하지 않고 제거 대기 사전에 추가한다. SetGameObject(0x69DBF0)는 기존 핸들러가 제거 대기 중일 때 새 핸들러를 `_waitForLoading`에 Add한다. 원본 효과 렌더를 연속 호출하면 Update 처리 전 동일 GGraph가 남은 상태에서 Add가 겹칠 수 있다.
- **진단:** 모드의 불필요한 전체 스킬창 재렌더가 위 중복 등록 경로를 유발한다. 로그로 확정되는 중복 키는 UI GGraph이며 책 GUID/스택 중복이 아니다. 정확한 프레임별 사전 상태는 사용자 로그에 없으므로 위 대기 처리 타이밍은 본문으로 설명되는 재현 경로이며 실전 계측값은 아니다.

## 변경

`RefreshSheetSkill`을 팝업에서 제거했다. 원본 책 목록 RenderListBook, RefreshSkillBookTips와 학습/조건 판정은 계속 사용한다. 상세 함수가 필요로 하는 스킬 미리보기 행은 팝업 소유 UICom_SkillItem 패키지 인스턴스로 준비한다. 이 행에는 RenderListSkillShow를 호출하지 않아 3D 등록을 요청하지 않는다. 동기 상세 호출 중에만 content.listSkill을 임시 대체하고 finally에서 복원하며 닫을 때 자체 행을 Dispose한다. 언어 분기는 기존 RefreshTipsRoleInfo로 언어 표시 행을 준비한다.

원본 sheet 전체 크기+380/120 및 강제 확대를 없앴다. UI 기준 폭 1000의 두 열, 관련 책이 없으면 폭 488의 한 열이다. 왼쪽은 스킬/언어 정보 및 책 목록, 오른쪽은 책 이름·학습 조건·필요 경험치·설명·습득 효과·현재 함대 경험치·사용 버튼/불가 사유다. 높이는 텍스트 높이·조건 목록·책 행 수로 계산한다. 책 목록은 최대 세 줄 높이로 제한하고 원본 스크롤을 유지한다. 전체 내용이 화면을 넘으면 축소하며 여유가 있어도 1배 이상 확대하지 않는다.

원본 조건 행 아이콘/색상, 책 금지 아이콘과 판정은 유지한다. 불가 사유 문장은 원본 상태 코드(0 사용 가능, 1 이미 학습/언어 습득, 2 언어 한도, 3 스킬 최대, 4 조건/경험치 부족)를 따라 자체 공간에 표시한다. 스킬북 효과 +Lv.1을 명시한다. 장비 이름/+수치는 한 항목 안에서 한 줄로 묶는다.

빌린 sheet와 직계 자식의 위치·크기·표시·그룹·관계를 저장/복원한다. 팝업 배치 중 관계를 분리하고 좌표/크기 쓰기에서는 gear 갱신을 잠시 잠가 원본 페이지의 위치 저장값을 덮어쓰지 않는다. 0.2.0의 모달 입력, 단일 원본 학습, Item Rebuild 수량 소비 계약은 유지한다. 공유 3D 관리자 사전 삭제·예외 무시·새 훅 없음.

## 검증과 한계

- Release 경고/오류 0. 기존 페이지 대역 11,509개 + 실제 BookPopup/BookLayout 소스를 이용한 팝업 대역 920개 = **12,429개** 통과.
- 반복 갱신에서 전체 스킬창 렌더 호출 시 실패하는 회귀 검사, 원본 공유 목록 무변경/임시 목록 복원, 상세 예외 시 복원, 원본 캔버스 크기 배제/닫기 복원, 장비 보너스 줄바꿈 수정, 책 행 높이 검사 포함.
- 기존 13개 훅 서명/인수, 현재 설치 interop의 참조 216개, 시작 경로 4개 메서드 검사 통과. 검증기는 RefreshSheetSkill/RenderListSkillShow/SetGameObject 참조 재도입을 거부한다.
- [소스·검사·DLL 고정 사본](../../../TabCharacters/evidence/0.2.1), [해시](../../../TabCharacters/evidence/0.2.1/release-hash.txt).

0.2.0의 대역 검사는 native 3D 등록을 재현하지 않아 이 오류를 잡지 못했다. 이번 검사는 문제가 되는 호출을 제거했음을 검증하며 실제 FairyGUI 화면을 실행한 검사가 아니다. 실제 배치/스크롤/포커스, 사용 가능·불가 책/언어책, 반복 열기·닫기 및 기존 스킬 탭 복원은 사용자 실행 확인 전이다. 기존 상단 스킬·장비 탭은 유지한다.
