# Tab Characters 0.6.4 — 상단 장비 탭 폐지, 닫기 버튼 글자

작성: 2026-09-20, Claude (Cowork).

## 사용자 보고·요청
- [사용자 보고] 0.6.3 정상 작동. 닫기 버튼에 글자가 없다 → 버튼 크기에 맞게 `닫기` 표시.
- 상단 장비 탭을 스킬 탭처럼 숨긴다.

## 원본 근거 [본문/메타]
- `UIMenuCtrl.ShowChild` 점프 테이블(0xBD7680): 인덱스 2→ShowSheet(0), 3→ShowSheet(1), 4→ShowSheet(2). GameAssembly 전체에서 `UICharacterCtrl.ShowSheet`(0x947500)로 가는 call/jmp는 이 세 곳뿐이다(rel32 전수 검색).
- interop `EMenuTabType` 상수: Map 0, Task 1, Character 2, Skill 3, Equip 4, Bag 5, Ship 6, Cabin 7, Knowledge 8, None 9. → 메뉴 인덱스와 같다.
- `UIMenuView.RefreshBtnKnowledge`는 3번·8번 버튼만 `!`를 다룬다(0.5.9 기록). 장비 탭 배지 이동은 필요 없다.

## 수정 [소스]
- `SkillTabHide.cs`: 폐지 탭 집합 `Retired(tab)` = 3 또는 4. 기존 5개 훅이 4번도 처리(열림 false, 빠른 키 차단, 버튼 숨김·foldInvisibleItems).
- `EntryPoint.cs` BeforeSheet: Skill·Equip 요청 모두 Character로 바꾸고 경고 1줄.
- `EquipPanelLayout.cs`: 닫기 라벨을 autoSize Both(책 패널 라벨과 같은 생성 방식), 글자 크기 = 버튼 높이×0.62, 진한 회색, 버튼 중앙 배치, 매 배치마다 패널 최상단 순서. 버튼 테두리 추가. 0.6.0 라벨이 안 보인 원인(고정 크기 autoSize None 추정)은 확인하지 않았다.
- 테스트: 대역 enum에 테스트 전용 `Other`(9) 추가. 장비 시트 요청이 인물 시트로 바뀌는지 검사를 추가하고, 기존 "다른 시트로 전환 시 복원" 검사는 `Other`로 옮겼다.

## 한계
- 빌드 전. 원본 장비 시트는 이제 열리지 않는다. 장비 변경은 인물 탭 장비 패널만 쓴다.
- 탭 숨김으로 메뉴 버튼 간격이 바뀐다(0.5.9와 같은 fold 방식).

## 사용자 확인
1. 상단 메뉴에 장비 탭이 없고 간격이 자연스러운지. P 키, L2/R2 순환에서 장비 탭이 건너뛰어지는지.
2. 장비 패널 닫기 버튼 가운데에 `닫기` 글자.
3. 인물 탭 장비 패널 기존 동작 유지.
