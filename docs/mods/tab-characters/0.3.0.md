# Tab Characters 0.3.0 — 팝업 경계·닫기·학습 알림·스킬 포인트

2026-09-20. 사용자 0.2.1 화면/입력 보고를 반영한다. 게임/Steam 실행 및 설치 폴더 변경 없음. 루트 `Restitutor_Additional_Tab_Characters.dll` 제공.

## 사용자 보고와 원인

사용자 첨부에서 수량이 책 그림의 아래쪽 경계에 걸리고, 긴 스킬 설명은 오른쪽 열로 넘어가며, 사용 불가 문장이 외곽을 벗어났다. Tab/Esc는 작동하지 않고 닫기 버튼만 작동한다고 보고했다. 책 학습 메시지가 팝업 아래에 가려졌으며, 인물 탭 하단의 지정 영역에 남은 스킬 포인트와 팝업 내 포인트 사용을 요청했다. [0.2.1 사용자 화면 사본](../../../TabCharacters/evidence/0.3.0/user-report).

- 수량: 기존 좌표가 슬롯 기준 고정 4px/26px이고 생성 텍스트의 기본 자동 크기 조절에 의존했다.
- 긴 텍스트: 폭 지정만 했고 singleLine/autoSize를 명시하지 않았다. 양쪽 열과 외곽의 별도 클리핑 경계도 없었다.
- 닫기: 기존 Action_Start/Action_B 경로만 사용했다. 실제 사용자의 무응답은 확인된 실행 보고이며 액션이 누락된 세부 원인은 키 설정/실행 계측 없이 확정하지 않는다.
- 메시지: 자체 root overlay sortingOrder=32000이 기본 알림보다 위에 놓이는 구성과 사용자 화면 보고가 일치한다.

## 구현

### 수량과 두 열

수량 기준은 슬롯 전체가 아니라 실제 `UIBtn_SkillBook.loaderItem`의 위치/크기다. 그림 폭의 9%를 왼쪽 여백, 높이의 8%를 아래 여백으로 두고 표시 영역 폭 62%/높이 24%, 글자 크기를 표시 높이의 80%로 계산한다. `singleLine=true`, `AutoSizeType.Shrink`로 ×99 같은 두 자리 수량이 사각형을 확장하지 못하게 한다. 렌더마다 재계산한다.

양쪽에 폭 440의 별도 GComponent를 만들고 `SetupOverflow(Hidden)`을 적용한다. 외곽 panel도 Hidden이다. 중앙 선은 내용 높이를 따른다. 스킬/책 설명·불가 사유는 폭 고정, singleLine=false, AutoSizeType.Height로 실제 줄바꿈 높이를 배치에 반영한다. 타이틀/경험치 값도 각자의 폭에서 줄바꿈 높이를 반영한다. 책 목록의 세 줄 viewport 및 기존 스크롤은 유지한다.

원본 필드들을 각 열로 임시 옮기므로 부모/원래 순서/좌표/크기/표시/그룹/Relations와 native text의 singleLine/autoSize를 저장하고 복원한다. 원본 sheet 자체의 touchable은 잠시 끄고 실제 입력은 열로 이동한 컨트롤이 받는다. 자체 위치 변경 때 gear 저장값 갱신을 잠근다.

원본 GComponent.ApplyController는 현재 직계 자식만 순회한다(0x21FABC0). 따라서 열로 옮긴 필드에는 책 상세 갱신 후 원본 sheet의 isSeaman/noBook/isExpNotEnough/bookType/btnType을 HandleControllerChanged로 다시 적용한다. 책 선택이 바뀌어도 표시·부족 경험치 색상 상태가 남지 않도록 한 것이다. 마지막 배치는 자체 열 기준으로 다시 계산한다.

### 닫기와 알림

닫기 버튼 문구는 `닫기`. 팝업 동안만 활성 앱의 `Keyboard.current.escapeKey.wasPressedThisFrame` / `Mouse.current.rightButton.wasPressedThisFrame`를 확인하여 닫는다. Tab(Action_Start)은 닫기로 쓰지 않고 배경에 전달하지 않는다. 기존 게임패드 취소 Action_B도 유지한다. 닫기 입력이 눌린 동안과 해제 직후 2프레임은 배경 입력을 소비하여 팝업 뒤 메뉴가 함께 닫히는 것을 막는다.

신규 훅은 `UITipsCtrl.ShowBaseTips(string texTips,string url)` Prefix 한 개(0xDFAB60)다. 자체 학습 Committing 범위에서만 원본의 메시지/아이콘 인수를 root sortingOrder=32760의 전용 비입력 알림으로 전달하고 원본 중복 표시를 막는다. 알림은 실제 시간 3초 동안 유지되고 팝업을 닫아도 남는다. 전달 실패 시 원본을 허용하며 일반 게임 알림은 항상 원본 처리한다. 메뉴 이탈/Reset/모드 종료에는 자체 알림을 정리한다. 스킬 포인트 성공도 같은 최상단 영역에서 알린다.

### 스킬 포인트

선택 인물의 SkillPoints가 남아 있고 인물 탭이 활성 상태일 때만 하단 오른쪽 단축키 앞 영역에 `사용 가능한 스킬 포인트: N`을 표시한다. 위치/크기/글자 크기는 GRoot 크기 비율을 사용한다. 다른 탭/닫기/Reset에서 제거한다. 인물 변경과 포인트 소비 후 갱신한다.

언어를 제외한 각 스킬 팝업에 `스킬 레벨 +1 (1 포인트 사용)` 버튼을 추가했다. 책이 없어도 사용할 수 있다. 포인트 없음/최대 레벨이면 비활성 이유를 표시한다. 매 클릭 직전 같은 인물·현재 DB의 동일 객체·포인트>0·최대 레벨 미도달을 확인하고 같은 프레임 중복 호출을 차단한다.

원본 스킬 배분 저장이 호출하는 `PlayerHoldRoleDB.UpdateRoleSkillLevelBySkillPoints(roleId,skillId,1)`을 사용한다. 책 수량과 함대 경험치를 별도로 차감하지 않는다. 원본 함수는 스킬 변경 성공 뒤 포인트 차감/MarkDBDirty를 수행하나, 포인트 부족 시 사전 거부가 없으므로 호출 전 검사가 필수다. 원본 RoleSkillData.IsMax는 장비 합산이 아닌 기본 스킬 레벨과 템플릿 상한을 비교한다. 성공 후 원본 스킬 데이터/인물 표시를 새로 읽고 팝업·하단 포인트를 갱신한다.
