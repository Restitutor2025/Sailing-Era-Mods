# Tab Characters 0.5.2 — 재발 로그 확인과 바깥 클릭 완료 판정

사용자는 조이스를 만렙까지 올리고 포인트를 2회/3회 사용했을 때 상승 알림 종료와 함께 창이 닫혔다고 보고했다. 게임은 실행/조작하지 않고 설치 폴더의 Latest.log만 읽었다. 로그에는 0.5.1 로드와 16:08:13.700, 16:08:17.909의 `Characters learning panel closed: CreateOutsideDismiss`가 있다. 해당 닫힘 경로는 바깥 좌클릭이며 오류 복구 기록이 아니다. 이후 TickBooks 기록은 0.5.1 코드에서 물리 Esc/우클릭에 해당한다. 각 로그 시점과 사용자의 개별 클릭이 정확히 일치하는지는 영상/좌표 기록 없이 확정하지 않는다.

알림 종료 함수가 직접 CloseBooks를 호출하는 경로는 없다. 알림이 좌표/히트 테스트에 간접 영향을 줬는지는 미확정이다. 이전 버전은 Stage.touchPosition을 읽어 바깥 누름만으로 창을 닫았고 실제 이벤트의 좌표·해제 조건을 확인하지 않았다.

이번 수정은 입력 판정을 보강한다. EventContext.inputEvent.x/y로 양쪽 창의 내부 여부를 판정한다. 밖에서 시작한 왼쪽 누름을 CaptureTouch로 추적하고 밖에서 해제한 경우에만 닫는다. 내부에서 시작하거나 내부로 들어와 해제하면 닫지 않는다. 후속 배경 클릭은 CancelClick으로 방지한다. 닫힘 로그에는 누름/해제 좌표, 양쪽 창 좌표/크기/배율, 알림 playing을 추가한다. 물리 Esc/우클릭도 각각 구별하여 기록한다. 원본 알림과 포인트 소비는 변경하지 않았다.

Release 경고/오류 0. 11,509 + 2,284 = 13,793개 대역 검사 통과. 훅 20개 유지, 참조 301개, 시작 경로 5개 검사 통과. 실제 게임 재현은 수행하지 않았다. 이 버전이 간헐적 증상을 완전히 해결했다고 판단하지 않으며 재발하면 새 좌표/알림 상태 로그로 구분한다.
