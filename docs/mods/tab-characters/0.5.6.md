# Tab Characters 0.5.6 — 원본 스킬 정보창 읽기 전용화, 원본 학습 버튼 복귀

작성: 2026-09-20, Claude (Cowork). 근거 등급: [사용자로그] Latest.log / [사용자 보고] 스크린샷 / [본문] 보존 asm / [소스] 이번 변경 / [추론].

## 1. 반복 열기/닫기 시 창 축소·정보창 왼쪽 밀림
- [사용자로그] 2026-09-20 17:51–17:53 실행(0.5.5)의 `Characters learning panel closed: outside left release` 줄: 정보창 영역(`info=`) 폭이 593 → 593 → 626 → 677 → 745 → 830 → 932 → 1051 → 1187 → 1340 → … → 3778 → 4835 → 5222로 커졌고 배율이 1.000 → 0.590 → 0.473 → 0.441로 줄었다. 같은 스킬을 반복한 처음 두 번은 변화가 없었고 다른 스킬 행으로 바꾼 뒤부터 매번 커졌다. 오른쪽 끝은 유지되고 왼쪽 끝이 밀렸다.
- [사용자 보고] 스크린샷: 원본 설명 내용이 정보창 영역 왼쪽 끝에 붙고 두 창이 함께 작아짐.
- [본문] `GGroup.MoveChildren`(RVA 0x21FF530, `evidence/0.4.0/native`)은 그룹 소속 자식에 gear 잠금 없이 `SetPosition`을 호출한다. `RefreshTipsSkill`(RVA 0x1025D10)은 좌표를 직접 쓰지 않고 `tipsType` 컨트롤러로 좌우 배치를 바꾼다.
- [추론] 0.4.0~0.5.5는 원본 정보창 위젯을 그룹에서 떼어 자체 컨테이너로 옮기고 닫을 때 좌표만 되돌렸다. 그 사이 원본 그룹·중첩 그룹의 위치 기록과 gear 저장값이 실제 위젯 위치와 어긋나고, 원본이 다음에 그룹을 옮길 때 어긋난 만큼 누적된 것으로 본다. 정확히 어느 호출에서 어긋나는지는 확정하지 않았다.
- **사용자 결정:** 원인 단계를 특정하는 대신 원본 정보창을 옮기지 않는 방식으로 바꾼다.

### 변경
- `PrepareNativeInfo`는 읽기만 한다: `groupTips` 경계(EnsureBoundsCorrect 후)와 배경 이미지·색만 읽는다. 원본 위젯의 부모·그룹·좌표·크기·배율·Relations·gear·표시 상태를 쓰지 않는다. 복원할 것이 없으므로 `RestoreNativeInfo`는 글자색 테마만 되돌린다.
- 선택 스킬 내용 고정(`RefreshTipsSkill` 외부 호출 차단 Prefix)은 유지. 자체 갱신 호출도 유지.
- `infoPane`은 원본 정보창 영역만 표시하는 빈 컨테이너다(바깥 클릭 판정용). 언어 패널은 기존처럼 자체 요약을 이 컨테이너에 그린다.
- 배치: `SidePanelPlacement.Beside` — 원본 정보창은 그대로 두고 학습 패널만 이동·축소한다. 선호 방향(기존 판정)에 1배로 들어가지 않으면 반대편이 더 크게 들어갈 때 반대편으로 옮긴다. 양쪽 모두 0.5배 미만이면 화면 안에서 겹침을 허용한다. 화면 크기가 바뀌면 경계를 다시 읽는다.
- 언어 패널 배치는 기존 `Calculate` 유지.

### 한계
- [미확인] 패널이 열려 있는 동안 마우스가 스킬 행을 벗어나면 게임이 원본 정보창을 숨기는지 확인하지 못했다. 숨긴다면 정보창 없이 학습 패널만 남는다(재보고 필요).
- 이미 어긋난 원본 상태는 현재 실행 중인 게임 세션에 남아 있을 수 있다. **게임을 재시작한 뒤** 확인해야 한다.

## 2. 학습 버튼
- 사용자 요청: 원본 `스킬 배우기` 버튼 모양(스페이스 키 아이콘 포함)을 그대로 쓰고 누름 반응만 추가.
- 원본 `btnSkillUp`을 **원래 크기 그대로**(0.5.4의 440×60 강제 조정 제거) 오른쪽 열 가운데에 둔다. 원래 폭이 열(440)보다 넓을 때만 비율 축소.
- 누름 반응: 왼쪽 버튼을 누르는 동안 버튼 중심 기준 95% 배율. 떼기·밖으로 끌기·버튼 밖 이동 시 원래 크기. gear 잠금 상태로 적용하며 닫을 때 기존 `RestoreLayout`이 부모·좌표·배율·크기를 복원하고 리스너를 제거한다.
- 학습 실행은 원본 클릭 → `OnClickBtnBook` → `BookUse` Prefix → `Commit` 경로 그대로(0.5.4와 동일). 0.5.5의 자체 버튼·다음 프레임 대기 요청은 제거했다.
- 0.5.5의 패널 배경 alpha 0.8은 유지.

## 검증
- 훅 20개 유지, 저장 호출·책 차감 경로 변경 없음.
- PopupTests 추가·수정: 열기/12회 열기·닫기(두 스킬 교대, Esc·닫기 혼합) 동안과 후에 원본 정보창 자식 전체의 좌표·크기·배율·표시·입력·alpha·그룹·부모·gear 잠금 상태가 동일, 빈 대역 컨테이너가 원본 경계와 일치, 학습 패널이 정보창과 겹치지 않음, 원본 학습 버튼 원래 크기·가운데 배치·95% 누름·떼기/이탈/밖 이동 복원·누름만으로 학습하지 않음·닫을 때 복원 및 리스너 제거, `Beside` 배치 행렬(화면 안, 여유 있을 때 비겹침, 0.5배 이상).
- 작업 환경에서 .NET을 쓸 수 없어 빌드·테스트는 사용자 `build.ps1` 실행 결과로 확인한다. 게임/Steam 미실행, Mods 자동 교체 없음.

## 사용자 검증
1. `TabCharacters/build.ps1` 실행 → PASS 확인.
2. 게임 종료 → 루트 DLL로 `Mods/Additional_Functions/`의 동명 파일 교체 → 게임 시작.
3. 여러 스킬을 번갈아 10회 이상 열고 닫기: 창 크기·정보창 위치가 변하지 않는지. Latest.log의 `info=` 폭이 스킬별로 일정한지.
4. 패널이 열린 상태에서 마우스를 다른 스킬 행/빈 곳으로 옮겼을 때 원본 정보창이 계속 보이고 내용이 선택 스킬로 유지되는지.
5. `스킬 배우기`: 원본 모양 그대로인지, 누르는 동안 작아지는지, 안에서 떼면 1권 학습되는지.
