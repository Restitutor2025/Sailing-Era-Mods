## 변경
기존 화면/입력/DB/알림 동작은 유지. BookUiTrace.cs에서 포인트 사용 전후, 원본 팁 호출 전후, 정렬 변경/복원 전후와 다음 프레임의 상태를 관측한다.
- 객체 주소/부모, visible/alpha, 실제 displayObject 표시/alpha, sortingOrder, 좌표/크기.
- 설명/학습/overlay/포인트 표시, 안내 조상 최대 12단계, GRoot 자식 최대 64개(통합 치트 포함).
- 입력 활성 상태, 애니메이션 진행, 프레임/시간/포인트 시퀀스.
- 포인트 사용마다 15초, 변경된 프레임만 기록, 최대 180개 스냅샷 + 제한 안내. 다음 포인트에서 새 관측. 만료/Reset/관측 예외 시 참조 해제. 원본 UI 수정/강제 재열기/포커스 이동 없음.
- 로그 식별자 `[CharactersUITrace]`, 기존 MelonLoader Latest.log 사용. 새 네이티브 훅 없음.
