# Tab Characters 0.6.6 — 스킬 레벨 +1 버튼 가시성

작성: 2026-09-20, Claude (Cowork).

## 요청
- [사용자 보고, 스크린샷] 학습 패널 위쪽 `스킬 레벨 +1` 버튼이 어두운 배경에 작은 글자라 잘 보이지 않는다. 훨씬 크게, 바로 보이게.

## 변경 [소스]
- `BookActions.cs`: 버튼 높이 52 → 84(`PointButtonHeight`), 글자 23 → 38(`PointButtonFont`), 버튼 전체 폭 가운데·세로 가운데 정렬. 누를 수 없을 때 안내 문구는 글자 크기 2/3.
- `BookInteraction.cs` PaintPointButton: 누를 수 있을 때 파란 채움(0.16,0.46,0.80), 테두리 3px(기본 하늘색, 호버 더 밝게, 누름 흰색), 흰 글자와 반투명 검은 외곽선 1. 누를 수 없을 때 어두운 회색 채움·회색 글자. 호버·누름 그라데이션도 파란 계열로 높이에 맞춤.
- `BookDock.cs` ThemeTexts: 이 버튼 글자는 패널 공통 글자색 맞춤에서 제외(상태별 색 유지).
- 패널 폭(488)·동작·입력 판정(누르고 버튼 안에서 뗌 → 다음 프레임 1회 사용)은 그대로.

## 사용자 확인
1. 버튼이 크고 바로 보이는지, 글자가 가운데에 있는지.
2. 포인트 0·최대 레벨일 때 회색 안내로 바뀌는지.
3. 누름·호버 표시와 1회 사용이 이전처럼 동작하는지.
