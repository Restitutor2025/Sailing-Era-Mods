## 1. 책을 바꾸면 두 창 사이 간격이 벌어짐
- [사용자 보고] 처음 열었을 때 원본 스킬 정보창과 학습 패널 사이 간격이 좁고(스크린샷 약 5px), 책을 바꾸면 약 15px로 벌어져 다시 바꿔도 돌아오지 않는다. 사용자 확인: 처음 간격이 정상.
- [소스] 0.5.6~0.5.9는 책을 바꿀 때마다(Refresh → UpdateSummary → PrepareNativeInfo) 원본 `groupTips` 경계를 다시 읽고 그 오른쪽 끝에 패널을 붙였다.
- [추론] 자체 갱신에서 원본 `RefreshTipsSkill`을 다시 호출한 뒤 그룹 경계가 보이는 배경보다 넓게 계산되는 것으로 본다(어느 구성원이 넓어지는지는 미확인).
- 수정: 패널 위치 기준(anchor)을 패널을 연 순간 한 번만 읽고 고정한다. 화면 크기가 바뀔 때만 다시 읽는다. 이후 원본 경계가 달라지면 패널을 옮기지 않고 한 번만 로그를 남긴다: `Characters tooltip bounds changed after open (panel kept at first position): open=(…) now=(…)`. 원인 확정용이다.

## 2. 책 수량 표시
- [사용자 보고] 학습 패널 책 칸에 수량이 보이지 않았다(가방에는 《아서왕의 죽음》 x3).
- [소스] 가방의 `x3`는 게임 원본이 아니라 Item Rebuild `BagBadge.cs`가 그린다. 원본 `Common.UIcompSlotCommon.title`의 서식을 복사한 뒤 크기 = round(round(원래 크기/2)×1.1), 흰색, 그라데이션 없음, 오른쪽·아래 정렬, 검은 외곽선 1, 그림 안쪽 여백 min(14, min(w,h)/5), 높이 min(h−2×여백, 크기×1.6+4), 문구 `x`+수량.
- 수정: 같은 규칙을 Tab Characters에 그대로 옮겼다(`src/BookCount.cs`, Item Rebuild DLL을 참조하지 않음). 서식 원본은 `UIcompSlotCommon.CreateInstance()`로 한 번 만들어 읽고 바로 폐기하며 결과를 캐시한다. 생성에 실패하면 패널 글꼴·크기 20으로 대신하고 경고를 한 번 남기며 다음 패널에서 다시 시도한다. 위치는 사용자 선택대로 가방과 같은 우측 아래(금지 표시와 겹침, 수량이 위).
- [추론] 0.5.9 이전 수량 표시는 어두운 색과 그림 비례 크기를 써서 책 그림 위에서 보이지 않았던 것으로 본다(확인 안 함). 이번 수정으로 방식 자체를 바꿨다.
