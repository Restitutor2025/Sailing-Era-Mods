# Tab Characters 0.4.0 — 원본 스킬 정보창 옆 학습 패널

2026-09-20. 사용자의 최신 요청에 따라 중앙 팝업 방식을 폐기하고 원본 스킬 정보창과 인접 학습 패널로 바꿨다. 게임·Steam 실행 및 Mods 폴더 변경 없음. 루트 DLL 제공.

## 구현한 화면과 입력

스킬 행을 클릭하면 원본 스킬 정보창의 실제 배경·설명·레벨·장비 보너스 위젯을 재사용한다. 정보창이 선택 행 오른쪽에 있으면 학습 패널을 그 오른쪽에, 왼쪽이면 그 왼쪽에 둔다. 원본 정보창의 root 좌표와 선택 행의 중심을 비교하며, 행을 확인할 수 없으면 원본 tipsType 방향을 사용한다.

학습 패널은 포인트 사용 영역 → 관련 책 목록 → 구분선 → 선택 책 상세/조건/사용 버튼 순서다. 책 목록은 이전 방식의 native 슬롯/금지 표식/수량 표시/스크롤을 사용하고 viewport는 최대 3행이다. 목록과 상세는 별도 클리핑 경계를 가지며 높이는 내용으로 계산한다. 책이 없으면 상세 영역을 숨기고 포인트 사용은 유지한다. 언어는 별도 언어 정보 영역을 만들고 언어책만 표시한다.

원본 정보창의 package 이미지 배경이 있으면 같은 resourceURL로 별도 배경을 생성한다. 그래프 배경이면 원본 색을 사용한다. 중립 텍스트는 원본 정보창의 글자색을 공유하고 부족 조건의 빨강/보너스 초록은 유지한다. 책 그림 위 수량은 가독성을 위해 진한 색과 기존 비율 여백/축소를 유지한다. 원본 설명이나 장비 아이콘을 문자열로 재구성하지 않는다.

두 창은 작은 비례 간격으로 구분한다. 화면 가장자리에서 두 창을 함께 이동하고, 합친 폭이나 최대 높이가 화면보다 크면 같은 배율로 축소한다. 원본 크기보다 확대하지 않는다. 정보창/학습 패널/책 영역/상세 영역에 각각 클리핑을 적용한다. 아주 긴 내용은 전체 배율이 작아질 수 있으며 실제 가독성은 사용자 확인이 필요하다.

화면 암전·중앙 배경·GRoot 포커스 강제 이동·전체 배경 입력 차단을 제거했다. 다른 스킬 클릭은 기존 패널 복원 후 새 패널로 교체한다. 인물 변경/페이지 이동/다른 탭/메뉴 닫기는 패널을 정리한다. 닫기 버튼 문구는 `닫기`, Esc/우클릭/게임패드 취소는 패널만 닫으며 해당 닫기 입력이 뒤 메뉴까지 전달되지 않도록 기존 짧은 해제 보호를 유지한다. Tab과 페이지 입력 등은 원래 메뉴로 전달한다. 전역 확정 입력을 책 소비로 바꾸지 않으며 책 사용은 패널의 사용 버튼으로 수행한다.

인물 탭에서만 보이는 잔여 포인트 표시, 1포인트 사용의 상한/잔여량/인물 동일성 검사, 책 소비의 최신 재검사, 최상단 학습 알림은 유지한다. 상단 스킬·장비 탭 제거는 이번 변경에 포함하지 않는다.

## 공유 상태와 수명

원본 `UISheetCharacter.groupTips`는 화면 요소를 담는 GComponent가 아니라 GGroup이다. 원본 group에 속한 직계 위젯과 알려진 스킬 정보 필드들을 모아 부모/순서/좌표/크기/배율/그룹/Relations/표시/텍스트 크기 설정을 먼저 보관한 뒤 자체 정보 컨테이너로 옮긴다. 개별 위젯을 옮긴 후 남은 자식 순서로 원래 순서를 잘못 기록하지 않도록 모든 스냅샷을 먼저 만든다. 닫기/오류 정리에서 native 위젯과 책 sheet를 원래 부모로 복원하며 자체 배경/컨테이너만 폐기한다. 원래 부모가 이미 폐기됐다면 native 위젯을 자체 컨테이너에서 분리한다.

원본 `RefreshTipsSkill(PlayerRoleData)`은 model의 현재 SkillIndex/CurFoucType을 읽어 텍스트·tipsType·장비 목록을 갱신한다. 비모달 화면의 마우스 이동이 학습 대상과 다른 스킬 설명을 덮어쓰지 않도록, 동일 View의 native 정보 위젯을 빌린 동안 외부 호출만 Prefix로 막는다. 자체 정보 갱신 호출은 허용하며, 그동안에만 선택 스킬과 Skill focus를 대입하고 index/focus/장비 dictionary를 finally 복원한다. 다른 View 및 패널이 닫힌 상태는 원본 실행이다. 이동된 위젯에는 tipsType을 직접 재적용하고 자체 위치 변경 중 gear 저장값을 잠근다.

이전 전체 스킬창 렌더/3D 등록 금지는 유지한다. 책 상세는 별도 미리보기 행을 동기 호출 동안만 연결하고 복원한다. 저장 데이터의 직접 재구성 없음. Item Rebuild의 한 권 차감 경로 유지.
