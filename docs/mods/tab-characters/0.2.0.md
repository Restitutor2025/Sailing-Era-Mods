# Tab Characters 0.2.0 — 인물 화면 스킬·언어책 사용

사용자 요청: 인물 창에서 관련 책을 필터링해 사용하고, 기존 스킬 화면/스킬 클릭 설명에서 보이던 정보도 함께 표시한다. 기존 Restitutor_Additional_Tab_Characters.dll에 구현했다. 상단 스킬·장비 탭 제거는 포함하지 않는다.

## 화면과 동작

- 인물 탭 스킬 행 클릭: 실제 skillId로 관련 보유 스킬북 표시. 언어 제목/언어 문자열 클릭: 보유 언어책 표시. 고용 선원은 제외한다.
- 기존 UISheetSkill을 팝업 안으로 임시 이동해 원본 책 아이콘·금지 표식·이름·설명·학습 조건·필요 경험치·스킬/언어·사용 버튼 상태를 재사용한다. SheetType은 Character로 유지한다. 별도 모델로 원본 학습 규칙을 복제하지 않는다.
- 왼쪽에는 기존 스킬 설명, 기본 레벨/장비 보너스, 해당 장비 설명 텍스트를 표시한다. 학습 가능하면 원본이 계산한 학습 후 레벨 미리보기도 표시한다. 언어 모드에는 현재 언어/보유 개수를 표시한다. 한국어 글꼴은 원본 스킬 설명의 글꼴을 사용한다.
- 책 아이콘에 현재 저장 기록의 ×수량을 추가한다. 책 선택은 상세 표시, 사용 버튼 또는 기본 확정 액션은 실제 사용이다. 금지 책도 목록에서 볼 수 있으나 사용은 차단한다. 빈 목록은 안내한다.
- 원본 GetBookStateByParam을 사용 직전에 재검사한다. 경험치는 FindCurrency(2).Amount로 최신화한다. 인물/모델/가방 변경, 재고 소진, 경험치 부족, 같은 책 사용 이력과 상한을 확인한다. 선택 책이 사라지면 다른 책으로 자동 소비하지 않는다.
- Ctrl.OnClickBtnBook 한 번을 호출한다. 책 차감은 원본/Item Rebuild 기존 경로에 맡긴다. 추가 수량 차감 없음. 사용 후 InitBookData/InitSkillData 및 인물·책 표시를 갱신한다. 연속 누름과 같은 책 재사용은 재진입 가드/원본 판정으로 차단한다.
- 팝업 동안 GUI 배경을 덮고 게임 입력을 차단한다. 기본 Action_Start/Action_B는 팝업만 닫고 Action_A는 사용이다. 해당 press에 대응하는 release도 소비한다. 축 입력을 버튼 값으로 읽지 않는다. 기존 게임 액션 이름을 사용하며 키를 강제 재지정하지 않는다.
- 창 크기 변경 시 배경과 패널 배치를 맞춘다. 닫기/탭 전환/모델 교체/ForceReset/종료 시 원래 부모·위치·배율·그룹·표시 잠금·renderer·GUI 포커스를 복원하고 자체 이벤트/수량 라벨을 정리한다. 원본 sheet를 overlay와 함께 Dispose하지 않는다.

## 원본 재대조와 주요 수정 근거

설치 GameAssembly SHA256은 `50D53D17829E3E77B9786EA42D998D1AD258F0653846524069F22E5E442EFFCA`로 기존 기준과 일치한다. [네이티브 본문](../../../TabCharacters/evidence/0.2.0/native)과 [리뷰](../../../analysis/character-book-review/REVIEW.md)를 사용했다.

- RenderListBtnSkill(0x1026CD0)이 인물 탭의 UIBtn_SkillItem 행이다. RenderListSkillShow는 별도 UICom_SkillItem 표시 경로이므로 클릭 훅 대상으로 사용하지 않는다. GetSkillIdByIndex로 화면 인덱스와 스킬 ID를 대응한다.
- RefreshSkillBookTips는 sheet 내부 설명뿐 아니라 UICharacterMain.listSkill의 학습 후 미리보기 행과 roleInfo의 언어 미리보기도 접근한다. 단독 호출 전제는 부족하다. 따라서 필터 목록을 준비한 뒤 원본 RefreshSheetSkill로 미리보기 행/역할 정보를 먼저 구성한다. 기본 화면을 스킬 탭으로 전환하지 않는다.
- OnClickListBook 및 SetFilterListSkill은 SheetType=1 가드가 있어 인물 모드에서 선택 어댑터로 직접 쓰지 않는다. 팝업이 ListFilterBook/BookIndex를 관리하고, 확정 순간에만 CurSelectBook/IsSelectBook을 설정한다.
- 금지 아이콘은 RenderListBook의 원본 GetBookStateByParam 결과를 유지한다. 동일 책 수량이 남아도 같은 인물의 사용 이력 판정은 유지한다.
- ForceReset은 static 메서드이므로 패치 탐색에 Static을 추가했다. UI 패키지/팝업 객체 생성은 최초 클릭 시점이며 시작 호출 그래프에서 GUI 접근은 없다.

## 공유 상태와 제한

기존 인물 10명 페이지·초상화 정리 유지. 가방 데이터/저장 형식은 이 모드에서 직접 쓰지 않는다. Item Rebuild 0.1.16과 함께 사용하면 대표 책 기록의 Number가 한 권 감소하고 마지막 권에서 삭제된다. 언어책은 해당 버전 Item Rebuild의 통합 대상이 아니지만 원본 학습 기능은 팝업에서 제공한다.

원본 SkillSheet 객체와 컨트롤러 상태를 공유하므로 동일 sheet/renderer/책 선택/포커스·입력 캡처를 바꾸는 다른 모드와 실행 순서 검증이 필요하다. 원래 게임 UICtrl 포커스 소유자는 유지하며 자체 overlay의 FairyGUI 포커스와 InputSystemManager 캡처로 모달 입력을 처리한다. 기존 문서의 SetFocusOnUIView/TransferFocusTo를 서로 대체한 구현은 아니다.

## 검증 및 배포

Release 경고/오류 0. 기존 페이지/리소스 회귀 대역 11,509개 + 실제 BookPopup/BookRules 소스를 사용하는 별도 API 대역 910개 통과. 합계 12,419개. 페이지 대역은 팝업 경계를 stub으로 분리하고 새 팝업 대역이 해당 소스를 직접 검사한다.

팝업 검사: 스킬/언어 분리, 원본 상세 호출, 표시 잠금 및 복원, 클릭 listener 중복 방지, 한 권 소비/마지막 권/사용 이력 재판정, 경험치 최신화, 인물 교체, 책 삭제 후 다른 책 오소비 방지, 닫기 release 차단, 풀 callback 정리, 사용 예외 복구, 창 크기 변경과 Reset. 대역은 원본 UI/학습 본문 실행이 아니며 실제 장면/글꼴/해상도별 배치·금지 표시·사용·저장·병용의 성공 증명이 아니다.

13개 고유 훅 서명/핸들러, 190개 게임·Unity·interop 참조, 시작 호출 그래프 통과. 새 훅 4개의 RVA 별칭은 각각 1개 선언이며 공유주소 없음. [검증/소스/DLL 사본](../../../TabCharacters/evidence/0.2.0). 빌드 재현: TabCharacters/build.ps1.

루트 DLL SHA256 `2E3EC8C70278CBB7062C5ECE3CE382B3850297E8B8493FA7C395583511491066`. 기존 DLL 이름 유지. 설치 폴더는 수정하지 않았으며 게임·Steam 실행 없음. 사용자 확인 항목: 인물 스킬 클릭/책 상세와 장비 보너스, 언어책 상세, 학습 가능·금지 책 사용, xN 변화, 마지막 권, 닫기·재열기·Q/E, 기존 스킬 탭 복귀, 저장 재로드.
