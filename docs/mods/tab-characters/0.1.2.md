# Tab Characters 0.1.2 — 비표시 초상화 및 닫힌 상세 이미지 정리

2026-09-20. 사용자 승인한 캐시 리뷰의 첫 구현. [리뷰](../../../analysis/character-cache-review/REPORT.md)의 표시 슬롯/선택 인물 분리를 유지한다. 0.1.1 소스·DLL·설치 기록·현재 문서/패치 목록은 TabCharacters/archive/0.1.1에 보존했다.

## 변경

페이지 축소나 스킬/장비의 전체 목록에서 인물 탭으로 돌아와 비표시 행이 풀에 쌓이면, 해당 GList의 풀을 순회해 분리된 UIbtnRole의 loaderRole을 정리한다. 살아 있는 UI 틀과 풀 큐는 보존한다. 인물 탭에서 닫을 때 동일 정리 후 큰 일러스트/상세 초상화 URL도 비운다. 다른 탭으로 옮길 때는 상세를 유지한다. 현재 표시 10개 및 페이지 밖에 있을 수 있는 선택 항해사의 상세는 사용 중에 비우지 않는다.

URL 비우기만으로 대기 중 로딩 작업이 남을 수 있어, 원래 URL 해제 처리 후 MyGLoader._handler가 남아 있는 경우에만 ReleaseLoader를 호출한다. 기본 로더 및 알 수 없는 다른 파생 로더의 내부 handler를 임의로 다루지 않는다. GC/전역 UnloadUnusedAssets/Texture.Destroy/풀 전체 Clear/3D 강제 반환 없음. 원본 전체 CharacterData나 ListTalent 지연 생성은 이 버전에 포함하지 않는다.

## 현재 설치 본문 근거

[재추출](../../../TabCharacters/evidence/0.1.2/extract.py) GameAssembly SHA256은 50d53d17829e3e77b9786ea42d998d1ad258f0653846524069f22e5e442effca로 기존과 일치한다.

- [CONFIRMED: 본문] GLoader.set_url 변경은 ClearContent/LoadContent로 이어진다. ClearContent의 외부 이미지 반환은 실제 texture 존재 조건에 있어 미완료 handler는 별도로 확인한다.
- [CONFIRMED: 본문] MyGLoader.FreeExternal/Dispose는 ReleaseLoader를 이용한다. ReleaseLoader는 handler가 null이면 바로 반환하며, 존재하면 관리자/작업 반환 후 handler 필드를 0으로 만든다. 완료된 URL 해제가 이미 반환했다면 추가 Release를 하지 않는다.
- [CONFIRMED: 본문] MyGLoader.CheckResourceLoad는 시작 시 handler null이면 종료한다(0xD4480C → 0xD449E8). 원본 로더 해제 이후에도 확인 루프가 남아 있는 경우를 고려했다.
- [CONFIRMED: 설치 수정 본문] 설치 MyGLoaderManger.Update는 0x3784000으로 분기한다. 0x3782000은 기존 prologue 후 0xD44BDF로 복귀하며, 본문의 로더 검사 호출은 0x3752000 guard를 거친다. guard도 null handler를 건너뛴다. 0x378C000의 추가 작업 디스패치 본문까지 보관했다. 그 디스패치의 모든 하위 기능/실행 병용까지 분석 완료한 것은 아니다. 관리자 훅이나 이 설치 패치를 수정하지 않았다.
- [CONFIRMED: 본문] View.ShowHook은 RefreshTipsRoleInfo, ShowSheet/ChangeCurRoleIndex는 모델 dirty 후 현재 인물 갱신을 수행한다. 상세 URL을 비운 뒤에도 기존 재열기 갱신 경로를 유지한다. native 방식의 실제 재로딩 성공은 사용자 검증 전이다.

[함수별 근거 폴더](../../../TabCharacters/evidence/0.1.2/) 및 [기존 상세 갱신/선택 근거](../../../analysis/character-cache-review/REPORT.md). 기본 GLoader와 MyGLoader 타입은 TryCast로 구별한다. 원본 참조 반환과 실제 Unity/GPU 메모리 회수는 구별한다.

## 검증

Release 경고/오류 0. 실제 구현을 API 대역과 함께 빌드한 관리 검사 11,509개 통과. 기존 페이지/인덱스/탭/수명주기에 더해 완료된 로더 단일 반환, 미완료/빈 URL 작업 반환, 반복 정리, disposed 및 부착된 행 제외, 다른 풀 항목 제외, 10→5 페이지의 여분 5개 정리, 25명 전체 탭에서 10명으로 복귀, 재사용 행 이미지 재설정, 선택 상세 보호, 종료 시 상세 두 로더 정리, 정리 오류 후 페이지 유지 등을 확인했다.

훅 서명은 9개 유지, 게임/Unity/interop API 참조 60개 해소 확인. 정리 로그의 urls/remainingOperationsReleased는 반환 횟수이며 절감 메모리량이 아니다. 게임·Steam 실행 없음. 실제 IL2CPP 로더/공용 리소스 참조 카운트/이미지 재표시/메모리 감소/병용 정상은 사용자 실행 전이다.

## 사용자 실행 확인

마지막 잔여 페이지와 Q/E 왕복, 선택 인물이 페이지 밖에 있을 때 상세 유지, 스킬/장비 탭 왕복, 인물 탭에서 닫기/재열기, 이미지 로딩 중 빠른 닫기/재열기를 확인한다. `Characters cleanup pool` 및 `closed-details` 로그와 페이지 반응 속도/메모리를 함께 비교한다. 이미지가 비거나 정리 오류 로그가 나오면 성공으로 판정하지 않는다.
