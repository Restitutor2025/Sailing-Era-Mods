범위: ItemId 36000~36007, 36009~36013의 비무역 항목. 책·장비·기타 종류·무역품은 이번 버전에 포함하지 않는다. 상점/NPC 교환의 원래 개수별 선택 슬롯 UI는 유지한다. 모든 화면의 표시를 합치는 버전은 아니다.

## 설치와 저장

루트의 `Restitutor_Additional_Item_Rebuild.dll`을 게임의 `Mods` 폴더에 넣는다. 이 작업에서는 DLL을 자동 설치하지 않았다. MelonLoader와 현재 설치 게임에 맞는 interop가 필요하다.

기존 세이브 사본을 보관하고 확인한다. 세이브 로드 또는 가방/출발 준비 갱신 때 대상 도구의 중복 행을 합친다. 총수량과 대표 GUID 하나를 유지하고, 도구별 구매가·공급·품질·특수 여부·상태는 0으로 통일한다. 공통 저장 스키마의 필드 자체를 제거하는 작업은 아니다. 탐험 중 내구도·파손 확률은 원본을 유지한다.

처음 합치기 전에 기존 대상 항목을 `UserData/Restitutor/ItemRebuild/inventory-backups/*.json`에 기록한다. 이 JSON은 변경 전 항목의 조사/복구 자료이며 게임에서 직접 불러오는 전체 세이브가 아니다. 백업 기록 실패 시 합치기를 중단한다. 저장 후 DLL만 빼도 원래의 개별 기록으로 되돌아가지는 않으므로 복원은 변경 전 세이브로 한다.

지원 GameAssembly SHA256: `50D53D17829E3E77B9786EA42D998D1AD258F0653846524069F22E5E442EFFCA`. 다르면 패치를 활성화하지 않는다. 다른 모드의 실행 중 템플릿/후킹 변경까지 검사한 것은 아니다.

## 검증

`./ItemRebuild/build.ps1`은 Release 빌드, 실제 소스를 연결한 오프라인 대역 검사, 설치 interop 서명/참조 검사 후 루트 DLL을 만든다. 게임을 실행하지 않는다.

2026-09-18 과거 저장 사본 389행을 대역으로 읽어 308행으로 합쳤으며 모든 종류의 총수량을 유지했다. 등불은 17행에서 수량 17인 1행으로 줄었다. 현재 플레이 중 보유량에 대한 결과가 아니다. 성능 향상은 측정하지 않았다.

실전 미검증: 팝업 배치/포커스, 판매·선물·폐기, 출발/탐험 사용/귀환, 저장·재로드와 타 모드 병용. 사용자는 8개 보유에서 3개 휴대→가방 5개, 탐험 1개 사용→2개 귀환→가방 7개를 우선 확인하면 된다. 무게가 충분한 조건을 사용한다.
