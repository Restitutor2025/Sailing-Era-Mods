# Restitutor Devil Fruits (Restitutor_devil_fruits.dll)

"(스탯명) 악마의 열매" 5종(신체·감지·기교·학식·매력). Tab 인물 화면에서 Stat Rank 등급 글자(S~D)를 클릭해 사용하면 선택한 항해사의 그 능력 **성장 등급이 한 단계** 오른다.

- 설치: `Mods\Rebalance\` (build.ps1이 manifest.json과 함께 복사). 게임을 끈 상태에서.
- 필요: `Mods\Additional_Functions\Restitutor_Additional_Stat_Rank.dll` (클릭할 등급 글자). 없으면 아이템은 존재하지만 사용할 수 없다.
- 빌드: `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1` (빌드 → 규칙 검사 → releases\0.1.0 → Mods\Rebalance).
- 획득 경로·가격·판매는 이 모드에 없다(별도 아이템 추가 이벤트 담당).
- 문서: `docs/mods/devil-fruits/CURRENT.md`, `PATCHES.md`, `0.1.0.md`.
