Restitutor 모드 v1.0.1 — Base
==================================================

■ 필요한 것
- Sailing Era (Steam)
- R11-T17-S2 한글패치+버그픽스(상회비용 포함)판
  → 다른 판이면 Item Rebuild, Stat Rank, Tab Characters, Fleet Info 가
    스스로 꺼집니다. (게임과 나머지 모드는 정상 실행)
- MelonLoader 0.7.3

■ 설치
1. MelonLoader 설치 (처음 한 번)
   - MelonLoader 설치 프로그램 실행 → SailingEra.exe 선택
   - 'Latest' 체크 해제 → 버전 0.7.3 선택 → Install
   - 게임을 한 번 실행했다 끕니다. 첫 실행은 준비 작업 때문에 몇 분 걸립니다.
2. 게임을 끈 상태에서 이 zip 을 게임 폴더(SailingEra.exe 가 있는 곳)에
   그대로 압축 해제합니다. (덮어쓰기 허용)
   Mods 안의 각 폴더에 들어 있는 manifest.json 도 함께 풀어야 합니다.
   (없으면 MelonLoader 가 그 폴더의 모드를 읽지 않습니다)

※ 설치 전에 세이브를 백업하세요.
   위치: %USERPROFILE%\AppData\LocalLow\bolingo\SailingEra
   Item Rebuild(가방 합치기), Contribution(허가 해금)은 세이브에 기록되며
   모드를 지워도 되돌아가지 않습니다.

■ 모드별 기능
[Restitutor.Core]
  다른 모드가 함께 쓰는 공용 파일. 지우면 모든 모드가 꺼집니다.

[Intro Skip] 시작 로고·건강/면책 안내 화면을 자동으로 넘깁니다.

[Text Speed] 설정 → 영상 탭에 대사 속도 항목 추가.
  '빠르게' 선택 시 대사가 바로 전부 표시되고,
  문장이 끝나고 3초 뒤 다음 대사로 넘어갑니다.

[Instant Entrance] 항구에 다가갔을 때 입항 대기(약 2.5초)와
  입항 표식 등장 연출을 없앱니다.

[Contribution] 공헌도 혜택 자동화
  - 도시 공헌도가 오르면 조건을 채운 정부 허가 혜택이 자동 해금
    (관청의 수동 허가 탭은 숨김)
  - 첫 입항 / 공헌도 100 / 역참 신규 자원 등록 때
    그 도시 교역품을 자동으로 알게 됨
  - 도시 메인 화면에 혜택 현황, 해금·인식 알림창 표시

[Item Rebuild] 가방 정리
  - 같은 소모품·스킬북·언어 서적·역참 도구를 한 칸으로 합침(수량 표시)
  - 같은 장비는 묶어서 표시 (착용 중인 것은 따로)
  - 판매·구매 수량 슬라이더, Min/Max 버튼, 마우스 가운데 클릭 = 최대
  - 선실 설계도·선실 확장 공법은 가방에서 숨김(효과는 그대로)
  - 이미 가진 선실 아이템, 이미 연 항로의 항로도는 상점에서 숨김

[Stat Rank] Tab 인물 화면 능력치 이름 옆에 성장 등급(S~D) 표시.
  등급에 마우스를 올리면 레벨업 때 능력치가 오를 확률표.

[Tab Characters] Tab 인물 화면 개선
  - 인물 목록 10명씩 페이지 (Q / E)
  - 스킬·언어 줄 클릭 → 옆에 학습 패널
    (책으로 배우기, 스킬 포인트로 '스킬 레벨 +1')
  - 남은 스킬 포인트 표시
  - 장비 칸 클릭 → 옆에 장비 패널
    (장착·해제, 우클릭 해제, 다른 인물 장비 가져오기)
  - 상단 '스킬'·'장비' 탭은 인물 화면으로 합쳐져 없어집니다.

[CTRL Instant] 항해 중 CTRL 을 누르는 순간 시간이 멈춥니다.
  (선단이 없어도) 떼면 다시 흐릅니다.

[Fleet Info] 여급의 주변 함대 정보가 같은 세력 함대가 여럿일 때
  열리지 않던 버그 수정. (겹치는 함대는 하나만 표시)

[Map] 항로 계획·출항 준비를 Tab 지도에서 합니다.
  - 좌클릭 / Space 로 경유지 선택
  - 갈 수 없는 도시는 빨간색 표시
  - 지도 안개가 반복해서 다시 그려지던 문제 수정

■ 제거
  해당 DLL 파일을 지웁니다. (Mods 폴더 안)
  UserLibs\Restitutor.Core.dll 을 지우면 모든 Restitutor 모드가 꺼집니다.

■ 알려진 제한
- 게임패드는 지원하지 않습니다.
- 게임이나 한글패치가 업데이트되면 일부 모드가 꺼질 수 있습니다.
