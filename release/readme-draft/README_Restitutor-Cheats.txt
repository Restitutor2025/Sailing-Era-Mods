Restitutor 모드 v1.0.0 — Cheats (선택)
==================================================

■ 설치
  Base 를 먼저 설치한 뒤, 게임을 끄고 이 zip 을 게임 폴더에 압축 해제.
  제거: Mods\Cheats 폴더의 DLL 삭제.

■ 조작
  O : 치트 전체 끄기 / 켜기 (끄면 창과 효과가 모두 사라짐)
  H : 치트 창 접기 / 펼치기
  패널은 해당 장소에서만 나타납니다.

■ 패널
[Speed]        항해 중     이동 속도 X1~X5 (항해 끝나면 X1)
[Battle]       해상 전투 중 아군 전투력·포격 피해 X1~X5 (전투 끝나면 X1)
[Contribution] 도시 안     이 도시 공헌도를 원하는 값으로
[Money]                    소지금을 원하는 값으로
[Exp]          술집        경험치를 원하는 값으로 / Max
[Skill]        술집        스킬 포인트를 몇 레벨마다 받을지 변경
[Bargirls]     여급 있는 술집  여급 호감도 한 단계 올리기
                           (여급 과제 진행 중에는 막힘)
[Character]    Tab 인물 화면  HP·공격력·능력치·스킬 레벨 직접 수정
[Items]        Tab 인물 화면  장비·책·악마의 열매 검색해서 받기

■ 주의
- 공헌도·소지금·경험치·호감도·인물·아이템 변경은 세이브에 남습니다.
  O 로 꺼도, 모드를 지워도 되돌아가지 않습니다. 세이브를 백업하세요.
- 공헌도를 올리면 Base 의 Contribution 모드가 혜택을 자동 해금합니다.
- 알려진 문제: 타이틀 화면에서도 치트 창이 보입니다.
  (다음 버전에서 수정)
