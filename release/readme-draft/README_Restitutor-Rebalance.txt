Restitutor 모드 v1.0.0 — Rebalance (선택)
==================================================

■ 설치
  Base 를 먼저 설치한 뒤, 게임을 끄고 이 zip 을 게임 폴더에 압축 해제.
  제거: Mods\Rebalance 폴더의 DLL 삭제.

■ 악마의 열매 (Devil Fruits)
  능력치별 '악마의 열매' 5종이 추가됩니다.
  먹은 항해사의 해당 능력치 성장 등급이 한 단계 오릅니다. (S 는 불가)

  사용법: Tab 인물 화면 → 능력치 옆 등급 글자 클릭 → 열매 패널에서 [사용]
  (등급 글자는 Base 의 Stat Rank 모드가 표시합니다)

■ 주의
- 현재 게임 안에서 열매를 얻는 방법은 없습니다.
  Cheats 의 [Items] 패널로만 받을 수 있습니다.
- 올린 등급은 세이브에 남고 되돌릴 수 없습니다.
